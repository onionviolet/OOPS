World audits, expansion and exploration passes, source dives, facility and
person-to-person role passes, and reviews of lane returns follow
[world pass rules](docs/WORLD_PASS_RULES.md) WPR1–WPR32. Name the pass, budget and
owner file first; label every claim with evidence and a locator; review lane
returns against their sources before folding; end with a more-to-consider round;
save in the repo owner doc before memory. Use haiku first for bounded readers in
Claude sessions unless Weibao specifies Codex limits (AU5).
