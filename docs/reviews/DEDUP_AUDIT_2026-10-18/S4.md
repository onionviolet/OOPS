Area: every subfolder of `src/` (absorb_b, absorb_c1, absorb_c2, absorb_d, absorb_e1, absorb_e2, absorb_e3, absorb_p23, components, data, management, models, mods, ui) plus the non-.js files under `src/` (13 HOST_CONTRACT/CONTRACT .md files in absorb_p23, `src/absorb_c2/balance.json`, `src/data/srd521/*`). About 23,200 lines. There are no non-.js files directly in `src/` itself.

Method: scripted function-line hashing across all of `src/`, helper-declaration greps, import graph with Tarjan SCCs and importer lookup across src/tests/scripts/tools, unused-export scan, markdown link and path checks, doc-to-src path and line checks, then reading both sides of each finding. VERIFIED means I read every copy cited. SUSPECTED means one side is inferred.

## Summary

24 findings: 2 high (F1, F6), 13 medium, 9 low. Type counts below are approximate because some findings mix types.

| Type | Count |

Answer to the key question. The absorb_* folders are mostly leaf modules (only `absorb_d/ui.js` sits in an import cycle). They do not import `main.js`. They overlap the top-level modules in four ways: (1) they re-declare the same validator/helper lambdas (F1); (2) they spell world, location, save-slice and item-key strings as literals that top-level files and `main.js` also spell (F11, F12, F16); (3) they re-implement predicates other modules already compute (F3, F4); and (4) `main.js` holds the host half of each lane, including a second copy of facts the lane module also holds (F11, F15). `data/` is mostly upstream game content with no duplication of docs, but it contains one missing-key defect (F6), start-state facts duplicated in `main.js` (F11) and a few constants duplicated in code (F13, F18).
