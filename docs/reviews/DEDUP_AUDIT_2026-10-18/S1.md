Area: the first 185 files of `ls src/*.js`, `src/acquisition.js` through `src/feature_expansion_book_cultivation.js` (35,604 lines). Method: scripted detection (function-body hashing across the area, repeated string literals, import graph with Tarjan SCCs, exported-name usage across src/tests/scripts/tools, doc-to-src path and line checks), then reading both sides of every finding. VERIFIED means I read every copy cited. SUSPECTED means one side is inferred.
