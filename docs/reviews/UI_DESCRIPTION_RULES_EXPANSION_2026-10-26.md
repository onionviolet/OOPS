## E1–E5: Other-game precedents and their limits

All accessed 2026-10-26. These are developer statements and documented examples, not this pass playing those games or verifying their latest builds. OOPS adaptations below are inferences. Earlier Grim Dawn and BG3 comparisons remain in the prior receipt and were not rerun.

| Code | Primary source, date and what it establishes | Useful OOPS inference, with limits |
| --- | --- | --- |
| E1 | [Factorio FFF-318](https://www.factorio.com/blog/post/fff-318), 2019-10-25, “Categorization” and “Tooltip separation”: recipe and product information were separated; placed entities add state to shared properties. | Reuse the subject definition while keeping recipe method, product identity and instance state distinct. This does not select multiple floating tooltips for OOPS. |
| E2 | [Factorio FFF-426](https://www.factorio.com/blog/post/fff-426), 2024-08-30, “Recipe crafting throughput tooltip” and “Assembler recipe info”: contextual production rates account for interacting factors; product-slot tooltips need the actual item's state, including spoilage, while recipe identity has its own route. | A raw ingredient or stat bonus and the contextual result answer different questions. Name the object and assumptions; use a consumer-backed result when available. No OOPS spoilage or production feature is implied. |
| E3 | [Factorio FFF-397](https://www.factorio.com/blog/post/fff-397), 2024-02-09, “The core of the problem” and Factoriopedia: browsing both ingredients and uses solves different discovery questions. | A description can help answer “what is this for?” through existing known-use navigation. OOPS must preserve its own knowledge boundaries rather than expose the source game's whole reference catalogue. |
| E4 | [Diablo IV: Master your Power in Season of Blood](https://news.blizzard.com/en-gb/article/24014289/master-your-power-in-season-of-blood), the historical Season of Blood explanation, “Damage Buckets”: profile totals combine additive and multiplicative terms; the article explicitly describes omitting some multipliers to limit tooltip length. | Useful counterexample: concise totals can still fail to reconcile with visible parts. OOPS should offer a supporting explanation of material omitted contributors, subject to knowledge, instead of promising that a short sum accounts for everything. These historical formulas are not current Diablo balance claims or OOPS formulas. |
| E5 | [Xbox Accessibility Guideline 106](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/106), sections on narration scope and method, documents labels/roles/values and Gears Tactics hit/crit narration examples. | Readable prose and structured numeric relationships should survive linear narration. This is a bounded accessibility precedent, not evidence that OOPS supports narration or a proposal to build a voice subsystem. |
