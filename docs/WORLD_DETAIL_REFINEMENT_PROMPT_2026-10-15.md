### Fine-detail loop: Repeatable fine-detail and source-absorption workflow

Apply this loop inside existing world dossiers/cards/detail ledgers. Use S00–S14 and the existing core kit to find neglected areas, then examine one coherent aspect at a time. Do not create a competing questionnaire, dossier or standard. Improve the appropriate method owner if this pass establishes a useful refinement and its writer is available.

| Step | Internal questions and observable output |
| --- | --- |
| WQ1. Select and recover | Which aspect matters now, what did we already answer or research, and where is the reusable result? Name the source range, local owner, current gap and a bounded finish condition. |
| WQ2. Examine real detail | What actually happens in a representative scene or described practice? Record actors, prerequisites, materials/tools, sequence, time, cues, variations, interruption, aftermath and ordinary uses where supported. Distinguish explicit fact, interpretation and unknowns. |
| WQ3. Follow consequences | What does this imply for training, equipment, work, trade, institutions, social responses, discovery or later development? Which are supported consequences and which are new proposals? Identify fine details that change an action, expectation, choice or feeling of place. |
| WQ4. Map existing support | Which native mechanics and prior audits already cover this? Trace real consumers, not names or metadata. Record representable detail, missing joins, absent capability and intentionally unrepresented texture separately. |
| WQ5. Decide or ask | Apply the linked question workflow. Answer source/code questions through inspection. Ask Weibao only about a consequential premise, desired experience or adaptation choice that remains open. A higher-level answer should resolve repeated cases when appropriate. |
| WQ6. Record and advance | Save qualified details and dispositions with existing IDs/source locators; update the appropriate owner and applicable matrix cells. Finish the aspect or record its dependency, then select the next highest-value aspect without restarting the same source scan. |

Use internal questions freely without asking Weibao to answer a long checklist. The workflow should ask more precise questions of the material and implementation, not make him invent every small rule. For example, a lesson scene can establish tool custody, preparation, failed attempts, teacher knowledge and later independent practice; it need not become five preference questions.

For books/anime/manga, identify the actual edition, translation, adaptation, episode/chapter and source range. Preserve medium-specific evidence: prose explanation, observable choreography, visual/audio cues, ordinary routines and exceptions. A still frame does not prove a sequence or hidden cause; a summary/wiki is not a substitute for an inspected primary scene. Do not silently combine incompatible adaptations or treat an unexplained effect as a universal law. Mark unavailable source inspection explicitly.

Absorb finer detail through an explicit route: qualified source observation → local design implication → existing capability or missing seam → proposed representation → observable acceptance criterion. Possible dispositions include atmosphere/dialogue, contextual information, meaningful mechanic, future extension, already covered, contradicted or deliberately outside the selected scope with a reason. Texture can matter without a new simulation system. Do not reduce every detail to a numerical buff or mechanically implement every sentence.

Investigate other aspects beyond signature powers: meals and lodging, tools and maintenance, local etiquette and language, travel and access, money and services, paperwork/law, rank and reputation, teaching practices, disability/injury/recovery, seasonal rhythms and regional differences where relevant. Include subtle exceptions, mundane applications, alternative approaches and interactions with imported means. These are prompts for evidence, not universal content requirements.

Finish an aspect when existing claims are reconciled, material source details have a disposition, unanswered questions are classified, and the next action is clear. Preserve unread source coverage and whole-world remainder. Do not claim complete source absorption from a handful of scenes, or turn a sample into proof that every audit reached the same depth.
