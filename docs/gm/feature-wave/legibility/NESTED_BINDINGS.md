## Mission and extraction

Read actual `state.simulation.knowledge.player` or its equivalent already filtered `nestedPresentation.records`. An actual record supplies text/at/cause; qualify it `{known:true,observerId:'player',recipientId:'player'}`. Do not read private NPC knowledge, actual hidden issuer plans or frozen extraction.interference as an observed result.

| Actual emitted key | View meaning |
|---|---|
| `nested.offer.<missionId>` | Terms before acceptance. Header/issuer objective may use the same actually offered label/objective; never the full unseen mission definition. |
| `nested.accepted.<missionId>` | Actual accepted finite funding/obligation receipt; acceptance itself is no arrival or payout. |
| `nested.arrival.<missionId>` | Actual arrival/retained-instance receipt and start of the accepted local deadline. |
| `nested.outcome.<missionId>` | Actual reported outcome, keeping issuer success and known local welfare distinct. |
| `nested.extension.<missionId>` | Actual paid extension receipt; not a completed objective or guaranteed exit. |
| `nested.extraction.<missionId>` | Actual extraction initiation; local body and preparation remain distinct from hub arrival. |
| `nested.recovery.<missionId>` | Actual paid recovery of the selected interrupted route; not universal safe extraction. |
| `nested.returned.<missionId>` | Actual hub arrival, still awaiting settlement. |
| `nested.settled.<missionId>` | Actual once-published settlement. Use `occurred:true`; never pay or narrate it from a returned/ready flag alone. |

Additional current/interrupted/ready stage text needs the actual host's visible current stage/retained receipt, with `current:true`/`occurred:true`. No future extraction branch is revealed just because it was frozen. Terms about possible interruption remain terms.

Supply return deadline, extraction interval and settlement as separate declared rows, not one sum. A known future destination/offer is not a current observation of its off-screen local clock/stock. Retain the timestamp/policy. No projector advances, reads wall time or invents a rate.

Legal `nestedActions` come from actual `previewNestedCommand` with its visibility/eligibility and exact live native context. Preserve `{id,sequence}` or the owning host's equivalent displayed token. Known withdraw, extension, route recovery, arrival and settlement are separate actions; clone them through projectEssentialRecovery. Qualify only genuinely public specific reasons, costs and passage terms; do not blanket-map raw validation errors.
