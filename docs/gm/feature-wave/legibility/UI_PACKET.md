# Action view worker contract v1

Own only new `src/action_legibility_ui.js` and `styles/action_legibility.css`. Root owns projection/evidence; Features owns existing bindings and build. Read AGENTS, PROJECT relevant intent, common feature packet, Features INTERFACE and legibility assignment. No tests/browser/save access; syntax/import checks allowed. No shared/package/canonical/build changes. No direct messages to peer chats.

Implement dependency-free DOM helpers. Exports: `createActionLegibilityList({parent,onAction,onAlternative,onCancel,focusFallback,idPrefix})`, returns `{element,render({actions=[],work=[],aftermath=[],enabled=true,notice=''}),destroy()}`; `createActionLegibilityPanel({...options,label,read})` wraps a details panel and returns `{panel,render,destroy}`. No automatic attachment to native parents; caller supplies parent. Never evaluate raw definitions or owner records. Callback receives projected row plus any clicked alternative; host rechecks and publishes. Callbacks may be async; keep a local pending latch and report errors in live status, never assert saved success from return absence. Rendering has no RNG/commit.

Projected action row: `{id,label,description,status:'available'|'blocked'|'discovered',control:{visible,enabled},requirements:[{id,text,met?:boolean}],blockers:[{id,text}],costs:[{id,text}],duration:{minutes,text,kind:'quote'|'terms'},cancellation:{policy,text,canCancel},reservations:[{id,text}],preparation:[{id,text}],alternatives:[{id,label,description?,enabled}],completion:[{id,text}]}`. Rows are already observer-qualified. `searchText` is optional, never raw definition search.

Work row: `{id,label,status:'accepted',remainingMinutes,remainingText,cancellation:{policy,text,canCancel},costs:[],reservations:[],completion:[],control:{visible:true,enabled:false}}`. Cancel control availability uses global enabled and work cancellation, independently of action discovery/occupancy.

Aftermath row: `{id,text,at?:number,timeText?:string,basisLabel?:string,sourceLabel?:string,causes:[{id,text}]}`. Causes already qualified; never infer from IDs or display raw cause IDs. Render retained text and qualifiers. Do not promise future outcomes.

Use stable keyed rows and nodes, preserve details open state and input/focus across renders, move focus to focusFallback or panel summary only when removing/hiding a focused row. Native button Enter/Space and details keyboard behavior suffice; no unnecessary custom arrow interception. Blocked buttons remain keyboard-focusable using aria-disabled plus guarded click, aria-describedby points at visible costs/blockers, text status not only colors. Distinguish work, action and aftermath IDs in keys. Costs, known requirements, preparation/alternatives and cancellation stay readable, responsive and scoped CSS. Avoid innerHTML. Parent calls render; renderer supplies no timer. Document exact API and return syntax checks plus remaining behavioral gates.
