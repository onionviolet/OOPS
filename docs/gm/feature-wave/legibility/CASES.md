## Admission review findings

Current `feature_expansion_host.js` and UI import the projection/list and render `action.legibility`; Frontier host/UI and index stylesheet have also begun actual joins. No current bundle assertion yet. Backlog/Ink and other external controls still need their own admitted legibility joins. Cancellation, retained aftermath and alternative links need actual consumer coverage, not just export availability.

`feature_expansion_legibility.js` currently qualifies authored requirement prose automatically. In projection v1, `known:true` qualifies the term only; current met/not-met additionally requires `valueKnown:true`. An explicit reason string alone must not qualify hidden NPC/world truth. The adapter should preserve own default valueKnown descriptors when adding prose and mark only genuinely current observed facts. Participant/site metadata needs present offer/observation evidence, especially before marking reservation or capacity observed. Public definition membership alone does not disclose an unknown family, target, site or current private budget.

Static review later checks source imports, registrations/native callback routing and bundle source correspondence. Browser/keyboard/focus/removal/save/reload/failure/compatibility/director gates remain deferred in PLAYTEST; earlier checks do not establish changed behavior.
