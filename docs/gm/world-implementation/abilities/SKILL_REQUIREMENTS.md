# Bounded skill wave requirements

2026-10-05. Active authority: [dispatch](../../dispatch/SKILLS_DISCOVERY_AND_WORLD_COMPLETION_2026_10_05.md). This releases the old hold only for these four original prototype functions and their discovery/native integration. Names, costs and mastery bands remain reversible. The broader world roster stays held.

Required IDs are frozen for this wave: `frontier.brace_control`, `frontier.trail_reading`, `frontier.timber_judgment`, `frontier.shared_inquiry`. No new native XP ledger is requested. Existing `Equilibrium`, `Perception`, `Woodworking` and, where actual reading occurs, `Literacy` retain native competence. Existing simulation powers can own learned methods/mastery; discovery stays in existing knowledge/completed records. Merely seeing a card or trainer teaches nothing.
