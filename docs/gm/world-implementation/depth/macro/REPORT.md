## Priority and review choices

Necessary foundation families are E1–E5 with selected subsets; detailed maps, every organ, large armies, inheritance, offline simulation and full time-loop restoration are optional until the chosen campaign uses them. Avoid a separate engine per book, while leaving room for genuinely dedicated functions. Ordinary advancement must fund continuing useful work rather than require exceptional protagonist acquisitions.

Proposed first pair remains Frontier plus **Gu upkeep or MoL control/research**. This recommendation preserves the held Original Short Measure gaps: correct native player travel and physical stock reservation/recheck. Fallout is a strong next production/maintenance cross-check. Naruto's ordinary routes need no transplant; acquired-eye gameplay waits for source/Micro/body qualification. The Paradise hub adds a useful organizing structure after destination owner contracts work, without making it compulsory for every start.

Director/master choices remain the plan's existing five review rows: roster/depth; first starts/qualification IDs; clock/portability; RNG/dialogue; failure/release. No answer is inferred from source completion, elapsed time or creation of these reports.
