## Decisions that must become concrete on selection

1. Freeze each chosen world's local paths, IDs, represented era and mature functions, including required alternatives versus a player's one completed path. Keep broader desired taxonomy as optional/future coverage, not a moving completion target.
2. Select growth cause and actual result for each method: levels, practice, insight, transmission, chance, or supported compound choice. State which gates are alternatives; do not quietly turn every method into all of them.
3. Pick exact actors, source/body/item/target and clocks for the field, assembly or experiment. Declare fixed variants versus true mutable parts and live continuation versus already prepaid frozen work.
4. Name real output recipients, payers/rights, portable means and local support, then connect stages to changed future work, teaching, access or institution outcomes through the existing owners.
5. Record source/invention boundaries and actual source/module/native/build/behavior/director status. Only a selected new direct adaptation needs its named missing scene retrieval; no full-book restart is justified here.
