## Positive operating rules

Keep each genuinely superior function. A better ward can stop its actual target more reliably; an excellent actuator can raise supported load; an intrinsic source can supply its own control. Ordinary routes need worthwhile output and actual demand, not mandatory superiority against every exceptional source. Counterexamples come from real target/domain/support mismatches, never newly invented balancing flaws. Original heat/wear/upkeep applies only to the particular authored object that declares it.

Acquisition outputs differ: known method, portable owned device, body-bound faculty, loaned execution, transformed body, fused source or institutional permission. Declare donor/constituent/recipient outcome using existing [micro identity and conservation contracts](../../depth/micro/COMPONENT_AND_EFFECT_CONTRACTS.md), not a second acquisition ledger. A newly inherited or purchased validated device can skip invention; knowing an old-life design still cannot create current materials or consent.

## Ordered settlement and visible consequence

For a selected new command: safe preview; actual live eligibility/revision check; stock/worker/support reservation; one frozen choice/draw; ordered irreversible phases; owner-state validation and durable save; native publication and qualified observer consequences. Stale requests reject before new debits. Duplicate cause returns the settled receipt. Failed persistence publishes no new phase; earlier durably committed phases retain their outcomes. Physical custody, funds, source and local-clock rules must agree before a cross-path output is accepted.

UI shows a known method separately from its absent fuel/tool/access, remaining accepted work on its real clock, an actual paid trial's limited result, and dated reports separately from current truth. A maturity preview reports the usable new action and known terms, not a secret future ending. Later generated-state acceptance must include interrupted work, stale support/stock, repeated claims and failed publication; these checks were not run in this planning task.
