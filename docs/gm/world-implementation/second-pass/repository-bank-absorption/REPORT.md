## Reuse, authoring and provenance

Independent original implementation is the best fit for the five families. QuestJS and Arcanum have MIT notices, but their runtime/global task owners would duplicate current YAIR systems; copying a small function supplies no native stock/save/UI bridge. NetHack/xNetHack, ToME, Crawl, CDDA and Wesnoth have different source terms, while media/data can have separate terms. Angband has code-license alternatives and asset exceptions; FrogComposband file rights remain unresolved. Idle Loops and Progress Knight lack discovered top-level licenses. Public access is not a file/asset reuse qualification. No code, names, prose, scenarios, art, fonts, audio or setting content was imported.

A library can reduce a genuinely missing task: Ink/inkjs can provide long-prose continuation and authoring; rot.js can supply grid path/FOV queries. Current short native scenes and authored road edges do not demonstrate those needs. Ink's full cursor, stable host commands, compiled content identity, version guards and atomic save still require an adapter. The pinned YarnBound source also documents a narrow premature-command edge case beyond its README end-detection warning, so callbacks must not become reward authority. Inform supplies staged-action recipes without adopting its VM. TextWorld and TextWorldExpress are seeded benchmark/generation systems, not persistent campaign owners. [Authoring qualification](appendix-authoring.json) distinguishes exact prior reuse from the refreshed inkjs pin.

Seven commercial/tabletop references remain description/documentation comparators; no internals or complete book contents were reviewed. Cavernous II now has a verified creator-linked TypeScript source route and custom commercial-use terms. Proto23's published/source route and prior bounded HTML evidence are qualified, with no discovered license or direct creator confirmation. Suggested future source rows are returned in COVERAGE for the bank's writer; the bank itself was preserved.
