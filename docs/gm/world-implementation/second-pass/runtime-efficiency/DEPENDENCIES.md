## Required shared contract boundaries

Scheduling keys must identify clock domain, causal timestamp, current phase, original tie key and definition revision. Keep the present ordering visible: expansion commitments/opportunities and chronicle progression, then simulation jobs, conditions/life, expiry/checks, pursuits, controller choices and routines. A new index must return the same ordered eligible work. Definitions may supply a precompiled order, but saved RNG streams, sequence IDs and frozen job templates remain authoritative.

Read/write dependencies need actual owners rather than a lone `state.sequence`: time can move without a new command sequence, and native stock, skills, weather or busy state can change outside one simulation effect. Include actor/target, body/source, resource/stock/site, global/world/journey, observer knowledge, native XP unlock dependencies, content revision and relevant clock window. An effect can spawn a person, create a check/controller, transfer a source or alter a shared claim; those mutations wake/invalidate their real dependents. Unknown readers or writers use the full-state fallback. Derivable maps, display caches and counters should remain unsaved initially; no schema is approved here.

A cooperative advance must return consumed and unspent time plus the cause of stopping. The current host moves the native calendar by consumed time and returns it (`src/main.js:519-525`, `5790-5812`); this audit asserts no proven lost-time defect. Future driver-owned remainder distinguishes a budget pause from a real player decision/life ending. Preserving a long request across UI turns cannot turn frozen browser-closed time into an unauthorized offline policy. A complete timestamp is the safe first yield boundary; a single expensive timestamp can still overrun a soft CPU target. Strict per-frame completion is not promised.

Continuous functions use their selected startup/use/upkeep/recovery/throughput/strain semantics and source exceptions. An exact integrator stops at the first relevant cap, depletion, source/contact/consent loss, life transition, site contention, event observation or player choice. Integer/fixed-point residuals and rounding order need a declared carrier. Never add a universal drain, hidden strength cap or balancing drawback. Independent aggregate flows may batch only when their reads/writes and observer consequences commute; competition for a finite lot or a newly promoted actor restores ordered individual settlement. Preserve authored RNG attempt/miss/guarantee streams unless a replacement proves identical outcomes and seed progression.

Retention has three distinct concerns: short UI tails, persistent current consequences and exact replay/reversal evidence. Existing 100-entry log tails/terminal-event pruning and 32-entry relationship memories/transitions bound selected display records; open events and permanent causes/claims need separate treatment. Actual people/knowledge/progression survive separately. An archive horizon cannot be chosen by this audit. Do not coalesce two unique organs, named people, claim causes or different clock histories into a count. Temporary derived caches also need lifetime limits and removal on import, actor disappearance, world/definition switch and failed plan abandonment.

## Proposed evidence gate, currently deferred

After director review and permission to resume the relevant checks, compare generated fresh/small versus active-crowded, many dormant instances, body/effect-rich and long-history fixtures on one identified source/bundle. Independently vary due controllers, positive-weight outcomes, shared-stock conflicts, native actor/skill count, closed versus open panels and permanent receipt count. Report per-stage CPU, clone/validation/fact builds, active versus dormant work, raw sample counts, consumed/unspent time, save bytes, frame/input latency and retained heap/DOM/listeners. Keep RNG/identity/stock/history equality alongside timing. A faster but causally different plan fails. No workload size, latency threshold, actor cap, token saving or release criterion is adopted by this report.

Planning acceptance now is JSON schema, exact local evidence bounds/targets, Markdown links/anchors, whitespace, readback, input-drift reconciliation and sole-writer/process closeout. Future behavior gates above were not run. No tests/build/import/browser/profile/save process was launched, and no private or generated save payload was read; only saved result summaries and profiler source were inspected.
