# Runtime efficiency decision summary

Completed planning audit, 2026-10-04. Keep the common event-boundary scheduler and durable publication path. Prioritize derived indexes, scoped validation and change-driven views. Runtime implementation remains held for Weibao's review; the assigning master alone merges amendments into the [canonical plan](../../IMPLEMENTATION_PLAN.md).

The saved 64-paid-helper comparison reports a tick median of **209.90 → 128.68 ms** and twelve-minute jump of **743.70 → 549.19 ms**, five samples each. Earlier checks retained exact normalized plans, split/jump agreement and actual output owners. Retain the useful immediate preview reuse and early rejection. These historical samples neither measure current Glasshouse code nor predict another improvement. [Recorded proof](../../../../PLAYTEST.md#native-chest-and-scheduler-proof-2026-10-04) and [measurement qualifications](DEPENDENCIES.md#saved-measurements-and-their-limits) identify the artifacts.

Five proposed amendments cover the highest-value work:

1. **Measure and reduce repeated work within one transaction.** Eligible command previews clone the whole state and clone each positive-weight outcome; commitment validates further frozen candidates. Native commitment preflight also advances a hypothetical whole scheduler. Introduce a mutation/read-set contract, branch-local drafts and affected-invariant checks only after proving the exact identity, stock, unlock and failure behavior. Keep full import validation and the existing future-reward check until a replacement covers its dependencies. Never reuse a player quote across mutations.
2. **Index boundaries and occupancy.** Boundary selection scans jobs, checks, controllers, events, conditions and people; due jobs repeatedly filter the array. Precompute immutable controller priority/tie order and derive actor/site/event indexes. Start with due buckets or cached minima; measure before adding a heap. Bind scheduling to actual instance clock activation. Glasshouse prevents unsupported new caretaker work through context, while controller due checks still run. Paid jobs retain their selected completion semantics.
3. **Make workload and continuation explicit.** The 512-boundary cap returns unspent time but does not cap previews, effects or actors inside one boundary. Record phase cost, due work, clone/validation volume and remaining time. Yield between complete causal timestamps first. A hard limit inside one timestamp requires an explicit deterministic cursor and compatibility decision. Do not skip time, consume extra RNG or change source strength to meet a frame target.
4. **Publish and render only affected projections.** Native snapshots scan all bound actors and skills; publication rebuilds inventory mappings even for unchanged owners. The host refreshes many panels, some computing expensive previews while hidden, and expedition signatures serialize the whole state. Use an unsaved transaction change set and a shared read snapshot; separate countdown updates from eligibility/body/knowledge projections. Preserve stable controls, focus, disclosure and native skill dependencies. In the saved crowded browser fixture, inventory render p95 is 14.7 ms and command start p95 115.4 ms; storage-write p95 is 0.3 ms.
5. **Bound optional simulation and display history without losing causes.** Macro/micro already require aggregate promotion and distinct upkeep/recovery. Resolve only selected linear intervals to the first capacity, exhaustion, interruption or contact boundary; stochastic attempts and shared-stock conflicts stay discrete unless exact equivalence is established. Keep permanent claims and replay evidence outside short display tails. Named people remain real people. Archive or compact only after defining which later-return/reset operations need the evidence.
