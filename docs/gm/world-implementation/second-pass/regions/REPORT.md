1. **Bind harvest to real owners and legal phase boundaries.** Native gathering computes useful skill-scaled time, chance, count and quality, then awards inventory through its existing tick. It does not thereby supply finite-node conservation. The new patch must reserve stock, tools, occupancy and rights, then join depletion, residue and actual cargo in one durable publication. There is a concrete seasonal risk: GATHERING start does not call `can_work`, and the tick checks it after possible rewards. Select start/continuation/completion semantics and clock provenance before adding seasonal patches. Paid frozen work and live extraction need their own declared rules. REG01/02.

2. **Make the method change future supply.** Separate harvestable output from its producer or reserve. Tapping, felling, selective collection, tending, capture and prospecting should alter the particular supported state. Existing apple/wool jobs remain useful service shares; their declarations do not establish plant or animal lives. The additional depth is a preserved producer, a paid planting/care stage, an exposed finite seam or one bounded habitat connection. For example, an original bank intervention can change one downstream fishing pocket and one route. Source-supported inexhaustibility or superior extraction keeps its actual exception. REG03/04.

3. **Include the return leg in the resource choice.** Native links already have direction: Forest road to Carya Canyon is 120 declared minutes; Canyon back is 300, before native travel modifiers. A collector needs real egress, cargo and access terms. Packing one delicate sample, processing locally, caching goods under permission or hiring transport can create distinct careers and routes. Keep ordinary logs stable. Apply viability only to selected specimens whose preservation changes a useful decision, with a declared clock through travel and storage. REG05/08.

4. **Fund independent competition from the same supply.** The craftsman already receives and spends real wood; reuse actor jobs and occupancy. A collector must use actual tools, local access and time, then reserve the same patch units. Stable arbitration protects existing reservations and settled player cargo. Anonymous flows can stay bounded aggregates. Capture, personal interaction or a named rivalry promotes a real identity while conserving population and owned means; a hunt and a later product claim cannot spend the same animal twice. REG06.

5. **Keep information historical and resolution purposeful.** Existing observation/knowledge records already retain time, cause and basis. The world view's admitted keys read current instance values, so using that view for remote changing stock would silently refresh an old survey. Show dated estimates and offer supported re-surveys or reports while retaining learned competence. Keep the center menu, native adjacency and a few meaningful pockets; process selected regional causes at authorized boundaries. No tile map, full food web or climate simulation is required for this proof. REG07/09.
