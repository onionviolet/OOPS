# Whole-world bank and adaptive characters

2026-10-04. Planning delivery for review; implementation remains held.

Keep one reviewed reference bank per world/source edition, then derive small working sets for a particular era, branch, region, actor and task. Add explicit activation and observer projections around existing planners instead of building another simulation engine. A large reference bank can support deep local campaigns without enrolling every catalogue resident or simulating every distant settlement.

1. **Separate reference, policy, state and belief.** [Bank/query contract](BANK_AND_QUERY_CONTRACT.md) defines reviewed claim revisions, local exceptions, dependency closure and actor/task projections. Era validity and observer learning are independent filters. Mandatory source/body/fuel/ownership/time dependencies survive context limits; private dependencies go to the trusted verifier rather than the speaker. A catalogue supplies definitions, never owned stock, current power or automatic enrollment.
2. **Absorb timelines into bounded snapshots.** [Timeline contract](TIMELINE_ABSORPTION.md) consumes existing causal indexes, retaining occurrence, reveal, learning and clock relations. Intervention changes only dependent expectations. Canonical future events remain reference possibilities after divergence. Promoting a background person reconciles identity, actual stock and history once; missing source moments remain unknown or explicit original additions.
3. **Compose individuals rather than stereotypes.** [Actor model](ACTOR_AND_RELATIONSHIP_MODEL.md) combines optional occupation/culture/institution/life-stage/method/goal priors with constrained variation, fixed source overrides and lived history. Sampling freezes once. Canonical ancestry, bodies, secrets and fixed powers are never random fill. Two original harbor joiners have different commitments, supplies and histories, so one declines and the other accepts the same lawful work.
4. **Guard choices before ranking them.** Existing priority controllers and command previews already reserve real means. Add a bounded utility selector only where competing goals need it, and event-driven reevaluation where named changes matter. Directed trust can open a supervised project without supplying tools, affection, agreement or consent. Hearing, belief, teaching, obligations and institutional enforcement retain distinct records. Fresh dialogue uses speaker knowledge and settled consequences.
5. **Require functions and depth, not bank size.** The fixtures adapt one small inspection family to ordinary and arcane worlds with different acquisition, support, counters and portability. Future-world onboarding reuses valid families and adds bespoke consumers for genuinely new mechanics. Campaign and mechanic IDs must cover ordinary life, several routes, independent residents, functional growth, mature outcomes and useful return journeys. Superior or conditional-infinite functions keep their actual rules.

Current scalar bodies, single-topic knowledge and specialized native/world bindings do not constitute a generic character bank.
