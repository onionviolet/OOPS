## Optional composable priors

Separate identity/source facts, authored initial state, stable dispositions/preferences, temporary goals/needs, social ties, actual learning/episodes and present constraints. Compose zero or more priors from culture, region, institution, occupation, life stage, method tradition and immediate goal. A prior gives plausible distributions, action affordance candidates and voice cues. It creates no skill ownership, moral alignment, permission, property or secret.

Precedence: reviewed source invariants and exceptions -> explicit local branch overrides -> fixed individual authoring choices -> constrained sampled fields -> optional prior defaults. Contradictions reject before activation. A branch override to canon must name its cause; an undocumented numerical gap is a prototype parameter, not proof of a source rule.

This is baseline authoring precedence. Actual caused branch changes apply to committed state while the source reference remains intact.

Sample correlated profiles rather than independent adjective dice: a long apprenticeship can correlate with careful work, a narrow learned method and a mentor episode, but only actual authored learning grants that method. Scarcity can increase repair priorities while generosity still expresses through free advice. A hazardous job and a healing injury constrain feasible exertion; they do not force cowardice or hatred. Hard constraints cover age/care, body/ancestry/source, available institutions, legal role access, support and chronology. Individual exceptions remain possible when supported.

For generated actors, freeze seed, generator/prior revisions, selected legal profile, stable identity/body/instance, overrides and initial actual-state grants at one promotion/creation receipt. Preview, menu open, reload and new wording never reroll them. Persist resulting decisions/history, not just a seed whose algorithm may change. Revised priors affect new actors; existing actors need an explicit compatibility decision.

For source-defined people, copy only reviewed era-relevant facts into the baseline recipe. Never randomly fill unknown ancestry, organs, secret knowledge, powers, future events or motives. Unknown exact reserves remain unknown until an explicit labelled game parameter is selected. Source-defined age/body/life changes require a branch cause. A named character is not the generic occupation prior wearing a famous name. A generated local is explicitly original and inherits no named character's power or history.

Adaptation follows real causes: practice changes a learned function; reliable delivery changes relevant trust; care/loss can alter a current goal; acknowledged contradiction changes a belief. Changes can be delayed, conflicted or refused. Keep consequential stable episodes separate from rolling prose memories, consuming SOC05/TL07 rather than duplicating their ledger.

## Decision alternatives grounded in current code

| Approach | Existing basis and proposed extension | Best use and limit |
|---|---|---|
| Guarded priority | advanceSimulationBoundary sorts controller actions by priority, then predicates and preview eligibility | Small authored actors, duties and predictable independent work. Fixed priorities alone cannot express a tradeoff between two changing personal goals |
| Bounded utility | Proposed selector ranks the same eligible registered candidates using actor-local goal/value/history records | Competing useful work, teaching or care. Scores cannot legalize unavailable means, override consent or predict another actor's private state |
| Event-driven reevaluation | Proposed dependency queue wakes affected selectors on named changes, retaining deadline boundaries | Avoid repeated unrelated ranking. Needs wake dependencies, ordering, persisted pending decisions and fallback boundaries; it is not implemented by merely adding events |

Start with priority plus predicates for the two joiners. Add utility only when an authored choice needs more than that. Proposed score combines goal gain, accepted duty urgency, personal preferences, current attributed belief/trust and bounded risk/time/cost. Use goal-local scales, not a universal psychological number. An uncertainty-sensitive actor can choose investigation or abstention rather than fill unknown facts. Emergency safety and explicit commitments can remain hard priorities.

A concrete optional selector computes, for each legal candidate, the weighted sum of expected goal gains plus duty urgency and context-specific collaboration value, minus expected risk, time and resource cost. Each local term has declared units/bounds; expected outcomes use this actor's attributed beliefs, not author secrets. Frozen individual weights distinguish values; current need/deadline terms change through actual events. Candidates below the local abstention threshold produce wait/investigate rather than arbitrary work. Preserve the current job until its explicit interruption policy permits a switch. Deterministic ties use candidate ID; seeded ties consume one committed draw. This is a proposed algorithm, not an existing export or selected universal formula.

For event-driven selection, declare each candidate's read dependencies and next deadline. A stock transfer, injury, disclosure, accepted duty or relevant episode invalidates only affected candidates; coalesce same-boundary wakes, rebuild legal previews from the current sequence and commit at most one occupied action. Keep boundary checks as a fallback for deadlines/support expiry. Presentation changes never wake decision simulation.

Guard data comes from trusted state owners: alive/available body; supported method/source; actual fuel/tools/stock; permission/contact/location/instance; occupancy; learned execution knowledge; site capacity and commitment terms. Observed estimates inform risk preference, while actual support controls lawful execution. Showing the internal reason for a secret gate requires a safe disclosure mapping.

Rank only allowed candidates. Preview costs/effects through current command/response planners, freeze selected identity and outcomes on commitment, then persist and publish through Engine. Ties use declared stable order; if a seeded tie is selected, persist its draw once. Recheck sequence and real means before commit. An optional external planner may propose a registered command via acceptActorProposal; it cannot send effects, costs or executable code. Its current API still needs the scoped input/target authorization layer.

No spontaneous unregistered actions or menu-time simulation. A failed save changes no preference, stock, relationship, RNG or opportunity. The present prepaid completion model is not live-support monitoring for an injured worker; use EF05/06's phase/interruption adapter when the chosen job requires it.

## Relationships and actual opportunities

Maintain directed, contextual records: A's trust in B's craft is different from B's trust in A's discretion; respect, affection, grievance and collaboration readiness can coexist. A personal episode names participants, occurrence/discovery, claim versus witnessed result, cause, domain and closure. Existing relationship effects have directed axes and bounded memories; they are not an agreement or romance engine.

Knowledge: separate heard assertion, evidence, interpretation and current belief. Agreement: explicit offer, acceptance, terms, amendment/withdrawal and settlement. Affection: a personal feeling. Consent: a specific current voluntary permission, never derived from a score, gift, silence or occupation. Institutions own licences, sanctions and enforceable rights independently of personal trust.

Original case O01: returning Oren's borrowed gauge intact closes its actual custody record. He gains evidence of reliability and offers a supervised repair audition. Acceptance reserves his attendance, a workspace and actual material; only completed work can teach the method or open an independent commission. The player can remain a paying customer without that relationship route. A missing kit or injured hand still blocks work even after trust improves. Mira's accepted quay duty takes precedence over friendship until its stock/shift is free.

Optional romance requires eligible adults, two separately represented people, reciprocal interest and explicit voluntary steps with refusal/withdrawal/changed availability. Do not infer age from a role. A source-defined minor has no adult-romance affordance. Friendship, professional work, mentorship and care remain complete useful routes; refusal does not consume their basic access.

## Vernacular and dialogue projection

Voice profiles combine world/culture/region/era vocabulary, profession/context register and individual habits, with counterexamples to avoid caricature. Store brief analytical cues and fresh example lines, not copied prose. A skilled worker can speak plainly; accent is not a competence or morality label. Adapt wording to local terms already understood, an actual interpreter or earned translation faculty. Miscommunication is a concrete terms/evidence case, not random offense.

Build a scene-specific speaker card: present goal; known interlocutor; actual local means/occupancy; observations/testimony; relevant accepted terms/history; safe available actions; consequences/costs; source/voice cues and uncertainty. Author and player cards are separate. A speaker can conceal known facts without inventing false knowledge; a lie is an attributed act with its own later evidence, not an authoritative rewrite.

Render from settled receipts and known action offers. Fresh wording cannot accept a loan, reserve an NPC or pay a reward. Say “I can inspect it after the delivery” when unavailable; avoid naming an unseen power as the reason. A heard private-research report can become dialogue only after its disclosure/learning receipt. Current knownPeopleView is a useful handcrafted UI consumer, not a generic voice/retrieval service. Default implementation is authored variants; live-model dialogue remains unselected.
