# Integration strategy for review

Use a small opt-in package contract around the current planners, native adapters and durable publisher. Qualify repaired Short Measure, then a bounded Mother of Learning-compatible research visit, before repeating that route across selected campaigns. This is a proposed execution order, not implementation authorization. Engine/Ability/Original remain held; the assigning master alone amends the [canonical plan](../../IMPLEMENTATION_PLAN.md) and [RUN](../../RUN.json).

The alternatives are practical rather than claims of a global optimum:

| Route | Connected result and fidelity | Shared seams and compatibility | Recurring work and cost evidence |
|---|---|---|---|
| Extend each existing host separately | Reuse Glasshouse-style explicit bindings for each destination. A fixed cast can preserve exact local functions and reach a bounded native visit | Changes each destination's registry/enrollment, location/fact routing, native/save and UI bindings. Fewer generic contracts initially; repeated hosts must each reconcile dormant state and instance isolation | Reasonable for one isolated prototype. Separate binding lists and special cases recur as worlds grow. Completion time and savings unmeasured |
| **Manifest-lite, selected adapters** | Reuse those owners with explicit package activation, endpoint bindings and typed local rule consumers. Prove the same two routes before expanding | Five boundary classes: activation, instance/clock/location, settlement obligations, native publication/compatibility, UI/function consumers. Exact files and APIs are in the packets | Some up-front contract work; avoids repeating enrollment/view joins without requiring a new interpreter. Lower recurring burden is an inference, not measured time/token savings |

Retain the existing full validators, frozen commitments, cheap rejected previews and synchronous durable publication. The new package descriptor is authoring metadata plus explicit activation intent, not another inventory or save engine. [Authoring AUTH02/05](../authoring/FINDINGS.json) shows why registry composition alone is unsafe: enrollment scans provisioned actors, every site, automatic events and eligible controllers. [Foundations EF02/05/08](../foundations/FINDINGS.json) adds the actual instance, clock and content-version joins.

The immediate Frontier fixes are narrow. Replace the draft NPC 4/4/1 legs with the actual directed route durations, then declare how travel modifiers apply. Recheck the employer's physical log quantity/custody when paid inspection starts and settles; reject or refund changed support without a wage or successful report. Preserve audit, underwriting, independent refusal/delay, the real reserve and later teaching. [Held report](../../../../worlds/original-frontier/REPORT.md) records both gaps.

The second route uses source-qualified personal mana, shaping and structure-specific disruption from [MoL powers](../../../../research/novels/full-book/mother-of-learning/POWERS.md). An original eligible resident performs funded casting; the visitor earns instruction and cooperation, not an innate source. Actual light exposes a bench inspection, ordinary craft supplies useful stock, and explicit dispel removes a mana construct while ordinary burning retains its physical aftermath. Fixed scene mappings can use current timed conditions; arbitrary spells, maintained channels and item lamps remain separate coverage. Entry and return retain actual people, stock and knowledge.

The [DAG](IMPLEMENTATION_DAG.json), [rollout](ROLLOUT.md) and [packets](TASK_PACKETS.md) separate first-route requirements from feature-triggered adapters. Lots/grafts, multiworker construction, battlefield geometry, reciprocal institutions and temporal carriers follow only their selected consumers. All nineteen roster families need no simultaneous launch. Later coverage closes every reviewed required campaign/mechanic ID, not merely representative imports.

[Runtime findings](../runtime-efficiency/REPORT.md) retain historical scheduler improvements but provide no current latency measurement. Keep storage/backend rewrites off the critical path. [Token TF01–06](../token-efficiency/REPORT.md) supports claim-based retrieval, scene-specific context and revision-bound review receipts, with no measured savings. [Authoring tools](EASE_OF_AUTHORING.md) apply those rules to package diagnostics, recipes and packets. Input/delivery status is in the DAG and [checkpoint](CHECKPOINT.md). Checks here establish document/graph consistency only; native gameplay, save/failure, browser and human acceptance remain open.
