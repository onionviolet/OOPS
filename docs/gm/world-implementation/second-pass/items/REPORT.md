|---|---|
| A. Exact native item use | Distinguish fungible counts, condition/provenance lots and unique specimens only where needed. Bind bag/chest/equipment/cargo/custody consumers to one owner. | D. Research and exceptional sources | Link blueprint/trial evidence to reproducible functions. Artifacts activate actual sensing/protection; consumables deploy real objects. Containers conserve contents; manuals/keys separate knowledge and access from possession. Living/unique sources retain particular rules and superiority. IT06/IT09/IT12/IT13. |
| E. Qualification and simplification | Nest an ordinary bulk chain and one original repairable instrument inside the selected campaign qualification. Batch known safe work; keep inspection subordinate to existing inventory/equipment UI. No universal rarity conversion, second inventory, full thermal solver or nineteen-world prerequisite. IT10. |
