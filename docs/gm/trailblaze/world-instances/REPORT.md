## Actual world-instance interface

All data is plain JSON. Functions clone inputs for proposed outputs, use no DOM/timer/storage/native singleton, and never advance the actual joined clock. Invalid record/binding shapes throw; valid stale/backward/already-settled requests return `allowed:false` with reasons and no proposed instance. A successful plan returns an expected revision/time guard and `nextInstance`; Engine must compare those guards and its global sequence before durable publication.

| Export/signature | Concrete behavior |
|---|---|
| `WORLD_INSTANCE_SCHEMA` | Detached record version1; not a change to expansion engine schema5. |
| `validateWorldDefinition(definition)` | Frozen world identity/revision, regions/layers/sites, scalar initial facts and declared unique claim keys. |
| `validateWorldEndpoint(endpoint, instance?, definition?)` | Requires `{worldId,instanceId,regionId,layerId}`; when binding is supplied, both instance and definition are required and validated. |
| `validateWorldInstance(instance, definition)` | Exact supported fields, definition revision, site/fact domains, scalar types, claim times/holders, actor references and freeze-clock policy. |
| `validateWorldVisit(visit, instance, definition)` | Actual bound endpoint, separate visit revision/status, entry/exit chronology and reconciled instance time. |
| `validateWorldRecords(records, bindings)` | `records={definitions,instances,visits}`; `bindings={actorIds,externalInstances}`. Rejects duplicate IDs, missing actual actor/parent/definition bindings, nesting cycles and overlapping visits of one actor. External instances contain only `{id,worldId,parentInstanceId}` references. |
| `createWorldInstance(definition, seed)` | `seed={id,continuityId,eraId,playedAt,parentInstanceId?,actorIds?}`. Creates an explicit new history, empty claims, elapsed0 at actual played time. Never call as a reentry/load initializer. Collection validation guards duplicate history IDs. |
| `createWorldVisit(instance, seed, definition, bindings)` | `seed={id,actorId,endpoint,playedAt}`; `bindings={actorIds,visits}` contains the actual existing owner IDs and complete visit ledger. Records an already-authorized arrival; grants no passage, body, stock or source. |
| `planWorldClock(instance, request, definition)` | `request={playedAt,visits,expectedRevision?}`. Uses actual joined played minutes, unions occupied visit intervals once and reports `advancedBy`/`absentBy`. No wall-time catch-up or timer. |
| `planWorldDeparture(instance, visit, request, definition)` | Same clock-request shape; actual visit must appear in the supplied ledger. Proposes final local clock and an ended `nextVisit`, preserving history/claims/references. Does not authorize escape or native relocation. |
| `planWorldInstanceUpdate(instance, request, definition, bindings)` | Explicit `expectedRevision`; optional `facts`, `sites` booleans, `settleClaims=[{key,holderId}]`, `attachActorIds`. Only declared domains/existing actor owners; unique receipts cannot reset/reward again. `bindings={actorIds}`. Cost/reward publication remains Engine-owned. |
| `worldInstanceView(instance, definition, knowledge)` | `knowledge={discovered,identityKnown?,clockKnown?,factKeys?,siteIds?,actorIds?,claimIds?}`. Unknown instance returns only `visible:false`. Reveals only explicitly selected known fields; full definition/history IDs appear only when identity is known. |
| `WORLD_BINDING_SCHEMA` | Authoring-manifest version1; adds no saved state or new stock/site/claim owner. |
| `createWorldBindings(definition, options)` | `options={instanceId,worldFactPrefix?,siteBindings?,claimBindings?}`; optional maps are local IDs to registered IDs. Generates complete namespaced fact/site/unique-claim maps; default site/claim IDs are `<instanceId>.<localId>`. |
| `validateWorldBindings(manifest, definition, instance?)` | Closed JSON schema, matching frozen definition/revision/world/instance, complete non-aliased maps and fact prefix. Optional instance validation binds the real record. Does not prove native owner availability. |
| `worldInstanceFacts(instance, definition, manifest)` | Read-only `world.<registeredFactKey>` scalar predicate projection from one instance fact owner. This is private runtime input; player UI still uses discovery-filtered `worldInstanceView`. |

Actual instance fields: `{schema,id,definitionId,definitionRevision,worldId,continuityId,eraId,revision,parentInstanceId,clock,sites,facts,claims,actorIds}`. Clock is `{elapsed,observedAt,unit:"played_minutes",absence:"freeze"}`; sites contain only `{open}`; claims contain only `{holderId,settledAt}`. Inventory/body/equipment/quests are deliberately absent. Actor IDs are references, including historical associated people, not duplicated actors or proof of current presence.

Actual visit fields: `{schema,id,revision,actorId,instanceId,endpoint,enteredAt,exitedAt,status}`; status is `active` or `ended`. A conventional actor has one active visit; genuinely separate bodies need distinct actual actor IDs with any shared mind/resource pool owned by the traveler-profile lane.

Arrival order: reconcile the target's absent clock to current joined time with the complete existing ledger, then record arrival at `clock.observedAt`. Departure plans accrue active time before ending the visit. Reentry uses the same instance object/ID and new visit ID. Closing a route leaves the interior record and active occupants intact; it does not itself freeze an occupied interior. Absence freezes local elapsed time when no visit occupies it. Closed-browser loss/aging, time ratios, death/reset and automatic nesting are unsupported/unselected.

Until that exists, settle/cancel all local reserved work before departure and pause absent controllers/events; simply changing an `absence` label does not pause joined-clock jobs.
