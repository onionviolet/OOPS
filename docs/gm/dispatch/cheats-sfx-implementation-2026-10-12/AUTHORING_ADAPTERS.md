2026-10-12. Scope follows NEXT_CYCLE.md. Exact editors and defaults remain proposals. This ledger describes actual candidate adapters, not a universal authoring promise. Sealed definitions and undiscovered actor facts are never enumerated here or in author pickers.

Next connected authoring increment after C3 should use AU3/AU7: an original optional activity pack draft with real native visit, condition/duration/settlement, cancel and save behavior. This is a proposal within the broad authoring direction, not acceptance of an exact fictional world. Preserve existing private packs and registration owners. Later starts/items/NPC editing each needs its own adapter gate rather than an enum picker.
