## KL10: observation provenance, defaults and world dials

**inferred (proposal, W1):** use the pipeline `native outcome → authorized observer receipt → knowledge reducer → safe projection → every presentation channel`. Authorization checks observer, presence/channel, world, subject, fact and disclosed precision. Only a scoped measurement/appraisal/status adapter, including a genuinely granted skill measurement, may read true values for a fact it explicitly grants. The ordinary experiential reducer never accepts hidden `xp_value`, raw enemy stats, hidden tags, combat RNG, future attack choices or undisclosed truth revisions. Publicly awarded XP can be recorded as an award; it cannot be reverse-engineered into a threat/stat input. Basis: W1 (`NEXT_PARTS_2026-10-15.md:212,252–254`), LR2/LR4 and receipt-only drop precedent (KL04).

**stated (updated 2026-10-16):** the ordinary-world default is experiential: impressions and `???`, with exact opponent numbers learned (`docs/USER_VISION.md:4417–4423`; Round 11 LR11 at `NEXT_PARTS_2026-10-15.md:493`). **inferred (proposal):** the following are legitimate receipt types, not a claim that the current engine emits them all. Numeric damage already disclosed to the player can be recorded, while concealed damage in another world stays concealed. `src/models/combat.js:420–495,518–523` shows damage rolls, block, critical and mitigation; an observed result is not the base stat that produced it. KL25–KL29 below add the route order, LR8 exception and multiple-source contract.

## KL12: stable estimates, changed truth and lifecycle

**inferred (proposal):** resolve an estimate when its first legitimate evidence/method receipt commits, and save its result. Build its key from observer/life scope, world scope, apparent or recognized subject scope, fact key, public-input revision and estimator revision. Use the existing saved stream root with the pure `unitDecision`/hash helper, not combat/loot draws, `Math.random`, a per-render draw, hidden variant ID or truth plus random error. Existing pure and mutating RNG boundaries are `src/seeded_streams.js:15–17,53–84`; persist the resolved result so later formula changes cannot reroll it on reload/import. Old saves without a seed use the documented stable fallback precedent at `src/main.js:6832–6834`; lazy creation occurs in the first authorized transaction, not during load/render.

**inferred (proposal):** record acquisition does not require a random estimate. If only “large” is authorized and no learned calibration connects size to damage, show “large” and `???`, not a random number. A reversible first implementation can leave unsupported estimators absent. A new public observation can revise a range, but repaint, hover, pin, sort, theme, text size, reload and import cannot. Two individuals can share a species prior yet differ when there is individual evidence. No exact estimate-clamping against hidden truth, including after taking a new hit. Basis: W1 and R14 E7 (`R14_FOLLOWUP_CONSIDERATIONS.md:160,244–247`).
