CY · Six genre-inspired cheat families. Static visual proposals with original CSS/SVG ornaments, synthetic facts and no game commands. Each family has popup section, notice and center at real 14px and 21px over matching R14 shell pixels, plus a 1920×1080 center at 21px. The system family includes an awakening beat and an immediately readable reduced-motion form. Appearance plain is illustrated once.

The old counter is absent from current source. The inspected R14 shell images still contain it, so these composites replace the footer with a labelled static reconstruction. They are not fresh game captures. Motion choreography is described in the report, never played in these static exports.
