## W1: profile inputs, not universal plot laws

An arc profile declares world/instance/continuity/era/source cutoff, supported goal/action operators, cast reservations, available institutions/routes, knowledge channels, time/retention policy, relationship laws and local risk/frequency adjectives. It can be permissive, inexhaustible, scarce, dangerous, private, ceremonial, rapid, renewable, competitive or peaceful. Frequency and expenditure follow actual causes and world laws; a fixed universal once rule cannot substitute for them.

| Class | What P12 generates | What stays authored / qualified | Concrete proposed slice |
|---|---|---|---|
| W1a Book canon | Incidental requests, coherent preparations, background actor plans and causal aftermath within the selected era | Source event graph, canon identities/roles/laws, exact hinge conditions, known source horizon | A qualified OC repair commission attaches between existing events; changed supply can alter only declared dependencies |
| W1b Anime/manga | Same, with work/adaptation/route-specific capabilities, perception and institutional access | Manga/anime/film routes remain separate; power names do not define universal execution predicates | Support survey → qualified evidence → real evacuation/preparation, with a supported ordinary alternative |
| W1c Original | Larger cast/goal/incident/relationship variation under original authored laws; background generation may create new legal initial causes | Physical/social operators, functional consumers, map nodes and any fixed campaign facts | Village shortage → funded repair → later reciprocal job; no new realm required |
| W1d Tabletop | Generated clients, factions' bounded plans, encounters and downtime chains from selected rules plus setting | Rules edition, setting/era/adventure continuity, GM-authored premises, actual spell/risk/resource rules | Client request can be solved by equipment, skilled assistance, a qualified spell or negotiation; no mixing editions |

Reference techniques do not override a world. A quality-based progress loop fits an academy term, but its actual calendar/learning must still be correct. A rivalry pattern works in a peaceful world as competition or disagreement; it need not become a murder plot. A powerful hero can finish an ordinary problem easily and move to other goals without automatic enemy scaling.

## W4: canon after intervention, time and source revision

Follow [TIMELINES T1–T5](../../../../TIMELINES_AND_DIVERGENCE.md#implementation-planning-starts-histories-and-parallel-worlds-2026-10-11): world, continuity, era, instance and visit are different identities. A canon event is expected when its real causes still hold. The earlier role-substitution/inertia palette cannot fabricate a replacement actor, body, unique artifact or motive solely to force an ending. If a genuine redundant plan can still cause a similar event, give it its own actual cause refs and means. P13 owns those event/reservation bindings in [RULES C1–C4](../p13/RULES.md).

[Intro rounds 9–10](../../../../INTRO_FLOW_CONSIDERATIONS_2026-10-13.md#round-10-story-world-timelines-and-branches-2026-10-14) propose fresh canon, continued branch and bookmarked-moment starts plus source revision/horizon. These are proposals unless separately accepted; P12 does not install a default or branch picker. A continued branch retains its own arcs/cast/claims; a fresh instance begins without importing old affection, wages or privately solved mysteries. Player-layer knowledge requires an in-world route for the new character. A fictional reset declares carrier retention for goals, matter, body, memory and relationships independently; it is never triggered by file import.

A newly read chapter can extend future qualified operators but cannot silently revise active graph, hidden truth or accepted terms. Beyond a source horizon, motive-driven original extension must be labeled as such; it is not newly certified canon. No source pack is copied into public runtime by P12.
