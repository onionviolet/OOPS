## Additional cross-domain combinations

These compose existing rows rather than add competing stores. **M16: changing ownership** joins N2/M9 so inherited, donated, confiscated or loaned goods retain identity and a valid cause. **M17: competing interpretations of progress** joins N11/M5 so certification, competence and public credit can disagree without replacing actual skills. **M18: accessible expert assistance** joins M1/M4/N6 so the player can request a short recommendation while optional advanced comparisons remain reachable. **M19: deferred consequences with evidence** joins D8/N1/M6 so a later result reads a retained cause, never reconstructs gameplay from log text. **M20: local technological diffusion** joins P6/M4/N5 so a new process spreads only through actual teaching/material/communication means.

Each combination costs medium/high multi-owner joins; first select one supported action and two authoritative cause/consumer references. Its gate is an observed changed consumer plus exact custody/knowledge/receipt import and no extra owner. This is additional scope available for selection, not a request to build all combinations now.

## What not to mistake for a limit

A first slice with a few authored packages is an evidence target, not a permanent world rule. Local profiles can support many repeats, cheap services, unusually generous rewards, inexhaustible resources, strong powers and rare exceptions. Unsupported first-slice combinations stay design candidates with explicit dependencies. Retention bounds protect saves and actionable references; they must not become fixed gameplay once limits. New causes can renew work under each world's own adjectives.
