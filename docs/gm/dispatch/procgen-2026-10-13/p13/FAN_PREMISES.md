# Fan premises as composable generator templates

2026-10-14. **PROPOSAL ONLY.** These are generic analytical patterns, not copies of a fan author's scenes, accepted AUs or claims that a genre convention is canon. Credit a specific fan work/creator/version when actually adapting it. TTKS B3 is a pinned fan source, not JJK canon. [RULES](RULES.md) governs source/anchor/reservations; [P12 structures](../p12/STRUCTURES.md) owns plot assembly, [P15 authoring](../p15/AUTHORING_PIPELINE.md) owns prose production and [P16 other lives](../p16/OTHER_LIVES_AND_SELVES.md) owns viewpoint/identity extensions.

## FP1: template shape and generation

A template supplies a compatibility-constrained premise, not a randomly prewritten ending:

```text
PremiseTemplate = {
  id, revision, creditedSources[], evidenceMode: INFERRED,
  allowedWorldProfiles[], canonVersionRef, anchorRef,
  entrant: {identityKind, bodySourceRefs, cohort, priorHistoryRef},
  changedEdges[], changedLawRefs[], preservedReservations[],
  knowledge: {carrier, editionHorizon, claims, inaccuracies, disclosurePolicy},
  initialMeansRefs[], realObligationRefs[], actorGoalRefs[],
  permittedAttachmentScopes[], watchedPrerequisites[],
  generationInputs: {originalRoles, needs, knownEvidence, places, availableRoutes},
  arcGrammarRef, textGrammarRef, allowedContinuationRefs[],
  commitmentPolicyRef, clockResetBranchPolicyRef, compatibilityReviewRef
}
```

Changed edges are keyed `add|replace|remove` operations with validated actor/relationship/role references, not E6's unconditional appended arrays. A template composes with another only after resolved overlays pass law, identity, role and custody checks. Changes can be powerful, convenient or cheap where their premise allows; no required balancing curse or compulsory tradeoff between every benefit.

Actual creation pipeline: select compatible source/anchor and premise axes → bind real current people/needs/means → materialize original missing background roles only inside approved scope → P12 constructs a new causal plan/beat graph from supported operators → world-law checks admit it → freeze generated structure/cast/terms → P15 renders original safe text. Later actions update receipts and generate a new supported plan when causes change. This creates content and consequences; random labels on a fixed hand-authored ending do not pass the gate.

## FP2: pattern library

| Template | Entry and generated content | Canon constraint / observable gate |
|---|---|---|
| SI / self-insert | Retained outsider perspective in an authored compatible body; generate local learning, employment, friendships and interventions from scoped remembered claims | Player memory is not automatic character knowledge. A genuine source/entry carrier supplies only its declared memory. Observe one forecast tested/revised and one ordinary useful action. |
| OC / original character | New original pupil, artisan, civilian, support specialist or source-eligible adventurer, with fitting history and means | P7/P9 cohort/source/kinship rules; no surprise canon heir or copied protagonist power. One original need creates a new funded opportunity with a remembered consequence. |
| AU | Change relationship, admission, sponsor, start era, local law, outcome or institution as an explicit overlay; fill compatible consequences | Pin changed edges/laws and preserve untouched facts. Show one affected event and one unchanged independent event; AU is not blanket waiver of all source rules. |
| Fix-it | Knowledge/motive prompts a genuine intervention before a vulnerable prerequisite is committed; create preparation, evidence, rescue and aftermath | Attempt, prevention, mitigation and replacement danger are separate. Show actual changed prerequisite and outcome; do not guarantee happiness or erase independent actors' motives. Powerful successful rescue stays possible. |
| Villain-side | Work/live within a rival, antagonist or feared institution; generate administration, supplies, household, loyalty, disagreement and independent aims | “Villain” is an attributed viewpoint. Canon actor constraints, public evidence and private causes remain separate. Show a useful supported job plus a consequence recognized by the right observer; no universal moral score or forced betrayal. |
| Background-character life | Ordinary career, relationships, making, care and travel, touched only by canon events whose reach actually overlaps | No obligatory protagonist encounter or escalation into chosen-one identity. Show an autonomous local goal, ordinary closure and optional continued life. Ignoring canon adventure remains playable where local means permit. |
| Canon embodiment / alternate perspective | Authored canon actor snapshot and known current methods, then generated ordinary choices around actual source commitments | No generated canonical biography. Pin exact actor/body/control/knowledge and premise; played differences are earned divergence. Next fresh counterpart does not inherit changes without continuation. |
| Relationship / family AU | Explicit altered kinship, friendship, mentorship, rivalry, partnership or household; generate coherent obligations and access | Directed bonds require a source/AU edge and willing reachable actors; relationship is neither mind control nor source power. Do not invent secret parenthood through incidental name generation. |
| Prequel / aftermath | Earlier era or source-end snapshot, ordinary institutions and emerging/recovering plans | Earlier characters lack later knowledge; later cast/stock reflect completed history. New text is original continuation, not alleged canonical sequel. |
| Other returner / imperfect reader | Authored memory carrier with a different cutoff or prior branch; generate competing predictions, interventions and evidence disputes | Preserve each actor's carrier/means. Agreement is not independent corroboration if both read the same source. Show a changed plan based on new evidence, not omniscient rivalry. |

Templates are combinable: background OC + SI + relationship AU; fix-it + villain-side job; post-canon + ordinary life; canon embodiment + a source-supported loop. Stronger/stranger options remain reachable with an explicit supported premise rather than being excluded because they cost more to model. [P16 loops](../p16/LOOPS_AND_RESETS.md), [crossovers](../p16/CROSSOVERS.md) and [player authorship](../p16/PLAYER_AUTHORSHIP.md) own their full contracts.

## FP3: concrete synthetic composition

An original apprentice at a chosen academy anchor learns of an actual unsent inspection notice through ordinary work. Generated inputs bind a real issuer, recipient, dispatch site, funded job and two compatible transport/service routes. The template can be background OC; an SI variant additionally holds a fallible forecast about why the notice matters. A villain-side variant changes employer/aims, not the letter's truth.

P12 creates a plan whose usable actions include deliver, request qualified help, investigate, delay, refuse or take another funded job as available means allow. The committed route changes actual recipient knowledge. That recipient's next supported inspection changes an event prerequisite. If the old canon encounter becomes inapplicable, surviving actors may produce a new response. P14/P15 tell only the known sequence. There is no predetermined “hero saves school” result, universal fixed repeat cap or fabricated grateful relationship.

Minimal materialized output: stable original role/person references, source/anchor/branch refs, premise change receipts, one plan with at least two viable routes when available, funded request/settlement references, dependency deltas, safe known text and explicit unknowns. Counts are proof targets for the first slice, not permanent world limits.

## FP4: failure and acceptance

Reject unsupported role/unique source cloning, illegal overlay order, future biographies, actor knowledge without a carrier, missing real rewards and sealed truth in template labels. Rejection is an implementation qualification result, not a declaration that no future authored route can exist. Offer a fitting ordinary route or mark the option awaiting its source/adapter.

Future gate: same source/seed/context yields the same committed premise and original content; different meaningful inputs yield mechanically distinct supported plans; preview/reload do not reroll; intervention/abstention preserve source constraints and changed causes; Save/reload/import retains cast/custody/knowledge, text and next draw; source/fiction review and rebuilt desktop play remain separate. All NOT RUN here.
