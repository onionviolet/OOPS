## L1: generate from differences between attempts

A reset's interesting output is not another random deck. Generate new content from remembered experiments, changed preparation, altered arrival times, different witnessed relationships, bypassed hazards and interference by other eligible returners. Stable ordinary identities and baseline facts make discoveries usable. A new intervention can cause a new request even when the baseline is identical. Source-supported stochastic variation, moving anchors or cheap repeatability remain possible through local rules.

Conceptual reset record: law/source revision, trigger, anchor snapshot, affected endpoints/actors, cycle identity, retention map, pending work disposition, external exports and observers, RNG policy, prior cause archive and new committed causes. The boundary is one durable transformation, never a render, file load, import, browser closure or hidden reroll. Each state owner participates explicitly; `commitCampaignTransition` does not restore all history ([audit F4](LIVE_AUDIT.md)).

| Domain | Questions a local law must answer | Possible generated story |
|---|---|---|
| Identity/body | Same person, counterpart, new vessel or restored body? What actual body/source works now? | Remembered expert needs mundane tools in an unfamiliar body |
| Memory/knowledge | Which actor and carrier retains which observation, method and uncertainty? | Warn a friend who has no reason to trust this cycle's stranger |
| Matter/funds | Restore baseline, retain selected matter, explicit duplication or external escrow? | Reacquire a sample, or study a genuine exported anomaly |
| Relationships/claims | Reset local mutual history, retain another participant's memory, preserve outside claims? | Negotiate past an appointment without fabricating old affection |
| Generated people/lore | Baseline resident IDs fixed, fresh admissions caused anew, truth fixed or locally mutable? | A rescued resident's different plan creates a new cohort encounter |
| Draws/clock | Replay baseline stream, keep a carried stream or use cycle-keyed new draws where allowed? | Recognize a routine, then alter a causal branch rather than reload |
| Authored work | Physical edition erased but remembered method retained? Reader actually remembers? | Rewrite a useful book and teach it again with new evidence |

These are alternatives and combinations per domain, not a menu forcing one universal reset model. Explicit world copying can generate matter when that is its actual law. Otherwise a copied payout/export is a defect; transaction integrity is not a once-per-life content ban.

## L3: first connected slice

Original voluntary rehearsal pocket, separately labelled adaptation fixture: commit one authored baseline with a generated ordinary request and one measurable experiment; record the result through a declared memory carrier; reset; restore baseline matter and the nonremembering requester's relationship; use retained knowledge for a different successful preparation. Repeated cycles remain reachable without a fixed count limit. It demonstrates remembered content generating a new actionable inquiry, not merely a rerun button.

Cost high. Dependencies: isolated snapshot/reset owner, genuine knowledge carrier, actual stock/experiment consumer, P1 streams, P11 context and P12 changed-cause binding. Select one world/body and no external cargo first; generalized inter-world resets are not prerequisites. A nonlethal voluntary trigger is an original fixture choice, not claimed as any reference's canon mechanism.

## L4: deeper reachable stories

Multiple remembering actors with incompatible plans; a loop resident who discovers evidence but not the reset truth; multi-decade regressions rebuilding institutions; current-body apprenticeship informed by earlier expertise; objects/libraries outside the reset; partial rewinds; repeated ordinary peaceful lives; cumulative art; resetting a disaster while retaining a promise; reaching an ending that changes the anchor. Each needs the relevant carrier/endpoint rather than an artificial penalty to prevent strength. Other selves attach through [OTHER_LIVES_AND_SELVES](OTHER_LIVES_AND_SELVES.md).

## Conflicts and acceptance

Timeline's older B4 cost language is a proposal and cannot impose compulsory tolls or limited uses on every source. Later T5 and user world-adjective direction allow powerful/cheap variants. P9 freezes ordinary baseline outputs but allows qualified new stochastic outcomes; COMMON's reload rule prohibits file-based rerolls, not explicit fictional reset laws. Intro DV10 lazy generation cannot choose a baseline person's identity from observation time after several cycles; bind the creation context and revision.

Future gates, all OPEN: identical baseline restore where declared; changed intervention produces changed content with actual causes; carrier-specific knowledge and rebuilt body means; exact pending/reset/completed import; no duplicate exterior cargo unless the law expressly creates it; streams/cause IDs survive revision; failed write restores neither half a world nor consumed RNG; unknown lore and secrets stay sealed. Pause/continue at reset boundaries follows the chosen clock owner, not wall time introduced here.
