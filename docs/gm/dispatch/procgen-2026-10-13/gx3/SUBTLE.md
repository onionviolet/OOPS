Native A→B→player route demonstrates delayed attributed disagreement and correction from later evidence; isolated C knows nothing. |
| A4 GS4 two lots | For a future original physical law, resolve source variation then execution variation once per admitted batch, choosing a coherent vector with preserved mass and declared process response. Validate before spend. Same source/precise process can intentionally yield identical lots; heterogeneous lots stay separately selectable. Do not mutate P2's old profile/dose or merge knowledge across lot IDs. Native paid acquisition→two actual batches→observed useful difference→repeat, exact pending/final Save/reload/Import and split/merge conservation are required. |
| A5 GS7 first consumer | Query earliest qualifying settled receipt using P38 scope and P14 query pins, then atomically publish the index/cursor. Replayed receipt emits no second first notice. All five gates are future and NOT RUN here. Density, novelty and rare-event weights are local proposals. A rich, prolific, inexhaustible or consequence-free world stays possible; storage and transaction controls never manufacture a universal anti-abuse once rule.
