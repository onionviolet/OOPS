# Carrying, condition, storage and processing at source

PROPOSAL ONLY. [Audit F11/F12](LIVE_AUDIT.md): inventory keys/transfers, material size and real shipping escrow exist. They do not establish global carrying mass, spoilage or automatic storage conditions. P6 owns [repair/salvage](../p6/REPAIR_SALVAGE.md), [tools/textiles](../p6/TOOLS_TEXTILES.md) and process laws. Living-atlas P2/P4/L05/L11/L16 own condition distinctions. Do not turn all ordinary existing stacks into decaying stock.

D1: Author which resource families have relevant transport/condition choices and what container/route/site functions support them. Generate harvest condition and permitted package variability, not random container laws. Carrying can use load, bulk or awkward-part handling with actual body/cart/pack means, each a distinct dimension. Start opt-in per generated batch or expedition. Exceeding a declared capacity can split loads, return earlier, hire a carrier, cache goods, install storage or process nearby; no arbitrary universal inventory deletion.

D2: Freshness, moisture, live viability, contamination, charge and temperature sensitivity are separate conditions. Select only fields with useful consumers. A dry herb might store stably but lose a supported fresh-part role; a viable culture needs substrate/site; a wet board might require seasoning for one fit consumer. New preservation methods have explicit input costs, transformations and waste. Do not present abstract game drying/fermentation as real food-safety or medicinal instructions. Preservation improves an optional chain without making daily maintenance or feeding mandatory.

Storage has actual receiver identity/capacity, custody, shelter and supported condition law. The same batch transferred into a supported cool receiver changes future rates only at a recorded boundary; it does not reset elapsed age. Unsupported ordinary chest remains legacy storage, with no invented preservation benefit. Time-suspending storage works only under a sourced/explicit law (Soldier M04), not whenever a magical bag has a premium name. A bag that loses contents moves stock to a recovery/unavailable location when its law conserves identity (LOTM/COI M16); it must not manufacture replacement stock.

D3: Refining at source is a real tradeoff: remove gangue or water under P6 process rules to reduce carried bulk, spending fuel/apparatus/labor and leaving accounted residue at the site. Hauling raw feed preserves alternative processing routes and whole specimen geometry. Portable equipment, a hired processor and return trips stay available where supported. A field press never auto-unlocks all refiners or silently destroys the chance to obtain another raw batch.

Knowledge: weigh/inspect shows scoped load and observed condition; label estimated preservation window by known method/context. Truth controls actual change even when the window estimate is poor. Unknown imports retain their state when no condition law can evaluate them; missing data is not universal stability, nor a license to decay them arbitrarily. Source/processing records travel with batch; a familiar name is not proof of freshness.

Idle/persistence: queue collection-return-storage-refine stages with explicit receiver, overflow and shortfall policies. Persist reserved cargo, custody, cached lots, recorded condition exposure, deadlines and installed equipment. Event-driven advancement crosses supported boundaries exactly; save/reload/store-open does not reset age or reroll condition. Closed-browser simulation is deferred initially.

First slice R4-A: a fresh original herb batch fits a declared small expedition receiver. Bring it home directly or pay for field drying; store both under supported conditions and make two valid P2/P6 uses with different actual outcomes. Both choices can be used sequentially; ordinary old herbs remain unchanged. G1 capacity units, water/residue accounting and segment equivalence; G2 natural gather → carry/preserve → store → useful consume plus receiver-full/cancel; G3 carried/stored/cached/escrow/condition roundtrip; G4 no global decay or silent bag changes; G5 readable useful storage and load choices. All OPEN.
