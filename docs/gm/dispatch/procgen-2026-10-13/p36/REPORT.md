Rows name actual resource costs when physical action occurs; cosmetic text costs no coin/stock. Runtime work is indexed by relevant person/object/cause or boundary, not a scan of every receipt/NPC each frame. More templates increase authoring and localization coverage, not mechanical choice count.

D3: Commit a new utterance only at a real admitted meeting, observation, account arrival or outcome. The host stages updated owners, U, draw allocation and sequence before one durable publication. Revalidation rejects changed participant, stale quote, hidden/unresolved slot or insufficient stock before spending. Post-save render failure does not refund already published goods. A neutral complete fallback has no extra fact or draw. P15 grammar paths select variants from the committed line seed; final text/revision survives content edits. Previews, tooltips, ordering, reload and Import never select another variant. Duplicate cause acknowledgement is idempotent; fresh later kindness/contact remains possible under each world's law.

Keep exact chronicle claims limited to retained known evidence and label enrolled coverage. If a meaningful reference cannot be safely retained, reject that new admission atomically with honest explanation, not drop old facts, reroll or impose a universal once rule.

D5: Ink receives a reviewed, explicit known variable map and supported response bindings, not arbitrary raw world truth. Existing compiled content/runtime hashes and cursor formats remain pinned.
