These sets are optional ceilings, not a request to dispatch subagents now. No P39 worker was launched, no port opened and no runtime reservation transferred. Parallel implementation is safe only in disjoint new file areas with published frozen interfaces; merge and acceptance are sequential. The root direction “finish one playable slice before starting the next” means no second independently integrated gameplay slice begins before the previous checkpoint; sibling preparatory code/data can run in parallel when root authorizes it.

## BJ2.2: handoff data needed for an implementation lane

A selected lane supplies its exact base commit and owner revisions, exclusive path reservation, descriptor read/write/stream/clock declarations, expected shared joins and tests/harness with evidence labels. Root checks live dirty state and workers before granting writes. A lane that discovers a missing native capability returns a concrete adapter proposal to its owner while continuing independent fixtures. It cannot add that join to main/save/simulation itself merely because the descriptor needs it.

One root writer adopts staged domain deltas and confirms import order, pending/final restoration, draw continuation and UI recovery. Losing a writer or switching chats requires an explicit ownership handoff; this roadmap does not transfer authority. P39's own footprint is only this folder.
