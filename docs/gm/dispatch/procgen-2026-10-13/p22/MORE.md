## Contradictions to preserve during selection

**R22.2:** root A3 describes readable future draws. A saved RNG stream alone does not determine all future events: eligibility, commands, cast, content revisions and external native randomness can change the result. K1 forecasting must state its assumed trace and supported scope. P13/P16/P18 own real forecast/time mechanics; a dev preview cannot silently certify prophecy.

**R22.3:** E2/E5 contain different draw/gate contracts and E2/P3 retain authored once metadata. D9 already names this seam. Tools read the actual integrated scheduler policy and annotate interventions; they neither unify it by assumption nor generalize old once records into limits on all generation. [P3 report](../../../../../.claude/worktrees/proc-p3-storylets/docs/gm/dispatch/procgen-2026-10-13/p3/REPORT.md) is stated branch evidence, not main-runtime proof.

**R22.4:** E6 append-style inheritance/fixed-fact rules conflict with safe replacement rosters and causal divergence discussed by P7/timelines. K3 composition requires explicit keyed overlays and selected natural-course rules; no optimistic blending.

**R22.5:** a “browse every card” requirement includes sealed content, while Weibao must not see its truth outside discovery. K1 offers complete ID/status coverage and agent-only semantic review, with human safe rendering. Dev-only is not a secrecy exemption. Hidden names, per-secret counts and failure reasons need the same projection rules as prose.

**R22.6:** same-origin import probing is useful real-loader preflight (`src/import_probe.js:1-33`), but it deliberately handles a supplied save and shares origin resources. It is not evidence of a private-save-free director bootstrap. K1 uses only synthetic/test envelopes and separate storage/profile.

More tooling can remain available without becoming a prerequisite for every story. A one-file K2 request and a passive K5 feedback export can work before the full editor, pack switching or replay UI. Each integrated slice still ends in one reviewable playable result.
