| ID | Shared rule | Concrete requirement |
|---|---|---|
| C8 | A product carries only supported representations | Proposed envelope references immutable definition/law/resolver revisions, composition, assembly, pattern and exact identities as applicable. Mutable instance holds custody, condition, dose/charge, installed location and lifecycle. Economic names/knowledge are not physical identity. No numerical save schema reserved by P6. |
| C9 | Inputs are allocated from actual means | Roles specify exact/family/profile selector, unit/amount and consumed/retained/installed policy. Unique tokens/people/parts and divisible fractions have different ledgers. Revalidate body/source/access/site/stock and exclusive custody before admission. |
| C10 | Process and skill cause the result | Resolve ordered finite operators over a frozen snapshot. Skill controls specified execution/yield/tolerance; apparatus/source enables capability. Previews consume nothing; execution variation uses a named saved P1 scope and is committed with the result. No extra ignorance danger roll. |
| C11 | Knowledge is an observer record | Separate unobserved truth from unresolved model data. Truth resolves even if unknown; missing required model values block or use a declared fallback before spending. Observation has actor, subject/property/protocol, basis, confidence, time and scope. Unknown names/value/sort/recommendations never expose sealed effect truth. |
| C12 | Generated output is consumed | Every output declares a real native stat, work verb, treatment, worker, installed capacity, harvest, teaching, audience or trade adapter. A generated label is not a consumer; texture can be labeled texture. Conservation includes outputs, residue, emissions, retained tools and explicit magical source/sink. |
| C13 | Queued creation is durable work | Bind chosen method/revision and exact current stock at admission; reserve apparatus/site/receiver and real worker means. Store stage/next boundary/escrow/draw receipt. Repeats resolve new actual inputs under an explicit selection policy, stop on shortage and settle each occurrence once. Failed writes change nothing; post-write render failure cannot refund committed matter. |
| C14 | Time and cancellation follow the family law | First slice eligible played time, pause unchanged; sleep/travel applicability explicit, offline initially deferred. Save fractional progress. Refund only untransformed escrow; irreversible boundaries publish lawful partial material/structure, never recreate destroyed stock. Existing refund-whole-job adapters remain unchanged outside new scope. |
| C15 | Restore is complete and compatible | Save resolved generated truth plus revisions, not seed alone. Validate definitions before all holder/job/equipment/effect references, preserving meaningful traces. Old absent owners stay absent and unchanged. Explicit migration or retained interpreter for old versions; unsupported imports reject before replacing the prior save. No silent reroll/drop-to-zero repair. |

Proposed envelope is a contract description, not a second runtime owner. Stable type ID may group equivalent immutable products; mutable object ID distinguishes condition/installed identity when a consumer needs it. Quantity/owner/label normally do not define type. Preserve meaningful provenance/structure/recipient when queried; keep irrelevant receipt history outside stack identity. For P2 revision1 preserve its existing recipe-based identity semantics. Each extension declares equality, decoder and economic/use handling before accepting new fields.
