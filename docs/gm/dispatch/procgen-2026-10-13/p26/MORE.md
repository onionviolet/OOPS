## M2: compact evaluation questions for a selected batch

A structural batch review should distinguish **law fit, causal plausibility, interesting available choices, world voice and remembered consequence**. Passing JSON does not prove any of those. Reuse P15 QA1–QA14 with only justified checks, and P18 for larger traces. Add one source counterexample, an unchanged independent event, a missing-cast case, a valid refusal, a failed publication and a same-receipt replay. For rare/gag/first content, include its special deterministic/lifecycle checks from HUMOR_AND_NOVELTY. Do not demand a whole new universal framework before one ordinary scene works.

Natural player acquisition, seeded-native branch coverage, source contracts and human fiction acceptance remain separate. Target future UI proof at 1366x768 and 1600x1000; mobile deferred. Pure documentation work here runs no tests, server or build. No proposed slice is an instruction to resume another lane or create simultaneous writers.
