| Preflight | Scope |

The existing visitor is a registered client without a provisioned simulation body; no claim is made that this slice adds a new scheduled body. |
| Consumer | At the existing Blackthorn office, the instruction enables a native fifteen-minute runner job. It reserves two pence, returns them on cancellation, and saves the signed dispatch correction. Duplicate orders stay blocked. This is an ensuing action with cost and state, beyond the concluding report. |
| Clock | Existing `castCalendar` function moved unchanged to a leaf, with its host export retained. Next day is the local date after the saved session, not a delay after opening a panel. Visitor window 09:00–11:00; late or declined clients leave the ledger route available. |
| Ring | Producer, consumer, failure, persisted facts/notes and ordinary office UI. Missing old session dates disable the dated visit but preserve the ledger route. Existing save owners carry all additions; no new slice or migration. |
| Screen | Desktop 1920×1080. Existing Customers line explains tomorrow, presence, refusal or departure; existing office practice links and Rites and questions expose the two routes and runner. Mobile deferred. |
| Source and dials | Existing chart/return-client precedents remain those in the preceding return-visitor receipt. The dispatch error, later visit, corrected counter, schedule, five/forty-five/fifteen minutes and two-pence runner are authored proposals. No new passage or paid source reading. |
| Files | Office followup leaf, client fact projection, office case constant binding, command compiler, customer line, calendar extraction, focused tests and retained browser route. Shared host calendar hunk coordinated with `atlas_passes`; charm upkeep anchors preserved. |
| Failure and checks | Same-day visit blocks; another client's favor does not qualify; refusal gives no helpful memory; late visitor leaves; canceled search leaves no evidence; canceled postage refunds; restored correction cannot send again. |
