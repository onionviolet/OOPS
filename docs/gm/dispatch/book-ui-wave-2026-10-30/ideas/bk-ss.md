# bk-ss ideas (proposals, 2026-10-30)

Rows cited by id only (ss.law.rank-system, ss.law.rank-advancement, ss.law.nightmare-spell).

- **Creature ladder on the same seam.** The company pack hard-codes `COMPANY_RANKS` (Unwoken to Unholy, ss.law.rank-system second line). Map it to a second `definePath` and let the same ladder block draw the shadow's rungs. Small; needs the company pack's save to stay untouched.
- **Third Trial rung.** `ssRankPath` already has the Crowned crossing (trial, ss.law.rank-advancement). A next trial pack would reuse the expedition runtime with higher cost and a second route pair.
- **Crossing carry list (WCO1).** The Far Reach entry should show `renderCrossingThreshold` (what crosses, what stays, what waits). Below floor in this slice: the trial's `enter` command is a plain button.
- **Real risk roll.** The trial's danger is health loss and injury, deterministic. The expedition runtime has a `lethalId` slot for a true-death route; whether Weibao wants one in this life is a dial (default off).
- **Ladder block for other structured packs.** `presentation.ladder` is generic; HP houses, Gu ranks and MoL could declare one with no UI work.
