## Evidence projection, commitment and interruption

**Projection:** `inkObserverVariables` accepts bounded strings, booleans and enumerated results ([ink_scene_content.js](../../../../src/ink_scene_content.js):31–49), not arbitrary state. Tidemark reads `knowledge.player`, the player's prior accepted agreement and custody (:86–90). Relay reports are knowledge-gated (:170–179). Nested conversation reads player knowledge, filters private report keys and qualifies historical delivered account time (:328–358). Source-backed voice rows require actual active scene/world/people and an era/cutoff/profile binding for non-original profiles (:124–137); imported cue rows do not activate a book world by themselves.

This is not a generalized proof that every speaker has an independent evidence ledger. The observer API projects what the player may receive; the supplied native owners decide who could legitimately report it. A worthwhile negative case is changing underlying recognition after the player received a report and checking whether resulting speech is properly qualified as current versus remembered. That is a test candidate, not a confirmed leak.

**Commitment:** No EXTERNAL callbacks are bound; continuation rejects command/reward tags ([ink_narrative.js](../../../../src/ink_narrative.js):60–91). A host must implement observe/preview/commit (:106–112). Preview rechecks current eligibility, staged commit must return a distinct sequenced plan, and clock movement needs explicit joined-host admission (:126–137). Response commit stages host effects before updating the detached story cursor (:289–302). Scene agreement, real stock, jobs, custody and settlement remain native owners. Greeting or asking is not completion.

**Interruption:** Pause/resume increments revision in a cursor-only cloned plan and appends a receipt (:276–287). Resume rechecks actual host visibility/eligibility; pause does not cancel a paid job. Scoped host validators require native location/world/instance/mission/body and participant contact ([ink_scene_content.js](../../../../src/ink_scene_content.js):275–289,369–383). Legacy Tidemark/relay intentionally share one legacy cursor and `currentInkHost` routes an unfinished conversation back to its original host ([main.js](../../../../src/main.js):418–421). Nested scenes use independent scopes. The UI keeps displayed quote tokens ([ink_narrative_ui.js](../../../../src/ink_narrative_ui.js):68–96), does not replace them with a fresh sequence on click, and blocks concurrent controls within its panel. Main's stale token rejection remains the authority across panels.
