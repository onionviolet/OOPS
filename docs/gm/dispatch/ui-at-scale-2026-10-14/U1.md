Read `COMMON.md` in `docs/gm/dispatch/ui-at-scale-2026-10-14/` first.

Own exactly:

Task: survey how shipped games keep a growing number of systems usable, then
map each pattern onto the root palette codes (or propose a new code).
Groups, about 4-8 titles each, chosen for relevance:
1. Idle and incremental: Melvor Idle, NGU Idle, Antimatter Dimensions,
   Evolve, Kittens Game, Trimps, A Dark Room, Candy Box, Cookie Clicker,
   Increlution, Idle Champions. Focus: unlock-driven tabs, progressive
   disclosure, automation UI, offline reports, notation settings, prestige
   screens, how tab count grows over a run.
2. Deep simulation: Dwarf Fortress (Steam UI rework), RimWorld, Crusader Kings
   3 (nested tooltips, outliner, alerts), Stellaris, Victoria 3, Football
   Manager, Oxygen Not Included, Factorio, Kenshi. Focus: alerts, outliners,
   overlays, nested tooltips, encyclopedias, many-entity tables.
3. RPGs and MMOs: World of Warcraft (addons, Edit Mode), FFXIV HUD layout,
   Path of Exile and Last Epoch (trees, item compare, loot filters), Caves of
   Qud, Cataclysm DDA, Disco Elysium (skill voices), Persona (calendar),
   Baldur's Gate 3 (party, reactions). Focus: HUD editing, party switching,
   voices as UI, filters, comparison.
4. Text-first and browser games: Fallen London, Torn, Kingdom of Loathing,
   Sunless Sea, MUD clients (Mudlet panes and triggers). Focus: text-heavy
   layouts on desktop, storylet presentation, trigger and alias systems.
For each title: the pattern, why it works or fails at scale, evidence label
and URL, and which YAIRPG code it supports, contradicts or adds. End with a
ranked top 10 patterns to steal, a "what failed elsewhere" list and new
proposed codes (prefix GR).
