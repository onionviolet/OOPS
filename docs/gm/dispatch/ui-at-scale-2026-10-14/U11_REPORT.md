## Findings for the coordinator

| Code | Finding | Implication |
| --- | --- | --- |
| F1 | Full laptop use and comfortable prose measure are compatible | Keep useful panels across the screen; cap or tune the inner prose region. Initial comparison: 60-70 actual Latin characters, 1.5 line height, about 0.7em paragraph gaps |
| F2 | Prose, streaming logs and numeric comparisons have different reading jobs | Give them different rhythm and alignment using VI1's shared scale. Lining tabular figures suit changing data; oldstyle and proportional are separate optional features for prose |
| F3 | Literature guidance, research and accessibility criteria are not one universal optimum | Butterick's range, the Dyson abstract, and W3C spacing facilities differ. Values here are INFERRED candidates, and U4 owns settings/compliance |
| F4 | World flavor can come from attribution, document structure, heading type and trim | Keep controls and essential body text stable; system fields may use mono without turning every cheat or long document into a terminal |
| F5 | Reading comfort includes control over time and position | Instant prose/logs by default, optional paced scenes, full plain history, stable backward reading and explicit new-entry counts |
