## CHECKPOINT

Complete, 2026-10-14. U1 owns only this file and [U1_REPORT.md](U1_REPORT.md).
25 references: eight idle/incremental, six simulation, six RPG/MMO, five
text/browser references. Source pages and selected public source files were
read; no games were launched. Root palette remains read-only. Resume from
the evidence limits and open checks in the report, not from an assumed build.

## Scope and evidence

Considerations, not selected work or a replacement specification. The incumbent
is the [root palette](../../../UI_AT_SCALE_CONSIDERATIONS_2026-10-14.md), with
[Panel kit](../../../PANEL_KIT.md) and [accepted desktop direction](../../../USER_VISION.md#standing-ui-priority-2026-10-13)
retaining authority. Target: 1366x768 and 1920x1080. Desired visible outcome:
keep local actions and useful independent panels readable as known systems
grow, with quick routes to less frequent work. Mobile, controller work,
implementation and gameplay acceptance are deferred.

SHOWN means a page or public source actually loaded, not a live game test.
STATED means a developer, official manual or wiki claim; a search-only excerpt
is called out. INFERRED marks every assessment of suitability, scale costs and
YAIRPG recommendation below. MEMORY marks unchecked game recall, which can be
stale. Loaded developer prose can be SHOWN as a document while its game behavior
remains STATED. Historical dev diaries explain a design, not current-version
parity. No frame-rate, task-time, usability or late-run tab counts were measured.
Mutable source links were inspected on 2026-10-14; line numbers describe that
read, not a pinned revision. No source text or game code is copied here.

Mapping legend: **S** supports the named consideration; **C** qualifies or
contradicts a strong reading of it; **A** adds a proposed GR code. C does not
override the root or claim the pattern failed in every game.

Selection favors different mechanisms over exhaustive coverage. NGU Idle,
Cookie Clicker and Idle Champions were not retained in the eight-title idle
set; Victoria 3, Football Manager, Kenshi, Qud, CDDA and Persona are follow-up
candidates only. Increlution is a shipped Early Access reference, not claimed
to be a finished release. Mudlet is a shipped client ecosystem, not one game.

### GI9: what happens to tab count over a run

The inspected sources support a qualitative trajectory: few known homes early;
more parent domains at major unlocks; subtabs and automation settings within
those domains later. They do not support a universal numeric tab limit.
Antimatter Dimensions and Evolve show why measuring only root tabs misses the
real navigation cost: subtabs, reset pages and policy controls grow too.

Default proposal: preserve known parent homes, reveal new entries once, and
archive inactive known entries with reasons rather than erase their route.
Dial: show current activity only, show all known, or pin chosen views.
Unknown content stays absent in all three modes. A future census should record
root tabs, subtabs, reachable surfaces and hops to common actions separately.
