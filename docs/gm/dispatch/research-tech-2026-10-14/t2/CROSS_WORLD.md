## RX experiments: test a relation, not a universal tier

All five are **specified, not run**. Admission requires a genuine carrier for
apparatus/samples/records and qualified local means. No experiment grants
cross-world power execution. Carrying an object, using it, reproducing it and
exporting the result remain different achievements. Start with comparisons a
character can actually observe; proposed budgets are chosen per trial, never a
fixed once-per-life anti-abuse limit.

| Code / joins | Concrete comparison and controls | Useful result and unresolved gate |
|---|---|---|
| W40 / RX1–2, TP2, RF5–6 | HP magical site versus a qualified mundane home/TLM bench: carry the same simple battery/indicator circuit and reference ruler; verify it before travel, at each site and after return. Record charge, temperature, contact and observed magical conditions; include a second mundane indicator. | Distinguish depleted/damaged apparatus from a site-dependent failure; offer a local adapter project if supported. Hogwarts interference is still a source-detail gate, and one site cannot establish that all magic breaks all electricity. Stop when charge/parts or authorized trial budget ends. |
| W41 / RX1–2, TP4, KD2 | MOL versus a qualified home or FMA site: identical carried fuel/sample and physical vessel, first with no magical action, then a locally eligible practitioner’s precisely recorded operation. Use the same observed burn endpoint and contemporaneous reference sample; record available ventilation/conditions. MOL’s dispel/ordinary-fuel distinction is located in [brief source pin](../../../../worlds/mother-of-learning/WORLD_BRIEF.md#L22). | Test whether apparent “fire suppression” affects ordinary reaction, a spell effect, both or neither. A failure with one method is not a world-wide combustion-law difference. Separate practitioner proficiency from apparatus/sample changes. Stop at sample exhaustion or a material decision. |
| W42 / RX1–4, CT1, TP7 | FMA material transformation versus a qualified RI process and ordinary home craft: split a carried inert material lot, retain one control, record available mass/shape/composition before and after each explicitly different local method. Repeat the mundane measurement at both destinations. | Determine which useful product property transfers and which needs a local mechanism. These are function comparisons, not identical spells. No mass deficit establishes a soul/fuel theory; instrument uncertainty, residues and process inputs remain possible causes. Follow the unresolved FMA energy account instead of silently selecting one. |
| W43 / RX2, RX6, RB6, KL | HP ordinary study record versus LOTM/TTKS B5 qualified information handling: begin with innocuous matched records and copying tasks; establish language, medium and interpreter performance first. Any source-qualified hazardous category is a separate trial with an actual permitted exposure/containment method, never an automatic reader queue. Authored secrets use only secret ID and discovery route. | Distinguish medium/translation failure, cognitive misunderstanding, access enforcement and an information-caused effect. No universal “all mystical books corrupt” conclusion. A public report retains route/status, never a sealed truth or dangerous raw record. The specific hazardous trial stays unselected until source and operating means are qualified. |
| W44 / RX1, RX4, LB6, TM9 | Tensura slime contact sensing, MOL aranea communication, TLM instrument reading and a mundane observer: present the same harmless opaque containers/samples with separately recorded actual contents. Each uses only its acquired channel; compare repeated descriptions, not shared power levels. Sensory reference answers are accessible only after each test. | Identify range/resolution and whether the channel detects material, energy, identity or nothing. A matched outcome suggests functional substitution, not interchangeable mana/chakra/essence units. Retest at the destination with actual body/fuel support; no imported sense is assumed to work. Stop on lost contact, unavailable faculty or a player decision. |

A useful negative result can be “this operator cannot reproduce this here.” It
need not prove incompatible world physics. Strong means can settle an observation
without mandatory repetitive trials; translation, manufacturing or adoption can
remain worthwhile questions afterward.
