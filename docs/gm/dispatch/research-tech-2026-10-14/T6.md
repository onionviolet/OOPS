Create `src/invention_planner.js`: pure ES module, no DOM, no imports from
game/UI code, never mutates inputs, deterministic. Suggested API (refine if
needed and document why):
- `expandTarget(pack, world, target)`: target `{function, magnitude, form}`
  or a target id. Returns an AND/OR graph: OR over methods, AND over
  requirements, down to primitives the world declares as available. World
  rules prune or add methods.
- `checkFeasibility(graph, world)`: solvable or not, with a witness path and
  the named missing primitives; detects cycles (a product needed to make
  itself with no independent route) and reports them.
- `roadmapView(graph, knowledge)`: the actor's view; knowledge maps node id
  to fidelity 0-5 or `{wrong: true}`. Unknown alternatives hidden, low
  fidelity nodes shown as unknown slots, wrong nodes shown as believed.
  Includes `nextMissing` with a plain reason string.
- `estimate(graph, choice)`: depth, width, node counts by scale band
  (person, workshop, town, nation, civilization).
- `composeTargets(pack, world, a, b)`: merged graph with shared nodes
  de-duplicated (PI6).
