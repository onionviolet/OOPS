# A18: Shadow Slave

INFERRED roadmap proposals, 2026-10-14. Guiltythree's original novel; Spell-era and later Spell-independent cases cannot silently share rules. [Notation](../SHARED_VOCABULARY.md).

**Rules and design boundary.** STATED (historical wiki): Aspect, imposed Flaw and legacy requirements differ [DSS1](../../../../../research/power-systems/wiki-digests/DIGEST_shadow-slave.md:74); this archived community is not current canon proof. SHOWN/STATED in prior located novel readings: Sunny studies/manipulates spellweaves (ch.613, 618, 660, 696, 701); skilled Valor production has different participating faculties (narrator, ch.2048). Players can learn fighting/control and source-qualified sorcery/crafting. They cannot choose an Aspect/Flaw from an effect menu, assume every human has Divine core growth or learn Sunny's lineage faculties from a manual alone.

**PP2 nodes.** Actual Aspect/rank/Flaw, soul essence, eligible legacy/sorcery faculty, perception of weave, control, compatible base item, real anchor/source materials, supported enchantment and item custody. Memory rank/tier/capacity are not generic skill levels. Exact lineage acquisition remains separately source-gated.

**Small: convert a mundane cleaning implement into a usable Memory.**

```text
Create a summonable cleaning implement
 OR eligible weaver's supported conversion
    AND actual faculty + weave perception/control + base implement
    AND real anchor material + learned conversion -> paid trial
 OR acquire/commission an equivalent Memory
    AND eligible supplier + custody/payment + supported summoning access
 -> summon and use the implement; test that cleaning actually works
```

Prior shown toothbrush conversion (ch.800) supplies the narrow example. It does not add autonomous sterilization, universal enchantments or a weaving faculty to the buyer.

**Large: construct protective gear with several compatible effects.**

```text
Make a wearable protective Memory
 AND fitted material/base + supported protection functions + user eligibility
 OR qualified weaver project
    AND actual weave faculties + understood compatible patterns
    AND sufficient real anchors/capacity + essence/control + trials
 OR coordinated specialist production
    AND forge/infuse/inscribe/convert providers with their actual faculties
 -> test each effect, fit, summoning and sustained essence demand
```

This extends source crafting into an INFERRED target; no exact pattern is invented. Capacity alone does not make incompatible effects legal. A failed weave may destroy inputs, so an experiment does not guarantee the item (ch.696/701).

**PP4 hybrid.** Mundane tailoring/metalwork plus Memory conversion and enchantment, with source-specific materials and operators. Spelltech is an observed field (ch.823); it is not proof that electricity operates every Memory or that every Aspect can manufacture one.

**PP3 hidden view.** Undiscovered enchantments, another person's Aspect/Flaw, legacy steps and unreadable weaves stay hidden. Appraisal display changes only through its actual source, not opening the planner. Inherited located readings qualify these novel examples; no current full novel/wiki audit, exact custom pattern, rates or gameplay proof is claimed.
