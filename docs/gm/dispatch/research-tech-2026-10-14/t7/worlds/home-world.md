# A22: Home world's native skills

INFERRED roadmap proposals, 2026-10-14. Current YAIRPG home-world source, preserving native skills/numbers. This is source inspection, not canon-franchise evidence or fresh native play. [Notation](../SHARED_VOCABULARY.md).

**Rules and design boundary.** SHOWN IN SOURCE: Rat-step has observation, paid understanding, practice, internalization and execution prerequisites [technique definitions:11–38](../../../../../../src/technique_content.js:11). Native skill catalogue separates learned methods, XP parents and tools; learning grants no donor body/fuel [catalogue:48–69](../../../../../../src/skill_expansion_content.js:48). Players can assemble/train supported techniques and supply tools or teachers. Arbitrary free-text powers, a generic magical energy pool and unrestricted native ability fusion are not established by these definitions. A planner can propose an experiment but cannot claim a new native consumer exists.

**PP2 nodes.** Current body/stats/location, actual observations, understood method, owned technique, proficiency, native parent skill, available teacher, station/tool, stock, costs and actual consumer. Native stat requirements remain current source facts, not invented canon restrictions.

**Small: guide a crossing through narrow footholds with Rat-step.**

```text
Execute the actual learned Rat-step
 OR observe the field pattern / obtain the supported ordinary-combat observation
 -> paid study -> understood method
 OR supported idle practice / supported active drill
 -> proficiency for internalization -> owned technique
 AND execution proficiency + Agility + inspected crossing + current eligibility
 -> execute the supported footwork route -> receive its actual route outcome
```

Source defines ownership at proficiency 2 and execution at proficiency 6 with Agility 8; recheck these if the shared source changes. The existing consumer is the crossing route, not an automatic combat dodge [route:48–63](../../../../../../src/technique_content.js:48). Its guide outcome can vary before mastery. No native result was exercised here.

**Large: an expedition capability combining learning and equipment.**

```text
Prepare and carry out a supported crossing survey
 AND actor's learned applicable trail/evidence method
 AND obtain an actual usable survey kit
    OR self-build: timber/packing method + stock + tools + supported job
    OR commission: supported craftsperson + payment + collect delivered kit
 AND usable route/body + real observation opportunity + equipped kit
 -> test useful survey/action output -> retain paid evidence/result
```

INFERRED integrated target over catalogue methods, not a newly implemented expedition. Separate player learning from a craftsperson's output. A kit can remain useful even if the later route is inaccessible; hiring a builder does not award the player's mastery.

A new magical lamp branch needs an authored home-world source and consumer, not an imported mana node.
