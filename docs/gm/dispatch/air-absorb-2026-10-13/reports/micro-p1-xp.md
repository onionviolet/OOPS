# micro-p1-xp absorption report

## Air task

The Air work repaired the per-grant skill XP cap and added native and browser regression coverage. The bug was in `src/components/levelable_component.js`: `typeof skillXP.xp_to_next_lvl === Number` is always false because `typeof` returns a string. As a result, grants marked `cap_gained_xp` were never capped. The snapshot's replacement uses `Number.isFinite`, which preserves the existing infinite max-level sentinel behavior.
