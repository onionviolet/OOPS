## What changed

A quiet continuing faculty is recognized on a genuinely new ordinary Frontier
start. Existing saves retain their state and can explicitly establish a current
adoption baseline; no historical arrival is fabricated. From **More panels →
Continuing connection → Open your connection**, Return offers initial rewind,
one learned replaceable checkpoint, fresh separate-history embodiment and actual
reciprocal return to a paused living history. Anchors & study contains the first
10 available-minute self-investigation. Learning distinguishes retained knowledge
from body-dependent training and preserves known life-record memories.

Fresh B has its native opening date and an independent native world/body save.
A pauses with actual work/possessions and resumes at departure, not at a checkpoint.
One journey carries insight and enduring faculty growth. Current player preferences
carry without restoring old export cooldowns or UI options. Ordinary arrival is
paused until Continue. Deliberate repeat can be enabled explicitly for initial or
later point; every five played minutes a new cycle returns there. Stop disables
it. Duplicate event/retry is not a new cycle. No true-death farming trigger added.

Production engine timers now support a bounded transaction/arrival suspension,
including nested release, while UI stays responsive. The existing native writer,
lock, preflight and guarded root remain authoritative. An import race discovered
by stronger input testing was corrected: both enrolled and legacy import freeze
mutation and prevent the old runtime from saving over the published candidate.

## Explicit limits

- Adult-human scope is enforced; infant/nonhuman saves require their own capability adapter and remain preserved. The mastery adapter applies Literacy, Crafting, Smelting and
  Forging without copying Crafting mastery dexterity milestones. Other observed
  skill training remains recorded; its mixed body/stat application is not built.
  Knowledge of a skill is not unrestricted bodily execution.
- Current adapter supports Frontier with no other retained worlds/active optional
  campaign. Unsupported saves remain preserved; it does not reset Paradise hubs,
  contracts, external cargo or other worlds. No portable storage/duplication,
  active clone, branch revisit or general invention engine.
- Native defeat remains unconscious recovery. Return choices are not blocked by
  a body-alive requirement. A new real-death system, automatic terminal rescue,
  named hostile suppression and multiple rescue priorities are not implemented.
  The deterministic timer option is an intentional loop, not generic death immunity.
- Initial/new-history creation currently uses the supported native capable human
  profile and current name/bio. No new origin pool or arbitrary embodiment menu.
  Existing save adoption is explicit. Histories have no silent pruning; exceeding
  measured guarded storage rejects the transition without deleting the prior life.
