## Exact lock placement for future actions

**I40 shown foundation:** `src/main.js:602-609` locks the selected envelope key, `:889` rejects publication without writer authority, `:1478-1479` is the feature-command guard, `:4981-4984` guards serialization. `src/expansion_persistence.js:7-51` builds one envelope and writes once; `src/main.js:423-429` delegates that write to guarded storage before observer publication. Those functions are useful seams; the low-level storage wrapper itself does not check `ownsSave`.

Recommended eligibility is `ownsSave && !importProbeToken && !foundationSaveBlocked && !expansionError && !is_loading_error && !importInProgress`, plus ordinary lifecycle/occupation predicates. UI gating is convenience; command gating is authority. Recheck the expected run/instance/receipt/escrow revision at commit because state can change while a dialog or asynchronous preflight is pending. Do not release/reacquire the document lock for every click. On reload, await saveOwnership before honoring a durable pending transition.

## Export serialization and concrete IS6 policy

**I50 shown format:** `src/main.js:4985-5247` assembles explicitly listed state and JSON.stringify; `:5240` includes expansion state without an actor-knowledge export projection. `src/save_files.js:176-182` validates JSON syntax, UTF-8 encodes and prefixes base64 with `YAIR-UTF8-1:`. Decode `:158-173` reconstructs JSON and accepts historical formats. Import `:186-192` validates, preflights and writes. Ordinary export `src/main.js:5278-5294` serializes, can grant an export reward, serializes again and attempts storage; ended-life export `:8365` uses serializer/encoder directly. Encoding provides portability, not confidentiality or authenticity.

A player can remove the prefix, base64 decode, UTF-8 decode and read native inventory/counters, expansion RNG/facts/jobs and persisted pack definitions. `src/chronicle.js:79-82` even stores undiscovered actor profile data; this report names the path without revealing values. Knowledge-filtered `worldInstanceView:407-427` restricts its UI projection, not the exported object. No secret truth was displayed or private save inspected. Current code cannot be cited as already implementing observer-safe exports.
