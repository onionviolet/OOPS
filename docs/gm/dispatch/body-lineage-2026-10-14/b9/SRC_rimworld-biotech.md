# RimWorld Biotech: G53 reference check: modification evidence

2026-10-14. B9 docs-only research. Labels follow [REPORT](REPORT.md#evidence-labels). GM/GD mappings are analyst comparisons.

Boundary: base Biotech genetics as a design reference, not an invitation to reopen B5's game survey. Developer preview establishes concepts; a current wiki supplies qualified mechanics detail, not runtime proof.

Sources, accessed 2026-10-14: [developer preview #3](https://store.steampowered.com/news/posts/?appids=294100&enddate=1666109094&feed=steam_community_announcements), Genetic modification, genepacks/xenogerms, germline/xenogenes and metabolism; [Genes wiki](https://rimworldwiki.com/wiki/Genes), Mechanics / Gene expression; [Genetics wiki](https://rimworldwiki.com/wiki/Complexity), complexity and Heritability. No game/code test; exact numeric balance is not adopted.

| ID | Label | Codes | Bounded finding |
|---|---|---|---|
| RIM1 | stated, developer | GM5 analogy, GM8; GD6 | Extracted genepacks combine at an assembler into an implantable xenogerm. Collection, design and implantation are different operations. Preview, Genetic modification. |
| RIM2 | stated, developer | GD1 | Germline genes transmit to children; xenogenes do not through birth. The same visible effect therefore needs acquisition provenance to explain succession. Preview, gene flavors. |
| RIM3 | stated, developer | GD3, GD4 | Beneficial genes can increase food demand, while drawbacks improve metabolic efficiency. This is a specific balance scheme, not a rule every enhanced body must follow. Preview, metabolism. |
| RIM4 | stated, secondary | GD3 | Complexity determines assembly infrastructure and production time. Treating it as merely how many changes a body can tolerate misidentifies the constrained actor. Genes, Mechanics; Genetics, complexity. |
| RIM5 | stated, secondary | GD5 | Implanting a new xenogerm replaces prior xenogenes; conflicts can suppress germline expression. Replacement, suppression and deletion differ. Genetics, Heritability; Genes, Gene expression. |

Proposal: Default to separate clinic construction limits from recipient support needs. Dial generous or absent recipient limits with an in-world reason; cost can be facility time or materials. Exact version-dependent limits, extraction risks and archite exceptions need game/source verification before implementation. No universal flaws-for-power rule is proposed.
