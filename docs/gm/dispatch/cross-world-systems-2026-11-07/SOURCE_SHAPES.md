# Wave 3 source contract tests

The old sparse draft was insufficient and contained unsupported attribution. The current [inventory](source_shapes.json) covers **26 book-one spell occurrences/tasks** from the existing Harry Potter rules index across chapters 1–17, including the three exam enchantment/transfiguration entries, plus one inherited/involuntary-magic shape, and **nine source-pinned LOTM volume-one divination occasions**. Repeated Alohomora occasions and related methods remain separate so success, refusal and source scope are retained. The making, cupboard and house-standing index cases are listed separately in `engineCases`; a named potion with an unstated formula stays unknown. The JSON carries exact source paths, locators, hashes and qualification. Source prose stays private.

This is coverage of the existing book index, not a fresh exhaustive read of the two novels. A direct paragraph-level audit can still add omissions. It does not call every first-year spell Harry's learned spell. Harry's failed levitation, Hermione's casts, Ron's failed rat rhyme, demonstrations, reports and intended attempts are distinct evidence. Lumos was removed for lack of verified book-one evidence in these inputs. An early record's attribution of a broom jinx is an observer belief, not omniscient truth.

`tests/source_engine_shapes.test.js` compiles every indexed shape through the same grammar, spell records and structured ability descriptor. Fixture bindings exercise existing effect types for transformation, motion/transfer, damage, conditions/counters, display, compartment access and knowledge. This proves representability of contracts. It does not turn those fixture bindings into playable spell content, simulate full physical properties, or grant the player source knowledge. Native proof uses the actual levitation, feather-transfer, Spirit Vision and Cogitation callers instead.

The divination contract check compiles each method's prepare/rite/attempt/interpret stages as a procedure. Means, information contact, signal and interpretation stay separate. A result is not automatically certain. The test does not copy a future reading's signal or conclusion into this report. The original method inventory is `src/lotm_divination_rows.js` with source locators; some occasions are later than the current ch69 endpoint.

Numeric bands in the shape fixtures are test values. HP stamina, failure probabilities, LOTM spirituality and held-vision minutes remain authored dials where the book states no number. `scripts/calibrate_powers.mjs --strict` checks the chosen gameplay anchors, reports per-tier error, identifies underdetermined prices and leaves unanchored tiers assumed. It does not claim numerical canon fitting where no numeric observation exists.

The making checks cover both existing formula laws, order/heat, consumed ingredients, a missing or departed witness, cancellation, support loss, resumed work and a product awarded once. Home checks cover body/access, world-specific room plans, materials, tenure and retained fittings. Reputation checks cover unknown audiences, hidden/private records and independent source accounts. Companion practice checks require Ron, the earned tie and the learned method.

Later story windows add named spell/potion/rite rows and calibrate against their source events. A newly encountered effect kind can still require an engine extension; these tests make that gap explicit rather than treating an existing note string as a simulated mechanism. Polyjuice and the Sequence-5 rite remain content/integration stress cases, not delivered routes in this wave.
