# Xeus24 mod follow-up proposals

2026-10-11. User asked "What about the mod fork? More to consider?" during
absorption integration. This is ideaboarding, not authorization for another
runtime wave. Source: [Xeus24 audit sections 3–5](../../../research/proto23/xeus24-mod-2026-10-10/XEUS24_MOD_AUDIT_2026-10-10.md).
Use independently authored ideas; the audit found no code license for the mod.

O1. **Worn title with a retained collection.** Existing native lifetime titles
and their XP fix are already present. A player-selected title could add one
readable specialization while collected titles retain their small existing
benefits. Preserve old earned IDs; no repeat grants on reload. The audit's
Renown model grants lower-rank titles passively and compounds stats by ×1.05
per level. Start any original collection payoff modestly, with its growth and
tradeoffs tested before extending the catalog. This is a proposal.

O2. **Broader live readiness and codex.** Current local-life readiness and
Fort item-source observations are bounded examples. Extend the existing
Notebook using actual inventory, learned sources, skills, access and current
work gates. Show the means that can be obtained next, while keeping undiscovered
routes and sealed truths hidden. Do not create another journal owner. Proposal.

O3. **Three rotating backup snapshots and reviewed restore.** Current save
safety is already ahead of Proto23. Three bounded recoverable snapshots could
protect meaningful checkpoints; show timestamp/version and require an explicit
restore choice. Verify failed storage and old-save migration before claiming
recovery. This is separate persistence work, not part of the current runtime
assignment.

Additional later candidate: bounded hidden-tab catch-up for learned noncombat
work, with a stated cap and no combat replay. It changes offline policy and
needs its own explicit scope. Skill rarity words are a cheap UI follow-up only
where native rarity has an actual owner; do not invent tiers from color alone.

Current wave already adopts fitting Xeus24 A1 balance-baseline/number checks,
A2 local readiness, and A3 local live-reference ideas through W-C2. These do not
establish a full next-step page or universal codex. Native title selection,
Renown, backup rotation and hidden-tab advancement remain proposals.
