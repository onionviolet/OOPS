# Dangerous-site runtime delivery

2026-10-11. Candidate source implementation, awaiting integration and browser acceptance.

The helper qualifies a source-local site loop expressed through existing simulation commands. It adds no persistent domain, random stream, inventory, timer or dispatch path. Actor phase and injury facts plus permanent reward claims are existing owners. Older packs without expedition metadata are unchanged. Native defeat remains unconsciousness; the helper only admits true death through explicitly signalled, authored lethal commands. Source qualification and private content belong to the private pack lane.

Changed candidate files:

- `src/structured_expedition_runtime.js`: optional metadata validator and actor-safe projection of learned sites. Preparation, entry, held-means/ordinary approaches, withdrawal, finite extraction, actual-body treatment and explicit lethal choice require corresponding authored phase gates. Treatment can be authored at idle or returned phase. Projection excludes unchosen effects and hidden site truth.
- `tests/structured_expedition_runtime.test.js`: synthetic public fixture exercises native resource/vital consumers and existing command/boundary transaction owners.

Checks: `node --test tests/structured_expedition_runtime.test.js` passed all six tests. They cover invalid definitions, missing and active held means, unconsciousness remaining distinct from death, preparation/entry/injury/extraction/treatment, repeat withdrawal without duplicate reward, fatal actor state and command rejection, actor knowledge projection, reload and failed durable save preserving live domains. Pending preparation reload preserves its frozen outcome and supply reservation. These prove the narrow helper/transaction slice only.

Remaining authoritative gate: root must admit metadata through pack compilation, author source-qualified private content, rebuild and exercise the native player journey on a fresh origin including save/reload/import. Root owns legitimate fresh-character continuation after ended life; this helper offers no resurrection or hereditary power route. Clock integration must preserve actual native vital changes. Existing `advanceSimulation` expects actor-scoped vitals in its actor context and returns full vitals only for causal-story state; native projection is also available through `plan.native`. Tests use the ordinary simulation boundary owner, not browser native callbacks.
