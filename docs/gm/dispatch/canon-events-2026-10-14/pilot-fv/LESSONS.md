## Field inventory and one-line rules

All eight requested CV fields are included as extra event keys. They are author metadata except alternatives/fixed, which the updated module supports; this source unit supplies no positive substitution/fixed-point case.

| Field | Rule |
| --- | --- |
| roles | Bind actual actors and their available means; matching a role name never creates a replacement actor. |
| motive | Keep the actor's stated or inferred goal after a failed event; generating a response needs a separate consumer. |
| window | Declare source precision, relative order and coordinate units; chapter order never supplies a calendar date. |
| reveal_at | Separate occurrence from reader revelation, and record actor learning through its own channel. |
| confidence | Keep edition fidelity, pass-2 semantic status and dependency inference separate; uncertainty is not a numerical fate force. |
| recurring | Give cadence, bounded duration and stop conditions; an aggregate endpoint does not certify every intermediate occurrence. |
| alternatives | List only alternatives with surviving participants, means and satisfied requirements; label invented branch responses. |
| fixed | Require a supported law or explicit branch pin plus an in-world explanation; a warning alone cannot force an event. |
| knowledge metadata, proposed | Record holder, proposition, belief/truth status, messenger/channel and arrival separately from narrator evidence. |
| receipt/cost metadata, proposed | Record episode identity and known amount or interval; repeated passages and previews never mint another receipt. |
| time provenance, proposed | Mark a numeric coordinate as ordering-only, source-dated or resolved-window time before using it as a clock. |

## Granularity and checks

33 events is useful for this unusually dense ceremony/information/reward unit. Split an action, another actor's interpretation, receipt and later report when they can diverge independently. Keep a simultaneous multi-item acquisition atomic. Quieter arcs can use fewer events; add detail near used anchors. Leave duplicated passages, flavor, predictions, untested item functions, imprecise prehistory and speculative identities in notes or qualified base annotations. The bounded opening unit does not claim coverage of the whole first opponent arc.

V1: `check.mjs` imports the requested absolute-path module read-only. All five canon anchors derive with zero skips; incremental equals full at four successive anchors; lint is empty; input immutability and effective-claim/extra-field checks pass.

V2: The initial helper lacked timed changes. The latest module became available during this pilot, and the final run executes all three raw timed branches. Expected cascades are 8, 4 and 1 skipped events. Cancellation is checked by its explicit reason, inserted effects carry the change's cause, pre-intervention snapshots are unchanged, and branch incremental derivation equals full. RESULTS.json pins the tested module hash. Legacy one-set projections also pass but are recorded separately.

V3: The helper does not execute roles/motives/windows/reveal/confidence/recurrence. No positive fixed/substitution case, persuasion algorithm, source fidelity recheck, browser gameplay or save/import behavior was verified. A0–A4 are research snapshots, not accepted playable starts. Remaining source gaps: exact costs, overlap/custody onset, report cadence, intervention means and response alternatives.
