# R3: verified licences and machine-readable sources

Research completed 2026-10-14. Proposal for coordinator and Weibao review, not an accepted product decision or permission to ship. Extends HD1-HD9, NB2-NB3, NR8/12/13/31/35, MV19, R2, R10 and MC5-2. No game, save, catalog, shared manifest, build or Git staging change.

**R3-F1, SHOWN:** software and content licences differ in all three large d20 repositories. HD1 is now an archived, two-edition snapshot, not just a 5.1 database. Its README points to `5e-bits/5e-srd-api` as its successor; no seventh clone was made. [Pinned README](https://github.com/5e-bits/5e-database/blob/a6212beb4b278917c2cff41c2b04c4ef4f3e0d6f/README.md).

**R3-F2, SHOWN:** Datasworn classic's top-level CC-BY label does not cover its nested NC-SA material. The initial checkout was too broad: it exposed 55 nested NC-SA licence notices. Corrected by deriving a CC-BY subset with 17 NC parent subtrees removed and excluding the raw mixed JSON from the sparse checkout. The original blob remains in private Git object storage. This acquisition is therefore not described as a perfectly open-only initial transfer. No NC art, Delve data, Sundered Isles data, checkout form, account or personal-detail flow was used. [Publisher boundaries](https://tomkinpress.com/pages/licensing).

**R3-F3, SHOWN:** the ten-item comparison found a real same-edition omission in HD1 Conjure Animals. It also found deliberate rules differences between editions and a missing explanatory sentence in Foundry. Raw data is useful input, not the final authority.

**R3-F4, INFERRED from primary text:** NB2 is an open source of mechanics with ORC reciprocity, not an unrestricted bundle of Paizo content. Captured Cypher is reference-only for an autonomous YAIR videogame under this review. See licence rows and the remaining gate below.

**R3-F5, SHOWN:** `manage_library.py` has download, inventory and prepare commands, with no repository-registration command. The task's fallback is used: [private manifest additions](private/manifest-additions.json), 12 proposed records. The shared library manifest was left unchanged.

## Licence tiers and shipping boundaries

SHOWN means primary licence/notice text was read. Shipping boundaries and tier assignment are INFERRED applications of that text to this project. `open-shippable` means the identified material can ship with its stated duties; it does not mean a production export was built. `share-alike` includes OGL's content reciprocity, which differs from CC-BY-SA and ORC. Mixed repositories must be split by record, not assigned a permissive blanket licence.

**R3-N1, correction to MV19's implementation inference:** separate licensed data files help provenance. They do not alone determine the adaptation boundary. ORC I.c/I.m explicitly distinguish a single playable game from multiple non-interoperable games; II.b reaches adapted mechanics, while the AxE excludes an automatic source-code disclosure duty. CC-BY-SA distinguishes collections from adaptations. Decide the actual boundary before integrating either into a game with retained cross-world powers. This report makes no new product gate for unrelated original mechanics.

**R3-N2, source discrepancy:** `https://downloads.paizo.com/ORC_License_FINAL.pdf` returned a document headed `ORC LICENSE [INTERIM]` with a placeholder registration number. The current publisher HTML and Foundry notice carry TX 9-307-067. Both received bytes and hashes are retained; the HTML is the final-text source used here, not the misleadingly named PDF.

## Ten-item diff sample

SHOWN: read ten HD1 2014 spell records, both Foundry spell variants, and the corresponding publisher PDF pages. Exact objects, normalized text diffs and page captures are private in [comparison](private/sample-comparison.json), [5.1 pages](private/sample-pdf-51.json) and [5.2.1 pages](private/sample-pdf-521.json). Page numbers below are one-based PDF pages. Foundry's `@UUID`, `&Reference` and inline dice syntax are presentation/runtime additions. Text equality before removing those and rejoining HD1's `higher_level` field is not a semantic test.

| Sample | Same-edition HD1 vs Foundry 2014 | 2024 / 5.2.1 result and action | PDF 5.1 / 5.2.1 |
|---|---|---|---|
| R3-S01 Magic Missile | Same three-dart base rule; HD1 stores higher-slot text separately, Foundry inserts a heading and models one dart's damage as an activity | Still three base darts, but Foundry adds computed dart-count markup. Preserve individual dart targeting; a generic damage formula is insufficient | 161 / 146 |
| R3-S02 Cure Wounds | Same 1d8 + modifier and higher-slot rule, with field/HTML differences | 2d8 + modifier, +2d8 per slot. Do not reuse 2014 healing values | 132 / 121 |
| R3-S03 Healing Word | Same 1d4 + modifier, separate versus inline scaling text | 2d4 + modifier, +2d4 per slot. Keep bonus-action identity | 153 / 139 |
| R3-S04 Aid | Same maximum/current HP increase and duration. Different representation of higher-slot scaling | Sampled numeric rule stays aligned. Foundry activity/effects and prose must be interpreted together; a heal activity alone does not express a max-HP buff | 114 / 107 |
| R3-S05 Sleep | Same HP-pool rule; Foundry condition-reference markup and higher-level heading differ | 5-foot-radius selection, Wisdom saves, incapacitation then unconsciousness, concentration, 60-foot range. 2014 uses a 5d8 HP pool and 90-foot range | 180 / 163 |
| R3-S06 Spiritual Weapon | Same 2014 no-concentration rule and scaling per two slot levels | Concentration added; damage scales per slot above 2. Version-lock both persistence and scaling | 182 / 165 |
| R3-S07 Counterspell | Same 2014 automatic lower-level cancellation/ability-check rule; scaling field versus heading | Constitution save; failed-save spell slot is not expended. This is a different resolver, not a formatting change | 131 / 120 |
| R3-S08 Find Familiar | Foundry replaces creature names and sensory conditions with UUID/reference markup; raw text differs without a demonstrated rule disagreement | 2024 permits another CR 0 Beast beyond examples and changes sensing action wording. Translate links to local IDs, never silently drop linked choices | 143 / 130 |
| R3-S09 Conjure Animals | **HD1 omits four-times summons at a 9th-level slot. Foundry includes it. Foundry omits the sentence assigning creature statistics to the GM; publisher includes it.** Publisher wins both | 2024 replaces separate summoned-beast groups with an intangible pack effect; duration becomes 10 minutes.
