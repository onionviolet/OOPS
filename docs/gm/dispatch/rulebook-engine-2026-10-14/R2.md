# R2: effect DSL and SRD 5.2.1 pilot (code plus data)

Read COMMON.md in `docs/gm/dispatch/rulebook-engine-2026-10-14/` first.
Root codes: EA6, EA7, EA9, EP4, EP9, MC5-1, MC5-2, MC5-3, RB4.

Worktree: `.claude/worktrees/rbe-r2`, branch `codex/rbe-r2-effect-dsl`.

1. Design a small effect DSL as data: target, area, range, casting time,
   save or attack, damage, condition, duration, concentration, components
   (with costly components as real stock), plus a function record (does what,
   carrier, needs, scale) and a status flag: `supported`, `needs_ruling`,
   `unsupported`. Write `src/effect_dsl.js` with a strict validator.
2. Encode from SRD 5.2.1 (private text:
   `docs/research/tabletop-library-2026-10-14/private/text/dnd-srd-521.txt`):
   all conditions, 20 spells across levels 0-5 and schools, and 10 monsters
   across challenge ratings. Put data in `src/data/srd521/` with per-record
   source, licence (CC-BY-4.0) and revision, and one ATTRIBUTION notice file
   using the SRD's required attribution wording.
3. Importer trial: a script under `tools/` (new) that turns a text block into
   a draft record the validator then checks. Record how many drafts needed a
   human fix.
4. Coverage report in REPORT.md: percent supported, and for each
   `needs_ruling` item the ruling question it needs.

Do not wire into gameplay. Tests: validator rejects malformed records;
every shipped record validates; attribution present on every record.
Lane folder: `docs/gm/dispatch/rulebook-engine-2026-10-14/r2/`.
