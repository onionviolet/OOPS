## What changed

**S1. Remembered materials can teach a real native preparation (CRL45/35/41).**
Native acquisition now connects an existing herb preparation with a practiced
Alchemy learner's encounters. The starting familiarity is read from the existing
recipe, not copied into labels. Either herb can arrive first. Selling a sample
keeps the encounter knowledge; learning consumes no sample and creates no product.
Native recipe availability is the sole learned entitlement, shared with the
existing book route. The normal craft still rechecks full stock, station and
other native costs/chance. The actual buy/sell/buy journey initially failed with
an unsupported unlock: ItemRecipe's registration preceded its final ID. Final
item-recipe IDs now bind their own AvailabilityComponents. Repeated component
labels across crafting categories were not silently migrated to new global IDs.

**S2. A shop can restock while it remains open (CRL51/38).** Previously the legacy
shop refreshed only on opening. The native registry now calls the existing
TraderComponent on the played clock; that owner retains day cadence, seeded
stock and persistence. Existing special played-minute adapters keep their route.
Exact pending subjects recover where still stocked, quantities clamp to actual
stock and unavailable subjects drop without substitution. A static notice in the
existing trade surface explains the change. An old pending selection must be
reviewed before a charge; selecting after a restock with no prior quote needs
one acceptance. The existing native quote revalidation remains authoritative.
The catch text now says “Trade not completed”, because selections can remain.
No new stock calendar or reward writer was added.

**S3. Search responds to its current sensing means (CRL52/46).** Existing native
local search now reads place light and Night vision. It retains completed search
work while lamp expiry changes visual searching to slower nearby touch; a lamp
or sufficiently practiced night vision restores the visual method. The actual
light/tool callback refreshes the method explanation immediately. The initial
relight verification caught a refresh attached to the crafting callback; that
join was corrected and the complete journey rerun. Search settlement, location
interruption and its one finite find remain with the existing local-life owner.
No secret detector or second exploration system was created.

Reversible local proposal defaults, not accepted universal world law: **D1** the
selected Healing powder inference follows known Weak healing powder, the native
recipe's starting Alchemy familiarity and both encountered herbs; instruction
and books remain alternate routes. **D2** pending shop terms require review after
actual restock; no pending quote means no extra acceptance. **D3** native loose
finds need effective light 60 or half native Night vision mastery for visual work
at rate 1; nearby touch works at 0.5 toward the same five work units. These dials
have local reasons and costs, rather than imposing them on other worlds.
