## FL: one reveal ladder, two domain vocabularies

The palette's F shorthand is retained for RC cards. Companion RF describes
**access**, not a compulsory numeric appraisal rank. Library OV3 describes
**precision** (none/presence/category/range/exact/future). Store these axes
separately; neither F2 numbers nor a high precision grade grants private access.

| Code | Maker tier | Companion rung match | Meaning |
|---|---|---|---|
| FL0 | F0 | RF0 cue only | Feeling, sound, scent, posture or texture attributed to a means; no asserted diagnosis |
| FL1 | F1 | RF2 labelled need; RF1 only for mood | Named category or problem; an item's voiced mood uses RF1, not a need verdict |
| FL2 | F2 | RF3 exact track/field | Range or exact supported measurement, with units/context/as-of; exactness is a separate grant |
| FL3 | F3 | RF2 or RF3 for hidden nonmental fields | An allowed concealed property or mechanism; no automatic RF5 private-thought access |
| FL4 | F4 | RF4 cause history | Receipts or attributed recollection; memory is not certified history |
| FL5 | F5 | RF6 future forecast | Conditional possibilities, assumptions and freshness; no automatic guarantee |
| FLP | Separate private grant, not a new F tier | RF5 private thoughts | Only a named mind-reading route can add this, including for sentient weapons or makers |

F0-F5 are output options, not six mandatory upgrades. Each card states its
normal stopping point; higher entries marked unavailable need a named extension
or another card. F4/F5 can be granted without F2, as with visions. The shared
RF0-RF6 ladder remains unchanged. F0 can be an ordinary sensory cue: whether
highlighting it is a cheat depends on the world's WR standing.
