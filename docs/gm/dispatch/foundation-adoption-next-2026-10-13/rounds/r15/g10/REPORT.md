## Evidence method

All new behavioral claims use **seeded-native** unless explicitly labelled **source**. Existing test exports are imported literally, using the real importer and loader. Additional goods, purse and access are QA prerequisites through the actual native models. FA17's fixture reuses G5's native Node generator with no teaching and real career reducers to accept a shift, interrupt it, and keep its kit. Every hero is named `TEST FIXTURE R15 G10 ...`.

`build-probe.mjs` rebuilds the same main entry with a test-only `G` bridge appended. It replaces no implementation. This allows real host commands, serializer, native models and joined clock to be exercised in the loaded browser, and explicit impossible-state injections for rejection tests. Controls are used for normal actions and keyboard tests. FA18 refusal tests call the actual browser host through this bridge. Forced support tests deliberately change the native location, life/health, participant location/willingness or recorded body; they are QA transitions, not a claimed ordinary UI route. Manual changes to malformed jobs are confined to rejection tests.

Short jobs use held wall-clock timers and the real joined clock. Save, reload before PLAY, Export download and literal-file Import into cleared origin storage compare character, all inventories, expansion, location and calendar. Derived weapon display caches alone may differ, with their exact paths recorded per checkpoint. Refused imports compare the entire durable save byte-for-byte. Quota injection throws on actual save-data storage writes; live state, money, counted inventory, native stats, expansion and calendar must remain identical. Clearing storage failure requires reload, followed by one explicit retry.
