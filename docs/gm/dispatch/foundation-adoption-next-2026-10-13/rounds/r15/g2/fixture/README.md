# R15 G2 disposable test heroes

Generate from this worktree with `node .../g2/fixture/generate.mjs`.
`VERIFICATION.json` lists the original disposable export, real-model seed changes
and fresh native importer/loader checks. No browser or personal save is read.

| Fixture | Prerequisite |
|---|---|
| retort | Six Tree sap added to the earned R7 public workshop/retort state |
| reserve | Seven kits removed; two resin and six sound staves added. Three resin batches are fundable |
| held | Existing seven kits retained; reserve inputs supplied |
| program | Five coins, enough for two paid packs |
| program3 | Three coins, enough for one pack with two repetitions left |
| program1log | Six coins and one log, so wood is the sole next-pack shortage |
| mixed | Earned R4 household terms/state, renamed only |
| mixed-nowood | Same R4 state, logs removed down to one |
| retort-merchant | One actual receiver moved from character model to trader model; ordinary trader refresh preserves it |

The retort and three-coin `.txt` files stay directly available. Extract the
other `.txt` files from `FIXTURES.tar.xz`, or run the generator to restore them.
Literal-import the `.txt` into a fresh disposable origin/profile. All heroes
start with `TEST FIXTURE R15 G2`. Import replaces that test origin's save.
Seeds are not natural acquisition, accepted balance or a played sale. The
merchant refresh and its real native serialization/re-import are **source**
checks (`MERCHANT-SOURCE.json`); browser ownership/control uses the resulting
fixture and is **seeded-native**.
