## Technical constraints and gates

chooses their hosts; authoritative game owners retain clock, commands, custody,
save ownership, rewards and eligibility. Repositioning or duplicating a view must
not duplicate timers, work, commands or rewards. Read-only states remain visible.

Layout configuration is separate from gameplay persistence and versioned with
safe corrupt-data recovery. Define device/world preference scope explicitly.
Unknown/removed module IDs and changed viewport sizes recover safely. Hidden
panels can be reopened; unavailable content is not accidentally disclosed.

consequences, not screenshots alone. Use generated fixtures. Verify at 390,

reload and reset; missing/corrupt layout and absent/restored optional modules.

compatibility. Relevant progressed native and available candidate-world journeys
must cover combat, work, crafting, movement and required decisions; label any

suites in each worker. Inspect actual diffs and combined behavior. Human taste,
