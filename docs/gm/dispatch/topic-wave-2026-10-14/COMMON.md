## Rules

1. **Docs only.** Write exactly two files: `<lane>/OUTPUT.md` and
   `<lane>/REPORT.md` in this folder. CHECKPOINT at the top of REPORT.md,
   kept current. No other repo edits, no git add, commit or push.
2. Read PROJECT.md (top 80 lines), the AGENTS.md standing-direction section,
   and the relevant USER_VISION sections. Proposals stay proposals.
3. **Extend, don't restate.** Before adding a row, search the root palette and
   sibling owners for it. Cite the row you extend (code plus file). If a root
   claim is wrong, put it first as a correction with evidence.
4. Evidence labels on every claim: SHOWN (file and line or table), STATED
   (a doc says so), INFERRED, MEMORY. Read `src/` read-only to check seams.
5. Standing rules: Default + Dial + Reasonably; everything possible,
   reasonably; no either/or questions to Weibao; no fixed "once" limits;
   sealed secrets by ID only; desktop first; same rules for NPCs and player;
   no new mandatory survival chores; old saves load unchanged.
6. Game text is someone's writing: paraphrase, no raw dialogue or prose.
7. Plain English, short words, no em dashes.

## Output shape

OUTPUT.md: corrections first, then coded rows (lane prefix plus number) with
source, angle, existing row extended, owner, and a disposition (ACT NOW for
the root, ACCOUNT FOR NOW, LATER with suggested executor level, effort and a
done check). End with the top five picks, ranked.
REPORT.md: CHECKPOINT, what you read, unread table, contradictions found.
