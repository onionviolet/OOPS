## Standing direction

- Proposals only. A palette, not a spec: tables are options for fitting characters at fitting times and must make sense per world.
- Everything possible, reasonably: keep options reachable; never frame an either/or for Weibao. Default plus dial.
- Solo player: no fixed "once" limits; limits are per-world adjectives. Save safety still matters.
- Reload never rerolls; previews never consume draws; same rules for NPCs and player (GR13).
- Sealed secrets: never print a secret's truth. Refer by ID, route and status.
- Desktop first (1366x768, 1600x1000); mobile deferred.
- Persistence proposals name a migration or an explicit compatibility decision.
- Original names unless a canon source is cited.
- Evidence labels on every claim: SHOWN (read in repo or source, cite path:line), STATED (a doc says so), INFERRED, MEMORY (your recall, unverified). External sources: cite URL; if you cannot browse, label MEMORY.
- No em dashes. Plain English. Short codes for findings, prefixed with your lane (e.g. PC2-R3).
