# Whole-book gaps pass: mechanism family codes (L7 working list)

Codes group source-world rule rows by the mechanism they would need in the game, not by plot. Lanes pick one code per row. A lane that needs a family not listed writes `NEW:<kebab-slug>` and the Sonnet lane merges the slugs afterward. Proposal vocabulary, not an accepted design.

| Code | Mechanism family |
| --- | --- |
| ADV | Advancing a rank or tier: formulas, ingredients, digestion, promotion conditions |
| ACT | A method of practice that makes advancement work (behavioural rules of a role or discipline) |
| ABL | A power used in the field: conditions, costs, limits (combat or utility) |
| DIV | Divination, omens, dreams, scrying |
| RIT | Ritual, prayer, summoning, bargaining with or contacting higher beings |
| SPL | Spells, charms, words of power with set casting |
| MAK | Making things: potions, alchemy, crafts, mystic items from recipes |
| ART | Sealed or dangerous artifacts and their side effects |
| COR | Corruption, loss of control, mutation, madness, backlash |
| MND | Mind and spirit effects: reading, influence, memory, soul |
| IDN | Persona, disguise, assumed or second identity and its reputation |
| ORG | Institutions: membership, rank, access, rights, internal rules |
| GTH | Secret or private gatherings and information networks |
| LAW | Law, policing, crime, punishment, evidence |
| ECO | Prices, wages, trade, banking, debt, contracts |
| CUS | Customs, etiquette, festivals, daily religious practice |
| CAL | Calendars, clocks, dated events, news |
| TRV | Transport, fares, long journeys, sea and rail travel |
| PLC | Places: regions, cities, hazard zones, access rules of a location |
| WAR | War, conflict, city-scale or large-scale events |
| LIF | Ordinary life: housing, food, work, school, health |
| FTH | Deities, doctrine, faith, church structure |
| KNW | Knowledge: secrecy, rumor, who-knows-what, taboos on knowing |
| CRE | Creatures and spirits as actors with rules |
| LNG | Language, writing, ciphers |
| OTH | None of the above |
