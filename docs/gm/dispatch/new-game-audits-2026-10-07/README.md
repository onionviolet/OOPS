# New game audit selection

Checked 2026-10-07 against live `PROJECT.md`, research directories, the Steam manifest inventory and public developer sources. None of the five targets below had a game source dossier at initial inspection. Path of Achra and Magic Research 2 already had description-based reference notes; Erenshor, Soulash 2 and The Matchless Kungfu are new to this source wave. Existing games have finite selected audits rather than whole-game semantic coverage.

## Current project overlap

Current `src/power_models.js` already resolves mastery/capacity and typed effect amounts; `src/party_battle.js` binds consent, body state, actual owned equipment and a bounded helper contest; `src/skill_discovery.js` separates knowledge, unlock and eligibility. Useful new evidence therefore concerns deeper interactions, autonomous motives/aftermath, concrete crafting/material provenance and earned practical consumers. These audits do not reopen those existing foundations or imply they have no implementation.

Source waves for Dwarf Fortress, Book of Hours, Factorio Lua/API, Oxygen Not Included and Cult of the Lamb already have scoped completed dossiers. Factorio's full native goal remains active in its existing owner, checked through a live chat readback. This wave neither relaunches that writer nor claims the older selected passes exhaust their games. Your Chronicle's partial IL2CPP and Streets of Rogue's absent gameplay-source gates remain with their existing dossiers.
