## What blocks what

- **E19–E20 and E22.** Disarm exposes an integration gap between an effect on an item, the contest's proxy and the next cast. A subsequent action that reads the actual item is a small test of state ownership. That ownership also matters for a companion's injury and a Gu's control or fuel, though each still needs its own applicable rules.
- **E24–E25.** Source inventory and engine work can proceed together. The inventory sets the scope of the coverage claim. Engine proof supplies executable cases. Authored values can qualify a fixture and remain distinct from what the source states. The current run puts expansions after canon coverage.
- **PC95 and E23.** The headless bridge is evidence about the clock and envelope. Playable tie-in also requires a reachable command, actual equipment and resource owners, observer-safe feedback, and the game's own save and restore path. These needs inform the engine now and are exercised in the game at tie-in.

The current plan starts the canon inventory and items ledger alongside bounded consumer proofs for Disarm, creature lifecycle and dose settlement. Use those results to choose extensions to the current representation. A larger combat model or spatial view has a concrete case when position, timing or perception changes the outcome.
