## Exact causal chains beyond combat

**Selected paid work:** content command → `previewSimulationCommand` → `startCommand` reserves costs/claim, freezes result/draw/revision/support → `commitSimulationCommand` stages → single durable publisher. At due time `completeJob` rechecks declared support, refunds and records no output when unsupported; otherwise applies effects/completions/claim settlement. Existing controllers may then choose another legal funded candidate. This supports real causality within represented content. It neither invents replacement work nor follows every source event.

**Nested endings:** actual repair/export/claim commands → committed world facts → `localOutcome` → explicit report/withdraw/breach → quoted extraction/local deadline → actual hub arrival → once-only `mission.settle` returns reserved issuer funds less reward. Water welfare, claim arrangement and issuer reward differ. Later personal visits keep actual remaining stock and institutions. NPC death is not an input in these local outcome predicates today.

**Frontier endings:** previously earned order/evidence/owned stock/consent and actual mature work → conditional closure command → material transfer/world arrangement and ending knowledge → retained player-ledger UI/quest/next finite work. END.01–07 are composable closures, not seven irreversible whole-world finales. [TIMELINE_AND_ENDINGS](../../worlds/original-frontier/TIMELINE_AND_ENDINGS.md) expressly leaves body death/world destruction outside that pack.

**Ink:** stable response at saved content/cursor boundary → host scope/preview → real staged host commit → `ChooseChoiceIndex` and observer-variable prose on the staged result → saved Ink receipt/cursor joined to the same plan → main's durable publication. `pause` is cursor-only; other narrative bindings may commit a knowledge record rather than a physical effect. Existing `requireScopedAcceptance` revalidates a specific host; new death/hostility changes need that host's contact eligibility, not only a different line of prose. Retain older content hashes/cursors; do not recompile/repoint a saved scene and call old checks proof of the new story.

**Knowledge:** real witnessed result or actual received report → targeted knowledge effect with cause/basis → eligible later response/controller → known People/Events/Ink account. Truth stored in a world fact is not proof every actor learned it. Current key overwrites and pruned logs/events limit detailed contested-history audit; demanded retained CSE evidence must survive independently.
