## Host registration and one-off code

[HOST_INVENTORY.json](HOST_INVENTORY.json) lists every one of the 59 host files, exported declarations, line counts and source users. These are static references, not a count of instantiated controllers or registered commands. None were executed in this study.

Most host modules do not register themselves. Content arrays enter through `simulation_content.js` and `expedition_content.js`; `createRegistry` delegates simulation validation; `main.js` supplies native context, routes commands and invokes the common publisher. Destination native modules also have explicit registration calls in main. `feature_expansion_wave_host.js`, `steam_absorption_host.js` and `world_completion_host.js` compose presentation/admission from subordinate hosts.

| Host group | Reusable shape | Behavior that must remain an adapter |
|---|---|---|
| BOH/DF/ONI/Lamb, furnishing, fieldcraft, ordinary care | Context, group/actor/sequence validation, preview, commit, pending/cancel, received-knowledge projection | Exact stock report freshness, equipment/material checks, native effects and unique completion validation |
| Feature/power/book/society/refinement/audit aggregators | Register pack contributions and routes by namespaced group | Independent agendas, conditional authority, funded plans and optional enrollment |
| Pocket/Tidemark/nested/Paradise/MoL/Proto23 | World binding, visit, clock boundary, presentation hooks | Arrival/native location, support leases, paid returns, world-specific economy/body/cargo consumers |
| Native/feature battle, causal story, Factorio retort | Explicit registered hooks with single publication owner | Native fighter state, physical runtime/heat/storage, frozen situation support and causal consequences |
| Original Frontier, repository/backlog/lore/work completion | Shared jobs, claims, knowledge, project stages | Legacy receipts, quest synchronization, player/NPC separate means and specialized work-policy semantics |

Avoid deleting a host merely because two functions have the same signature. Standardize the repetitive shell first; keep a declared adapter until a comparison establishes the same legality, costs, visibility, cancellation and native result.

## Corrected sketch contract

**P1. Rules:** resolve a typed override key from defaults → multiverse baseline → world → place → scoped personal exception; merge keys use declared operators. Multiverse events also carry targeted world/place patches when they must change a world override. Otherwise a world value would mask barrier thinning forever. Personal exceptions cannot confer ownership, consent or bodily contact that no actual means supports.

**P2. Content:** cards are immutable definitions; instances own changes; knowledge owns disclosure. Keep approved code adapters for new mechanic families. Both original public packs and optional private packs use this manifest, without moving already-public legacy content solely due to this proposal.

**P3. Time and operations:** distinguish monotonic causal time, world-local elapsed time, subjective age, native calendar and operation history. Restore selected domains under a new history epoch; never move the shared clock backward while old jobs reference it. Offline banked time, world absence and exact active simulation are separate policies.

**P4. Research and people:** one staging/ownership substrate, multiple local progress signals. Factions and world wills can be actors/owners, but eligibility, salaries and yearly summaries need implemented policies. Aggregate households do not supply combat bodies or infinite unpaid labor.

**P5. Compaction:** presentation can lose detail; authority must retain sufficient state for future consumers. No ordinary log pruning can grant a repeated first-clear reward, cancel debt or erase an observer's retained memory.
