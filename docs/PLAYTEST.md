Implementation: structural/version/retirement validation, real-loader preflight in a disposable same-origin frame, and storage commit only after success. The frame never runs the simulation or writes saves; it is removed on success, rejection or timeout. Unknown references/loader warnings reject rather than silently discard data. File controls explain rejection in the player log. Export cancels if save creation/encoding fails, and saves cannot overwrite a stored payload after a loading error. New exports require this fork's updated importer; unchanged localStorage JSON and legacy decoding do not establish upstream export compatibility.
