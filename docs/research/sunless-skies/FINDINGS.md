## What Skies changed from Sea

All comparison cells are **seen in data or code**, except interpretations explicitly noted. Neither title is ranked above the other.

| Topic | Sea source | Skies source | Implication, **inferred** |
|---|---|---|---|
| Successor link | Choose1 of5 links,2 with Scion | Fresh person with broader automatic inheritance and new origin/history/ambition | The player can continue without a blood heir in either; neither inspected path is a full NPC genealogy. |
| Assets | One selected weapon/officer or chart; half money via selected link; will-protected home/heirlooms | Locomotive, bank, half money, affiliation allocation, persistent flags, most fittings | Broader retention can reduce rebuilding, but both use authored abstractions. |
| Knowledge/growth | Half selected base stat with floor25 plus unlock bonuses | Level-table XP floor/max, persistent heirloom-gated facets | These are world-specific progression rules, not character memory evidence. |
| Map/world | Same TileConfig only with Correspondent, otherwise regenerate | GeneratedWorld from latest saved character, fallback generate | Persistent geometry is distinct from retaining all narrative history. |
| Stories | Sparse29 persistent qualities among957 |130 persistent qualities among2110, demonstrated Hybras lineage flag | Different retained content; counts do not measure quality or prove every decision survives. |
| Hunger | Crew-scaled meter, supplies consumed at50, starvation story at100 | Fractional supplies, hunger flag, Desperation stages and thematic timed deck | Pressure becomes a linked narrative state progression. |
| Terror | Gloom accumulation, light/loneliness, selected threshold stories | Environment rates, terror crises plus later Nightmare episodes | Surviving immediate danger can leave later consequences. |
| Scheduling | Always plus probabilistic Sometimes card admission/shuffle | Timed thematic weighted decks, Always/Must precedence | Reusable structural patterns; neither proves YAIR's proposed adaptive storyteller. |
| Mercy | Manual saving changes mode/removes Invictus | Death can reload last autosave or continue legacy | A harsh ending can coexist with a gentler mode where the world supports it. |

Sea locators: sibling [FINDINGS](../sunless-sea/FINDINGS.md), F1-F17. The historical developer comparison supports design intent and feedback, not a substitute for build-specific implementation.
