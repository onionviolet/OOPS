# Deep-detail re-audit, 2026-10-14

Earlier game passes usually saved enough evidence for their selected findings, but often left the broader mechanics unread. Some saved full dialogue or tables privately; others kept only a small source slice. Many older private exports are absent at their recorded paths on this Mac. This pass records those differences and preserves useful existing material in **18 ignored private dossier folders**. It changes no gameplay and closes no source-game runtime gate.

**F1: The main problem is incomplete consumer reading.** A table value, metadata field, export count or dialogue excerpt often stops before the function that checks eligibility, spends a resource, changes state and produces a later consequence. The strongest remaining questions concern NPC perception, conditional dialogue, progression curves, combat counters, schedules and quest grammar. The [per-game ledger](LEDGER.json) names the actual boundary instead of treating a finite “COMPLETE” label as a whole-game audit.

**F2: Missing detail and unread detail are different problems.** Heaven's Vault, Vagrus, Idleon and recent idler passes have substantial readable inputs here. Book of Hours, Disco Elysium and Planescape historically retained much more than paraphrase, but their recorded raw roots are absent here. Citizen Sleeper's numerical scene graphs were never successfully retained. Streets of Rogue never obtained original gameplay bodies. Restoring a lost locator cannot fix an unrecovered consumer.

**F3: Existing routes should precede new decompilation.** Public code, JSON, compiled Ink, Godot token records and managed exports answer many named questions without REA. The [Hogwarts REA trial](../hogwarts-legacy/REA_TRIAL.md) demonstrated a useful optional interface over Ghidra, with no demonstrated decompiler advantage. Its bounded import used roughly 2.9 GB maximum RSS for one selected chain; that is a historical observation, not a budget for a different executable. Preserve Factorio's repaired canonical corpus if found; an ephemeral REA import is not a substitute for it.

**F4: Newer follow-ups narrow several old shortcomings.** Vagrus now has event priority/cadence and market consumers; its remaining return-path exceptions are specific. Path of the Idle Cultivator has a readable client follow-up, superseding the parent page-only wording. Immortality Idle's activity logic and hell/battle paths, Groundhog Life's named later-build paths and the prestige-community comparison have newer evidence. Their complete catalogues, dynamic execution and runtime claims remain qualified.

This uses the [coverage refresh](../coverage-refresh-2026-10-14/REPORT.md) for routing and the [adoption re-audit](../game-research-adoption-reaudit-2026-10-14/REPORT.md) for the distinction between research and existing YAIR consumers. Neither audit was repeated. Authority remains [USER_VISION](../../USER_VISION.md#save-deep-details-for-reference-2026-10-14) and [PROJECT](../../../PROJECT.md). Ranking favors useful knowledge for world-specific means, consequential choices, causal progression, ordinary life, idle systems and procedural content. It does not change canon-first world order or select ten implementations.
