## Scope and result

Static read of Weibao's installed Windows IL2CPP build. Il2CppDumper was built from inspected source and ran on macOS under local .NET SDK 10.0.402, target net10.0. It recovered metadata version 24.4. UnityPy 1.25.4 decoded all 462 objects in the selected master bundle without type-tree errors. This is strong data/schema evidence, not game execution or native method reconstruction. No game, injector, Windows executable or save was opened.

The strongest reference is the separation of shared item identity, destination rules and saved crafted-instance provenance. Use-based progression is also concrete at table level. P01 receipt quality and P19 paid choice behavior remain gaps. Lane status is PARTIAL because those specific questions need native consumer or binary script decoding, not because the output files are missing.

Full tables, joins, English master text and manifests are preserved in the [private reference store](private/fs-rune-factory-5/README.md). Decompiled definitions and the full event pack remain in `~/.codex/research/fs-rune-factory-5/extract/`. Public analysis paraphrases the source. No donor content or code was added to gameplay.
