# Private scalar lowering correction

Actual Ghidra12.1.4 AppleSilicon pcode overwrote the destination before reading the second scalar operand in FMAX/FMAXNM/FMIN. When destination equals that second source, the original operand disappears. This is a tool lowering defect, not a Factorio native gameplay defect.

The sole native writer preserved the original private AARCH64neon.sinc and AppleSiliconSLA, then minimally snapshots the second source in all nine scalar16/32/64 constructors. Official Sleigh compilation passed. Exact before/after hashes and identities are in [the receipt](LOWERING_REPAIR.json); originals, generated pcode, finite case details and recovered C remain in the private native reservation. Other languageSLAs/decompiler binary/install/saves remain unchanged. Shared source.sinc changes are explicit; only the AppleSiliconSLA was rebuilt.

A tiny owned synthetic Program produced48 decoded instruction samples, covering all fourmin/max opcodes, three widths and four alias forms. Evaluating the actual emitted finite pcode gave216cases:27failures before, all secondsource destination aliases, and216passes after. FMINNM's unchanged userop is excluded from that finitecase count. NaN/signaling/FPCR/signed-zero semantics are not qualified by these cases.

Exact native `ElectricEnergySource::extractEnergy` body0x1005df250 was separately decompiled from its retained32bytes/eightinstructions in a small isolated context, with the same physical X0source/D0amount/D0return signature fixed before/after. The corrected C restores the zero lowerbound before storing available energy at+0x20. Two calculation/getter control bodies produce unchanged C. Those physical prototypes follow actualloads/arithmetic/select/return instructions; hiddenX8 aggregate helpers remain a distinct ABI problem. No game or recoveredcode was executed.

All1776retained closed ARMchunks were scanned:1089latest methods contain1912changed scalar instructions, including233lostsecondsource aliases. Every affected method is queued for fullcontext refresh, with oldchunk/C/body hashes preserved privately. The remaining6095ARM initialattempts are not yet exported; rescan their bodies after completion. Isolated miniC is tool proof and does not replace the fullcontext corpus or count as1089refreshed methods. Whole x86 exports, meaningful failure/ABI repairs and final root sourcebinding/usage audit remain open.
