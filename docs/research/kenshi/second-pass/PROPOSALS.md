# Eight ranked north-star proposals

2026-10-08. **Proposals, not accepted decisions or implementation authorization.** Rank favors a connected Frontier interaction over shared-system expansion. Inspect the receiving owner's live contracts before implementation; hook existence below is source-inspected, not browser-verified capability. Each row describes a separately finishable slice, rather than one simultaneous wave.

The Red Basin's harsher dials are a separate destination proposal. Frontier can absorb social texture, work and environmental counters without acquiring mandatory starvation, slavery or limb loss. More faction life, schisms, inheritance traps and cross-life succession remain north-star ambitions; this source pass does not prove them as Kenshi systems.
