# Harry Potter source-to-playability dossier

Bounded official-companion evidence checked October 14, 2026. This is not a full read or adaptation of the seven novels. No raw book text is used. Original test premises and game-design proposals are explicitly separate from source claims.

H1: Official Wand-lighting Charm fact file: Lumos produces illumination at the caster's wand tip; Nox extinguishes that magical light. This supports a lighting function, not automatic spell knowledge, a generic mana pool or a source-specified cooldown.
Source: https://www.harrypotter.com/fact-file/spells/the-wand-lighting-charm

H2: Official Mending Charm fact file: Reparo can mend certain damaged objects. Mending the physical exterior of a broken wand does not, by itself, restore its damaged magic. The dossier supplies no numerical casting cost or duration.
Source: https://www.harrypotter.com/fact-file/spells/the-mending-charm

P1 ORIGINAL TEST PREMISE, not canon: a magically eligible adult learner owns an intact wand and has already learned Lumos and Nox. An ordinary nonmagical adult visitor owns a wand but has no magical source or learned casting. Owning a tool cannot silently grant the missing source/method. The learner is in a dim storage room and can leave freely. There is no enemy, teacher, reward, debt or mandatory quest. Reparo is a later separate learned method, not granted by this starting premise.

A1 SELECTED ADAPTER, actual source-inspected limits: the existing authored_site 14-field adapter only gathers a scalar input, consumes input in a timed work action, produces scalar output and pays fixed coins. It does not represent wand/source eligibility, learned spells, actor/wand/world scoped light, visibility consumers, object damage, magical integrity or character knowledge. Relabeling reeds as magic cannot create these readers. Other engine families exist; this test has not qualified their Harry Potter integration, and the existing Harry Potter brief remains a proposal.

O1 GAME-DESIGN FREEDOM: propose one small HP-specific practice/exploration loop using Lumos/Nox, retain leave/refuse, and name the minimum missing adapter/consumer rather than claiming it already runs. Numerical duration/energy/cooldown choices, new NPCs, quests or rewards must be labelled proposals or omitted. Treat failed/unavailable attempts as no mutation, no new mastery and no free items. Persist an accepted light state and identity under its later approved save policy; no new source/gameplay is installed by this test.
