# Wildermyth source pass

Build 21684217, version 1.16+562 Patch, is copied and audited. Retained 23,725 useful files (608 MB) privately, with every source/copy SHA-256 matched. Actual Java age, history, maim, legacy-aspect, relationship and dirty-save methods were recovered with CFR using the shipped Java 8 runtime. All installed-path consumers are released; **ready for immediate Steam uninstall** by the parent GM.

The strongest finding is that a life event changes future eligibility. A childhood creates tags that later scenes can match; a scar changes retirement age; retirement can train a chosen younger hero; a partner's death changes the survivor's remaining career. History records the cause and has separate current-campaign and legacy rules. These are connected state changes, not decorative biography.

- **F1:** Aging has stage-specific tradeoffs, including slower recovery and higher tenacity.
- **F2:** Mortal-choice survival leads through withdrawal, travel, inactive healing, a prosthetic/theme replacement and return to action. A scar and its present-campaign penalty have distinct retention.
- **F3:** Retirement passes 3/8 of the elder's experience to a selected eligible rookie, or gives a small resource alternative.
- **F4:** Childhood tags constrain later generated scenes; relationship-specific death aftermath and legacy restoration respect identity and existing partner/rival conflicts.
