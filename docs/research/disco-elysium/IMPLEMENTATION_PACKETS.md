## Compatibility and handoff

Later implementers should inspect live sources again because other sessions are editing this checkout. Existing save data stays intact. Optional new state starts empty on old saves; never reconstruct rewards or obligations from the lossy biography. A local thought-slot limit, forgetting cost, failure probability or narrator policy needs its own selected world design. These packets do not change PROJECT.md or authorize a new system wave.
