# DCSS and Cataclysm: DDA source-depth review

Completed 2026-10-05. Research findings and original proposals only. No YAIR gameplay changed.

The best transfer is a small durable record of difficult things the player actually did. YAIR already has finite endings, earned methods, meaningful combat responses, independent resident lessons/work and repeated contests. The useful additions are qualified feat receipts, one voluntary local conduct challenge, one defense-earned opportunity and function-oriented practice stopping. A general achievement engine, another martial-art subsystem and DCSS-style spatial simulation would add duplication or disproportionate cost.

## Seven concrete paths

**C1: collectible eligibility → escape → recorded run.** Rune acquisition sets a distinct-rune bit. Default Zot entry checks the three-rune requirement; descent mode differs. Leaving the dungeon with the Orb classifies a win, while leaving without it is a different outcome. The default score includes experience, distinct runes and gems, with a winner rune/turn component; it deliberately excludes carried item value. `end_game` writes high scores and a logfile, with wizard/explore exclusions by default. Sprint has a custom-score escape hatch. These are actual run records, not evidence of a formal general achievement catalogue. External tournaments, banners and account tracking were not reviewed. See [rune collection](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/items.cc#L1914), [eligibility](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/main.cc#L1443), [escape](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/stairs.cc#L868), [score](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/hiscores.cc#L1672) and [end record](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/end.cc#L275).

**C2: weapon brand → eligible hold → continuing harm/release.** The entangling brand has actual data weighting and a runtime branch. It rolls, then checks resistance, current hold, reach and capacity before storing both actor identities and hold type. Continuing constriction has real armor/time-scaled damage and death consequences. Actor life, sight, reach, movement and sanctuary can terminate it; actor-linked hold fields serialize. This is a lifecycle, not a bonus tooltip. YAIR's native arena currently lacks the tile geometry needed for a faithful spatial hold, so a broad tether system is a poor first fit. See [brand data](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/item-prop.cc#L464), [application](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/attack.cc#L1412), [actor lifecycle](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/actor.cc#L600) and [saved hold](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/tags.cc#L742).

**C3: selected training → spent XP → target reached/saved skill.** Exercise queues affect automatic allocation; selected/focused skills affect manual allocation. Exercise alone is not free skill XP. Training spends available XP, adds skill points and consumes finite manual bonuses. A valid base or modified target stops training when reached, announces the result and persists alongside skill points. Species/mutation exceptions and DCSS's level ceiling are real source rules, not YAIR requirements. See [allocation and exercise](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/skills.cc#L762), [paid growth](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/skills.cc#L1630), [target stopping](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/skills.cc#L1274) and [saved points/targets](https://github.com/crawl/crawl/blob/b005dc6fb05073307685cbb4d3ccec29962e6c2c/crawl-ref/source/tags.cc#L1805).

**D1: achievement data → attributed event/statistic → durable completion.** JSON declares comparisons, optional time bounds and visibility. A real non-hallucination monster death emits an attributed kill event; summoner attribution can apply. Avatar and species transformations feed the zombie statistic. Watchers track requirements and record completion once with the turn and current values, then remove that live tracker. The callback emits an achievement event and configurable notice; this reviewed path grants no combat power or item. Status serializes, and a separate completed-ID/avatar record supports past achievements. See [definitions](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/data/json/achievements.json#L1), [statistics](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/data/json/statistics.json#L30), [death event](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/monster.cpp#L3123), [tracker](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/achievement.cpp#L670) and [callback](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/game.cpp#L413).

**D2: conduct data → forbidden attributed result → durable failure.** No attacks and no kills are separate conditions. A conduct is not completed like a positive achievement merely because it still holds. A monotonic condition becoming false records failure once and produces a distinct conduct-failure event. This uses the shared engine above, rather than a separate independent event implementation. A global pacifist rule would need an attribution audit; the bounded YAIR substitute is a voluntary local no-strike contract. See [conduct definitions](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/data/json/conducts.json#L9), [failure handling](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/achievement.cpp#L682) and [conduct callback](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/game.cpp#L444).

**D3: martial requirements → actual block → timed cost effect.** Aikido data has skill-gated static tiers and a one-turn block-triggered move-cost buff. Requirements inspect skill, armedness/style compatibility, flags and required buffs. Candidate buffs are all qualified before application, so that batch does not accidentally chain through newly applied buffs. Native block resolution spends stamina and dispatches the effects; timed effects feed native attack cost. Owning a style alone is not the block event. See [data](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/data/json/martialarts.json#L28), [eligibility](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/martialarts.cpp#L744), [batch application](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/martialarts.cpp#L1178), [block dispatch](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/melee.cpp#L2215) and [cost consumer](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/melee.cpp#L2690).

**D4: practice recipe/tool eligibility → paid work → mastery without product.** Hydraulics practice specifies bounded skill difficulty, plumbing proficiency, time, tool qualities, a charged reusable kit and a book source. Start checks actual requirements and inventory. During work, resource/tool shortfalls stop advancement before skill gain; skill and proficiency progress are real work effects. Helpers learn at qualified rates and a knowledgeable crafter can boost proficiency learning. Practice completion creates no item; normal reference-based craft has a separate memorization path. This adds the work/output distinction to prior proficiency findings, not another claim of a missing method engine. See [recipe](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/data/json/recipes/practice/mechanics.json#L1), [bounded difficulty](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/recipe.cpp#L90), [start eligibility](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/crafting.cpp#L656), [paid progress](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/activity_actor.cpp#L6835) and [no product](https://github.com/CleverRaven/Cataclysm-DDA/blob/a68ad093f6f89f3e7d29ad62cbb7fcde46acfd25/src/crafting.cpp#L3722).

## Four ranked original transfers

1. **Keep earned feat receipts beside existing endings.** Record the player's actual route, cause and result for a few substantial field accomplishments. An early ordinary solution and later mastered alternative can both matter; the existing stock, route and relationship effects remain useful. This is a new qualified view over existing outcomes, not a new reward economy. Medium cost: small versioned feat definitions and durable receipt lifetime. Later gate: commit one result, see it once, retain it after generated save/reload, and get no receipt from preview, failed settlement or repeated polling.
2. **Offer one voluntary local conduct challenge.** Enroll before an attempt and try to secure sluice passage without making a strike. Support, objective work and the long walk provide concrete alternatives. Mature methods make later attempts more interesting; completed, violated and withdrawn outcomes remain distinct. Medium cost: attempt scope and violation set by committed actions, with any recognition requiring a real witness/report. Later gate: preview does not violate; a committed strike does; a later eligible route earns one certificate. Ordinary passage remains available and past saves are not judged.
3. **Earn a short retreat opening from actual defense.** After a qualified block or release-pressure outcome, choose a one-action exit discount or counter opportunity. Current guards, anchored resistance, hook equipment and injury costs remain relevant. The current arena already has much of the structural pattern, so this is a small extension. Low to medium cost; full spatial tethering is excluded. Later gate: the exact defended event produces one window, unsupported/evasive events do not, and using/expiring it prevents repeated free discounts.
4. **Stop a paid practice plan at a useful function.** Choose a next supported method function and stop funded known practice when it is earned, with a finite maximum. Current mastery bands and resident demonstrations already supply the progression. Low cost for authored finite steps; medium only if a reusable saved goal predicate becomes necessary. Later gate: actual funded jobs unlock the function, the plan stops before another reservation, and tool/source loss pauses rather than creating free growth.

[FINDINGS.json](FINDINGS.json) includes each recommendation's early-to-late development, reward/aftermath, exact consumer owners, compatibility decision and later playable gate. Proposed names, numbers and fiction remain reversible design choices.

This is selected semantic source coverage, not a whole-repository audit, game session, balance comparison or exploit review. No game was installed/launched; no build, test, browser, regression or private-save operation ran. Runtime, dependencies, source libraries, global docs, commits, publication and commercial acquisition stayed outside the writer scope.
