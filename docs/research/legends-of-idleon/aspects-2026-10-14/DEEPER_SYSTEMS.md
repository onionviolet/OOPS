Limits: Shared quest completion is not proof that every actor had the same conversation. Full definition field layout and every callback remain unread. Sources: A01/A02/A04, frozen N.js quest-complete.txt and save-dispatch.txt.

## D2 Cloud bridge and schema ownership

N.js beginSave emits CSver=33.05 and typed scalar/list/map/JSON/sparse entries. Active-character fields use a suffix derived from roster index; account stock does not. Limits: Client schema construction is shown, while storage durability, authoritative server timestamps and duplicate claim control are outside the inspected boundary. The host bridge is not a complete save implementation. Sources: A03/A04/A09.

PROPOSAL: audit scope and schema version for a single existing YAIRPG settlement receipt, then validate old-save fallback and stale-repeat refusal. Owner: engine save review.
