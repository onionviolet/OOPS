# Small touches

PROPOSALS only. These adapt patterns from the cited finding; YAIRPG details are not Idleon feature claims. Existing UI/Engine owners retain authority. All UI candidates target desktop 1366×768; mobile deferred.

| ID | Candidate | Intended visible behavior | Evidence |
|---|---|---|---|
| S01 | Current job icon | Represent the actual known assignment, not the strongest class. | F5 |
| S02 | Away duration | Show a readable duration beside the job, with game time and wall time distinguished. | F4 |
| S03 | Current character marker | Distinguish current control from another actor doing background work. | F5 |
| S04 | Useful role label | Name a contribution such as supplies or support rather than just combat level. | F3 |
| S05 | Shared badge | Mark an effect as shared only when its real scope is shared. | F2 |
| S06 | Personal badge | Mark equipment and mastery as personal even beside shared upgrades. | F2 |
| S07 | Enrollment reason | State a known local enrollment requirement instead of silently showing zero output. | F2 |
| S08 | Rate units | Use items per game hour with the clock basis visible. | F4 |
| S09 | Limiting input | Show which actual material or capacity stops a job. | F4 |
| S10 | Ready versus paid | Distinguish finished build time from unpaid final inputs. | F1 |
| S11 | Full versus growing | A full store stops; a growing mature crop may still improve. Display the real case. | F4 |
| S12 | Redundant support | Warn when a second support assignment adds no benefit, if the model proves it. | F2 |
| S13 | One support, several effects | List useful connected outputs of one support assignment. | F2 |
| S14 | Freed assignment | Show an earned aid that makes an actor available for other work. | F6 |
| S15 | Source of rate | Link one large modifier to its known acquired source. | F4 |
| S16 | Effective and base values | Distinguish a stored sample from its boosted actual output. | F4 |
| S17 | Known risk bands | Show a known risk band plus an exact chance when the game knows it. | F5 |
| S18 | Recovery timer | Show why a failed worker is recovering and when the task can resume. | F1 |
| S19 | Change costs | State the real cost of switching a known assignment before commitment. | F2 |
| S20 | Collection shortcut | Link to a discovered producer, preserving remote-operation restrictions. | F5 |
| S21 | Observed log only | Receipts use received evidence; private simulation history stays private. | F5 |
| S22 | No reward on review | Viewing past work never settles it again. | F4 |
| S23 | Alternative route | Explain a known substitute input or method rather than treating one path as universal. | F1 |
| S24 | Local carry rule | Put a known carryover restriction beside the affected action, not only in distant help. | F6 |
