# Contradictions and useful distinctions

C1, STATED: the March 2026 archived Trendy page lists Hardcore Unblemished Uniform equipment, while the special-path index lists stainless equipment. Preserve both claims. No account/server reward was checked, so the actual present reward remains OPEN. The individual page also contains an editorial uncertainty note about date restrictions. A dated wiki capture is readable evidence, not infallible rules authority.

C2, STATED: the general special-path index says the seasonal extra Karma is 50 Normal / 100 Hardcore, but the individual Grey Goo page describes 50 for either format during its debut season. Grey Goo is an explicit exception, not grounds to silently rewrite the general rule.

C3, SHOWN: enum path defaults are not effective capacities. Boris's path enum has default organs, but its class has 20/4; Bond's enum liver base is 2, but the rule page says it grows with level. `isAvatar=false` also does not imply ordinary classes: West and Shadows supply new class choices. Any flat enum export must retain these qualifications.

C4, STATED: the 2018 index gives G-Lover a Spring season label, while later indexes correctly describe its May-August summer interval. Use dates and later captures for chronology; do not promote the 2018 label into a current claim.

C5, SHOWN / INFERRED: `wereprofessor.txt` contains an Unimplemented annotation. This is a client data annotation. It does not establish whether the corresponding server-game mechanic exists, and cannot be used to declare the game feature absent.

C6, SHOWN / STATED: names usually label stable IDs, but some challenge paths deliberately use letters in names as mechanical input. Two Crazy Random Summer changes presentation and properties without replacing underlying item identity. A general “rename is cosmetic” policy therefore needs declared exceptions.

C7, INFERRED: the prior fixed-spine/one-or-two-rules summary was too broad. There is strong reuse, but paths also replace objective graphs, body equipment rules, resource conversion and whole combat models. The claim that learning cost stays small or that this caused 20 years of survival was not measured.

C8, STATED: Class Act II's page marks its old doubled-combat/halved-noncombat stat gains as obsolete after May 14, 2014. The older index still mentions them. Keep historical changes separate from rules that still distinguish the path.

C9, STATED: Slow and Steady's page says bottled day stopped dropping at the season boundary even for a run begun earlier. This qualifies the index's general start-in-season reward explanation. Earning conditions require reward-specific checks. The same page names aftercore exceptions to the otherwise flat turn supply.

C10, STATED: the November 2023 Pocket Familiars capture says Standard restrictions had not ended even though the path was long out of season, and describes infinite Normal Ronin. This contradicts a universal reading of the index's “past paths lose Standard” rule. Present server status was not checked.

C11, SHOWN / STATED: JourneyManager describes indexed awards at turns 4, 8 and so on, while the archived Journeyman page describes three adventures followed by a free learning encounter. Keep paid adventures and encounter indices separate. Their exact runtime counting was not exercised.
