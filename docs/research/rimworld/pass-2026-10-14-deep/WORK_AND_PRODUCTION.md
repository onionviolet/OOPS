# Work and production: intent, admission, execution and report

**SHOWN priorities F10:** Pawn_WorkSettings retains priorities 0-4, validates disabled work, marks ordering dirty and rebuilds normal/emergency givers. Lower positive priority sorts ahead using natural priority as a tie influence. JobGiver_Work walks givers and checks actor restrictions, skip logic, target availability, reachability and priority/distance. Its job-driver route is an ordered autonomous selector, not a general dependency planner.

**SHOWN bills:** Bill_Production.ShouldDoNow handles suspension, forever, finite iterations and target stock. Target mode can pause at targetCount and resume at unpauseWhenYouHave, avoiding repeated tiny batches. ShouldDoNow writes paused, so it is not a pure inspection function. Notify_IterationCompleted decrements finite counts on completion. Settings, pause and store/count scope are serialized. RecipeWorkerCounter counts map resources or scans storage, carried/equipped/minified goods using quality/health/stuff/taint/fog settings. It does not mean all possessions across the planet. In this 1.7 export the List<Thing> CountValidThings overload increments once per valid entry, while several other branches add stackCount. This is a source-level counting discrepancy, not a reproduced native bug; a future stock policy must declare units rather than assume all paths count identically.

**SHOWN blockers F11:** WorkGiver_DoBill first checks bill giver type/usability, pending work, fuelability, reservation and fire. It then walks eligible bills, checks skill, worker restrictions, special medical/mech states, unfinished work and ingredients. Explicit reasons include insufficient skill, a respected reserver, restricted medicine, waste capacity and missing materials. Missing ingredient detail is collected in the forced-menu route. Normal scanning can schedule a retry 500-600 ticks later instead. Multiple earlier gates return null without writing a reason. This does not establish an always-visible per-pawn causal diagnosis. Keep selected job, current absence of a job and actual last completed receipt distinct.

**SHOWN chains F12:** Recipes_Butchery defines a corpse input with a Butchery special product and actor efficiency, not fixed meat/leather totals. GenRecipe calls each ingredient's ButcherProducts. Recipes_Meals uses a nutrition value getter: simple meals take 0.5 nutrition and produce one meal, so a count of 0.5 is not half a physical object. Drug ThingDefs use recipeMaker and costList: tea/flake/yayo share psychoid leaves with different stations/research/skill routes. Their generated recipes are absent from the raw standalone RecipeDef total. SmeltWeapon/SmeltApparel use Smelted special products; SmeltOrDestroyThing can accept a broader set with no useful output for a non-smeltable input. Source-specific material recovery bodies remain unread.

**SHOWN settlement:** Toils_Recipe.FinishRecipeAndStartStoringProduct constructs products, consumes ingredient objects, notifies iteration completion and records production before it places/hauls results. GenRecipe can carry ingredient provenance, stuff, color, quality and ideology style into products. A stored product, produced product and delivered/usable product are different stages. The mutable donor code does not prove transactional recovery if placement or saving fails.

**INFERRED RW-D1:** extend selected P01 Village mixing using existing truthful plan and receipt projection, not a fresh work engine. Distinguish player pause, target met, missing known means, unavailable target and no known explanation. Queue eligibility must use the same authoritative reader at execution. Keep routine action, reason and actual last result side by side at 1366x768. Hidden alternatives cannot leak through blocker lists.

**INFERRED RW-D8:** extends P02/P08/P18 and K8/K9/K13/K18/K26: explicit stock unit/scope, one target with lower resume threshold, one alternate use of the same output, interruption and durable receipt. Do not import hunger death or global unattended harm. YAIRPG ordinary food remains beneficial and optional under current direction.
