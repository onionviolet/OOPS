# Proto-like mechanics survey, 2026-11-27

Read-only survey of four Proto23-family games for mechanics OOPS could pull, run by a Sonnet reader over shallow clones in `.local/protolikes/` (not committed). Companion to [PROTOLIKE_SCAN_2026-11-27.md](PROTOLIKE_SCAN_2026-11-27.md). Licensing: GauTech Experiment is MIT, so its code can be ported with attribution. NekoRPG own additions, CATA and Arkivia have no license (ideas only, OOPS writes its own code). Coordinator spot-check: Experiment `display.js:5231` map overlay and `main.js:2929` counterattack confirmed. Correction: OOPS has a counterattack in scripted chronicle fights (`src/chronicle.js:281`) but not in regular combat. Rankings are proposals, not decisions.


Read-only research. Nothing was run, built or edited outside this file. Labels: **shown** means I read the code at the locator; **inferred** means a reasoned guess from names, diffs or comments. Locators are relative to each repo under `.local/protolikes/`. OOPS fit codes: (a) already in OOPS, (b) new and fits, (c) new but conflicts with OOPS direction, (d) content only.

Companion record: `docs/research/PROTOLIKE_SCAN_2026-11-27.md` (Discord scan, YAIR dev gap). That file has the YAIR dev map prototype (`src/mods/map.js`), which matters for item M1 below.
