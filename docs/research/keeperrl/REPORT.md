## Five interacting paths

| Path | Actual code-observed chain | Boundary that changes the result |
| --- | --- | --- |
| K1: independent work | Minion activity checks individual need/trait/skill state; an actor chooses eligible work, then claims a reachable task with priority, ownership and transfer rules. Eating consumes a real item and applies satiety. | No destination/food gives no need reward. Reassignment is limited; the priority-dispatch branch ignores returned task-cost values, an observed exception rather than a refund policy to copy. |
| K2: materials and equipment | Workshop queue debt becomes paid stock; eligible skilled work creates a real item. Individual equipment ownership selects and retrieves compatible gear. | Unfunded/low-skill/missing-upgrade work produces nothing. Paid queue cancellation refunds only before progress. Locked equipment and unsupported retrieval can prevent use. |
| K3: training and body | A successful eligible furniture action invokes bounded training. Attribute growth feeds an actual body-qualified strike and defense/damage/effect consumer. Injured parts can remove attacks and equipment support. | Facility and creature caps differ. Archery availability checks a carried weapon; no supported body weapon means no attack. Lethal/capture damage can return before later effects. |
| K4: construction and invitation | Construction reserves actual cost, completion updates built facilities, and built attraction/population enters live recruitment admission. Acceptance spends requirement resources and occupies attraction; an existing source recruit can transfer as the same actor. | Removing unbuilt work returns reserved cost. Admission rechecks funding/attraction/spawn, but its population comparison is current population >= cap rather than full-group fit. Generated-candidate fallback is distinct from actual recruit transfer. |
| K5: faction/world consequence | Attributed theft/casualties/building/wealth pressure feeds an eligible surplus-fighter attack. Actual goals can steal, request payment, return or retreat. Stun/death/conquest updates retained campaign access. | Pressure values use a maximum, not a sum; activation, base presence, sunlight, available fighters and a draw still matter. Ransom cancels the visit without erasing the grievance or crediting the attacker's purse in the inspected branch. |

Exact file/symbol/spans and whole-file/span SHA-256 values are in [FINDINGS.json](FINDINGS.json), with detailed reader notes in [actors/materials](ACTOR_MATERIAL_NOTES.json), [training/body](TRAINING_BODY_NOTES.json), [base/recruitment](BASE_RECRUITMENT_NOTES.json) and [world consequences](WORLD_CONSEQUENCE_NOTES.json).

Key anchors: [actor/task claiming](https://github.com/miki151/keeperrl/blob/95d2be4e97db2243210a71918e36a533ad94dcd1/task_map.cpp#L64-L114), [paid work and output](https://github.com/miki151/keeperrl/blob/95d2be4e97db2243210a71918e36a533ad94dcd1/workshops.cpp#L47-L132), [bounded facility growth](https://github.com/miki151/keeperrl/blob/95d2be4e97db2243210a71918e36a533ad94dcd1/collective.cpp#L1583-L1619), [body damage](https://github.com/miki151/keeperrl/blob/95d2be4e97db2243210a71918e36a533ad94dcd1/body.cpp#L781-L818), [invitation acceptance](https://github.com/miki151/keeperrl/blob/95d2be4e97db2243210a71918e36a533ad94dcd1/immigration.cpp#L487-L517) and [faction admission/dispatch](https://github.com/miki151/keeperrl/blob/95d2be4e97db2243210a71918e36a533ad94dcd1/village_control.cpp#L346-L462).

These paths share actual owners: actor tasks perform workshop/facility work; conserved materials fund construction and recruitment; completed facilities support training; actor attack/defense attributes contribute to faction danger; attack dispatch releases previous work and losses remove actors; conquest affects campaign influence consumed by travel and active-faction updates. This is a static causal trace, not a claim that every branch necessarily happens together in one game session or that cache/timing/balance is verified.

## Current YAIR fit

Current source already has independent controller choices, finite resident purses/work, consent/refusal, stock/custody/equipment, useful material variants, facility projects, body recovery, functional mastery, native combat and retained grievances. `field_workshop.js` already spawns a funded pathfinder before project completion. `feature_expansion_society.js` already gives Orr repair/teaching priorities and Vale independent answers, work and handoff. `feature_expansion_nested_chains.js` already retains the forced-outlet grievance, funded audit and material restitution. Existing Qud and DCSS/DDA reports were reused as comparison owners; their older proposal wording is not evidence that these current systems are absent.

The four proposed additions are narrower: residence occupancy plus funded invitation; allocating one actual tool between alternative useful worker jobs; one trained Conditioned grip combat-cost consumer; and one funded local collection response with actual actor movement/means and changed access. They reuse the current publisher and require explicit save/retention decisions. No wholesale dungeon game, generic new NPC/equipment engine, additional prestige, background hunger economy or copied mechanics catalogue is selected.

`FINDINGS.json` freezes inspected moving YAIR file hashes and exact spans, including the actual storage-before-publication path. The shared checkout is dirty and other GMs are active. A later implementation owner must refresh these inputs rather than treating the repository HEAD or an old bundle as the complete source snapshot.
