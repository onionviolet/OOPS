# Coverage and limits

**Seen in data or code:** resources.assets scanned for TextAssets, 26 exported and hashed. Event/quality tables parsed structurally; root counts are inventory only. Targeted semantic reading covered successor selection and transfer, will death branches, lodgings/study inheritance conversion, family/Scion, hunger/starvation, selected terror outcomes, retirement and sacrifice. All 29 persistent quality flags were enumerated. Private STRUCTURAL_TRACES stores selected gates, effects and links.

Managed method bodies exported using ILSpy; reviewed LegacyProvider, LegacyPanel copy/selection, EventRepository, StoryletProvider, SailingUpdates hunger/gloom timing, NavigationProvider hunger/gloom, SunlessCharacter date handling, Branch, Character.MoveToEvent, QAssocRequirementExtensions, ChallengeArbiter, main menu mode text, FileHelper resource loading and BaseCollectionRepository input path. Exporting other classes is not reading them.

**Seen in data or code:** Unity resource tables differ from DLL embedded tables. FileHelper.LoadResourceTextfile loads SunlessSetupData through Unity Resources; disk-imported overrides may replace/add content later. The audit does not inspect a user's generated application files, settings or saves. Hash provenance distinguishes the two sets.

DLC: manifest declares installed depot452532 with dlcappid452530 (Zubmariner). Resource tables contain submerged content and code has IsZubmariner branches; data presence is verified, entitlement and activation are untested. Cladery Heart and Pirate Poet quality/DLC mappings are present in BaseRepository; their entire stories were not audited. Oxygen, submerged death achievement checks and constant companion hooks were noted, not complete underwater coverage. No soundtrack/art analysis.

Opaque/unread: every narrative row, every exotic effect, full UI/prefab wiring, combat, exact map re-generation/discovery-reward rules, serialized player state, cloud saves, imported overrides, balanced timing and real runtime. No launch was allowed, so there is no play or save/reload/import evidence. Source-body recovery alone does not prove a working game or an authored YAIR slice.

Public source: the developer comparison was read as historical explanatory text. Failed Reddit fetches were not retried or used as evidence. Player complaints are represented only by the developer's explicitly reported feedback.

Disk: extraction remained below200 MB; redundant icon archive removed from our private export. Useful code/table inputs retained privately with SHA-256. Install remained untouched and installed; Weibao manages removal. Assigned finite pass complete, not exhaustive whole-game coverage.
