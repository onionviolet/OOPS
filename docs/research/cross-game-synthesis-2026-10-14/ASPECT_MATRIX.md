# Aspect matrix, 2026-10-14 follow-up

**PROPOSALS only for YAIRPG adaptations.** The matrix reports the source lanes' research status, not acceptance or an implementation order. It covers **35 available aspect packages and 420 A01..A12 cells** at the pinned snapshot, including the nested Path package. Twelve columns are split into three tables for reading width; each table has the same game/dossier rows. Every cell gives the exact source status and a one-line method condensed from its summary. An ellipsis means the rest of the source summary remains relevant.

**Status legend:** C = covered at the lane's bounded evidence depth; P = partial; U = unread; A = absent in the explicitly inspected scope. Covered can mean a static architecture answer and does not mean every row, current server, browser UI or gameplay was exercised. Absent is never a whole-franchise claim. Melvor is declaration-only STATED evidence even where it names an API; Tale's current tables and historical native receipt remain separate.

Combined dossiers retain their supplied shared rating. The rating is not independently reassigned to every constituent game: DCSS differs from CDDA, KoLmafia is a client, and the Gu material is store-level. Rewritten/Communitree and Profectus are not three independent proofs of a game mechanic. The full per-cell source path and summary hash are in PATTERNS.json; the source file has each cell's complete summary, evidence locators and proposal owner.
