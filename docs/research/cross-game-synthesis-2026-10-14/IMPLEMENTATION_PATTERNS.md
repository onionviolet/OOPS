## Current YAIRPG boundary and the profile audit

**SHOWN now:** [save_files.js](../../../src/save_files.js) validates native envelopes; decodeSaveFile admits the marked UTF-8 transport and older encodings. importSaveFile decodes, awaits real-loader preflight and only then performs a guarded write. [import_probe.js](../../../src/import_probe.js) uses a disposable same-origin instance, a token/source/origin check and bounded loader-warning failure. This research did not run an import.

**SHOWN now:** [main.js](../../../src/main.js) still has named-field create_save, selected live/dev slots, a selected-key Web Lock and lifeSaveStorage. That adapter stages biography/NPC observations, performs writeGuardedSave and publishes after success. persistExpansionPlan receives it as its storage seam. A one-key guarded setItem is not an already implemented multi-branch transaction. Existing native import must not receive an outer profile object as if it were a native envelope.

**SHOWN now:** [structured_pack_state.js](../../../src/structured_pack_state.js) checks exact structured beginning identity/hash/revision; main preserves an unavailable structured save for recovery. [simple optional packs](../../../src/content_packs.js) have a different parking/restoration path. [retired-content preservation](../../../src/save_compatibility.js) retains selected old data. Unknown future/malformed schemas are not automatically executable dormant branches. Keep those three policies distinct.

**SHOWN now:** save_to_file can update an export-reward timestamp, grant an inspiration reward and attempt storage. Therefore exact-byte pre-migration recovery copying must use a distinct non-gameplay route. Current saved_at is a calendar/date representation and is not an already selected wall-ms offline cursor. This matches the audit's warning; its old line numbers and measured fresh-save size are historical measurements, not a fresh campaign/profile budget.

The profile audit's **INFERRED S1/M1-M8** provide P23's optional migration direction. Its reported 49 tests and RAM-only serializer measurement belong to that lane; they were not rerun here and do not test proposed profile code. Current source inspection establishes routing seams only. No new general profile/branch implementation was inferred from the document.
