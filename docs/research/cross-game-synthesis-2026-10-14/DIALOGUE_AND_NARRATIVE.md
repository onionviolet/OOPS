## The current YAIRPG seam

**SHOWN in current source:** [ink_narrative.js](../../../src/ink_narrative.js) already retains legacy and scoped sessions, compiled content hashes/revisions, runtime/story/cursor formats, a safe response frame, sequence/clock tokens and host receipts. It selects a stable response tag rather than using its current visible list position. Hosts implement observe/preview/commit; the returned plan contains both the new cursor and actual native changes. Continuation rejects command/reward tags and binds no EXTERNAL callbacks. This is an existing implementation seam, not a request to install another Ink runtime.

[ink_scene_content.js](../../../src/ink_scene_content.js) binds known observer variables and supported response IDs to destination/replacement/nested host commands. [ink_narrative_ui.js](../../../src/ink_narrative_ui.js) renders safe paragraphs/choices and submits the displayed token; the host owns legality and durable acceptance. The current paragraph representation is not a complete typed speaker/recipient/manner transcript. If a selected scene needs that, add a narrowly versioned frame extension with old-frame defaults rather than rewriting all story storage.

[persistExpansionPlan](../../../src/expansion_persistence.js) copies the native envelope, adds staged expansion/money/items/equipment/native changes, validates and writes before caller publication. [lifeSaveStorage in main.js](../../../src/main.js) stages life/NPC observations around the guarded write. Renderer updates and a copied cursor are not evidence of durable commit. This lane did not run the native conversation.

Existing native dialogue data/components and [DialogueAction](../../../src/models/dialogue_action.js) remain usable for fitting small interactions. Source protocols differ: adapting a legacy component to the scoped Ink host is a concrete join to assess, not an assumed interchangeable API. [lore history](../../../src/lore_history_state.js) has typed cause/audience/applied-delta records and consumer pins; [biography](../../../src/life_record.js) is deliberately lossy and cannot own reward/relationship/quest truth.

## Proposed narrative state contract

INFERRED adaptation: keep authored content identity separate from the occurrence (world/instance/scene/participants), observer knowledge, current decision/cursor, pending action, and settled outcome. Speaker, recipient, visible line and portrait cue belong to presentation metadata, while presence/body/permission/cost/outcome belong to host rules. A reread can repeat words; it cannot repeat a settled transaction. The same event may recur as a new valid occurrence under world rules.

| Code | Distinction to author | Evidence and receiving packet |
|---|---|---|
| N1 | Hidden alternative versus known unavailable response | Vagrus original indices, Legacy visible/selectable fields, CDDA failure explanations; P04/P19. Protect undiscovered option identities and counts. |
| N2 | Attempt success versus progress and bonus | Academagia research can deposit progress without gaining a level; adventure benefit threshold differs from exit success. P09/P19 preserve distinct receipts and useful next play. |
| N3 | Interruption versus completion versus closure | Path onClose/onFinish differ; Taiwu exit/remove/complete differ; current Ink pause/resume preserves boundary. P19/P24. Never bind a payment to closing a modal. |
| N4 | Occurrence versus account outcome versus private memory | Taiwu information circulation and Idleon selective propagation. P11/P20. Sharing a facility/quest outcome does not copy a private conversation. |
| N5 | Received versus noticed/read versus claimed | Bitburner suppressed popup still delivers; Legacy/Immortal Life correspondence schemas supply weaker comparative detail. P20 owns one useful original report without inventing their untraced delivery logic. |
| N6 | Ambient arbitration versus conversation branch | Discworld/DCSS/Legacy separate context, perception, priority and repetition. P21, using explicitly known clocks rather than guessed source units. |
| N7 | Transcript/history versus causal authority | NetHack synopsis, Immortality retained story versus compact routine logs, and YAIR lore receipts versus biography. P01/P12/P24. A short recap links actual cause, not reconstructed rewards. |
