# Reusable research flow: emergence from rules

This is a saved research method, not an implementation requirement or permission to run games.

1. Pin the exact installed input and retained copy with build identifier, native/managed format, hashes and original path. Reuse a stable private extraction; do not duplicate a full library merely to obtain another receipt. Identify readable shipped source separately from recovered native functions.
2. Inventory all definitions/classes, then select concrete causal chains. For each producer, locate the stored state, target/body/material eligibility, event/AI consumer and downstream world effect. Keep captures, text searches, selected windows, full semantic reads and observed execution as different statuses.
3. Trace combinations through the actual consumer order. Include negative tests on paper: excluded tags, missing organs, wrong phase, absent source, insufficient resources, interrupted action, already-affected target and ownership changes. An advertised power does not prove its producer is reachable.
4. Follow cleanup as its own branch: expiry, cancellation, unapply, actor death, source loss, body removal, item destruction, save/reload and offscreen boundaries. Record what is reversed, what persists, and which references or resources remain. Distinguish effect ending, physiological repair, rollback and deleting an actor.
5. Save complete private source/definitions and decoded flows, public paraphrases with exact hash/line locators, machine-readable coverage/unread ledger and a checkpoint. Independent audit verifies the claimed joins and corrects overclaims. Stop at a named missing consumer; deeper native decompilation should answer that question rather than generate an unread binary dump.

For NPCs, separately record capability, information/perception, target admission, decision preference, execution cost and observable consequence. Usage hints or actor-agnostic event handlers alone do not prove autonomous use. A native closed engine must remain a native gap unless an exact function or measured behavior has actually been recovered.
