## What became clearer

Interesting decisions and authored rules qualify regardless of genre resemblance. Source access affects what can be demonstrated or implemented, not whether a design is worth considering. The [genre-open/deeper owner](../game-discovery-2026-10-06/DEEPER_RESEARCH.md#genre-open-direction-clarified-by-weibao) and current shared assignment retain the broader direction. Small packets are a separate selection layer; they do not cap the larger system implications.

Current YAIRPG source already supports real paid work, current means/body/site/participant checks, native/simulation ownership and custody, numeric gear quality, personal energy, directed memories/knowledge, institutional claims, finite work plans, world instances, one integer played clock and one durable publisher. Its Ink bridge stages retained content/cursor and host effects together. Original source/native/UI delivery remains implemented-unverified under its own released remainder scope; this scout performs no build/gameplay/save test or shared runtime write.

The new questions are specific: how ongoing infrastructure behaves when supply changes; how physical goods age independently through holders and reservations; how a supported evidence pair changes a currently applicable right; and how a physical local rule arrangement changes the environment. They are not satisfied by another recipe, quality multiplier, dialogue flag, personal mana pool or generic scheduler.

## Strong connected mechanisms and failures

**Infrastructure has a startup burden, a buffer and a later consumer.** Mindustry's impact reactor must receive input/power support before its nonlinear generation rises. Actual connected demand can consume the battery reserve needed for startup. Graph balance draws only stored energy for deficits and charges surplus; a crafter's partial work and retained machine survive shortage. Delivered silicon can fund a larger battery, changing future startup/outage choices. Non-power input shortage/output backpressure and ordinary impact starvation differ from thorium's genuine cooling-failure heat/destruction route. Selected state writers were read; complete corruption recovery, offline/remote sectors and every acquisition gate were not. [Pinned source trace](traces/MINDUSTRY.md).

**Evidence can alter permission without changing identity or affection.** Creator material for Papers, Please describes intentional pair comparison, further questioning/documents, separate identity verification versus document validity, current institutional requirements and work/earnings/campaign reach. Some wage/family/exception discussion is historical prototype material, with exact current formulas unread. The2022 mobile explanation preserves discrepancy selection while changing presentation. Original YAIRPG transfer: an old authentic work authorization can conflict with a current posting; a paid physical inspection and willing exception can grant one repair right and enable useful teaching after actual completion. No omniscient citation or copied fine formula is selected. [Creator/source boundary](traces/PAPERS_PLEASE.md).

**Physical clauses reach real behavior, with two different mutation kinds.** The jam's Lua follows word positions into a feature list, matches subjects/properties, then reaches movement obstruction/control/contact consumers. Noun identity conversion uses a separate host callback. This supports a bounded local configuration lens; it does not prove automatic rule-rebuild timing, current retail condition/meta grammar, undo or durable campaign reversal. A declared physical arrangement can change a useful local operation, with a different policy for changing an object's identity. [Archive/hash and callback limits](traces/BABA.md).

**Goods can have independent life histories and terminal uses.** Factorio's selected stable living-input definition joins acquisition age, reproduction inputs/fuel/environment, terminal research and hostile expiry. Its other path generates lossy reverse recipes from actual useful armor, while quality-qualified grid capacity can change what real equipment fits. Public Lua/API reading does not expose C++ spoil merging, mid-craft failure, random quality yields, grid insertion or full research execution. Native YAIRPG item keys already distinguish ID/components/quality, but the inspected contract does not identify independently aging lots. Adding a temporary actor condition or arbitrary ignored JSON key would not preserve actual stock/custody. [Versioned source/API trace](traces/FACTORIO.md).

## Engines, authoring speed, maintenance and recovery

The incumbent remains the supported route. These interesting systems depend primarily on domain rules/state/consumers, not a renderer. Original site work and evidence comparison can use existing native menus/Ink with state additions owned by the integrator. A local rule or layout deserves spatial presentation when geometry changes an actual decision, rather than merely illustrating the same buttons.

The first pass already reviewed [XState](traces/XSTATE.md), [Godot](traces/GODOT.md) and [CK3](traces/CK3.md), now historical comparison/background outside the active five. Those source/maintenance limits remain: a statechart can author one goal but supplies no motive/resource authority; a Godot bridge still needs current native/save/Ink/clock/recovery contracts; documentation of political leverage is not a reusable proprietary algorithm. No new migration benefit was demonstrated by this continuation.

A full Mindustry graph port requires Java/Arc/generated entities, topology and fractional deltas plus ownership adaptation. General Factorio-style lots/layouts or Baba-style grammar need native identity/consumer/validation semantics before an engine could help. Original bounded rules have less integration surface. Authoring-speed/performance savings remain unmeasured; no new dependency or editor was installed. Applicable source licenses/notices are retained per trace; original proposals copy no game code/assets/fiction.
