These are inspected source facts, not newly tested gameplay claims.

Missing in this bounded source review is an authored collective demand with typed membership reason, issue-specific commitment, contributed practical means and an observable authority response. This is a narrower content/consumer gap than missing a social engine. Full arbitrary coalition discovery, government simulation and scalable utility AI remain separate unproven scope.

**Original optional guild case:** two existing-style independent workshop actors seek removal of a shared tool levy. A friendly steward can support the demand because the levy blocks funded repair work; a disliked trader can oppose it because the levy pays for their patrol. A witnessed, scoped service obligation can secure one public testimony without buying affection or control of the witness's future actions. Actual contributed coins, tool rights, paid time and disclosed records determine what the group can do. The authority can amend the rule, refuse, or negotiate a bounded exemption. Refusal changes real access/work options, not an automatic global hostility penalty. This is a proposed cast/rule case, not enrollment or approved balancing.

Use existing actor identities, claims, stock, knowledge, jobs, clock and host publication. Add explicit membership/demand consumers and permanent commitment/closure receipts where display-memory pruning would otherwise erase meaning. Ink presents heard motives and choices; it does not decide private NPC truth or own a separate pressure clock. No new schema, universal influence currency, save publisher or engine is selected here. Optional absent state stays inert; any added durable carrier needs the integrator's compatibility decision.

Later observable gate: with personal liking held constant, change actual levy burden, a neighbor's commitment or available means and show a different valid participation/response. Then show one obligation's bounded use, one independent refusal, conserved contribution and retained closure after a generated-fixture return/reload. Those gameplay/save gates remain deferred. Implementation effort is qualitatively medium because legality, authority response, conserved means and aftermath still need authoring. No authoring-speed measurement exists.

Park whole CK3/Clausewitz transplantation: there is no inspected reusable engine/library source or JS/Ink adapter. Its ruler/map/dynasty loop would add substantial content and state migration work without demonstrated benefit to the current character-centered campaign. Borrow the separation of personal feelings, practical coalition strength, scoped leverage and institutional permissions. Preserve the familiar opening and first one-realm/one-prestige milestone. This finite lane changes documentation only.
