## Implementation methods worth retaining

Definitions carry law stages, requirements, recipes, physical labels and event policies; managed jobs/toils execute their admission, locks, movement, payment, resolution and cleanup. Lua story actions call exposed managed helpers to change actual route access. This separation makes a selected rule reusable while keeping expenditures and consequences with their owners. Exact identifiers/loading behavior matter: installed mod documentation describes definition replacement, so a readable base definition does not prove every active campaign uses it unchanged.

The interesting seams are ordinary ones: capacity-backed knowledge access, actor-local eligibility, actual resource debit, typed effects, attributed accounts and downstream consumers. UI previews, descriptions, global collection marks and narrative memories establish different things. A displayed rate or story label alone does not prove payment or output. Source interruption policies also differ between systems, so one universal refund rule would misrepresent this game.
