## Named question and evidence

**F1, SHOWN: perception is bounded and differs from target validation.** Brain accepts sight or supported active-zone sound/smell when judging suitable hostile targets. Its initial candidate enumeration also requires explored-map cells within a sampled square. Sensory mutations affect flood range and obstruction handling. Kill separately requires a current valid target with a present, visible Render component, party/hostility safety and usable cells. Earlier sound acceptance does not bypass that later Render check. E01–E04, E13–E14 in the [evidence index](../private/repass-2026-10-14/decoded/EVIDENCE.json).

**F2, SHOWN: body ownership and readiness change eligible responses.** Missile candidates come from the actual recursive body attachment tree, including valid equipped, cybernetic or unobstructed default weapons. Loose stock alone is insufficient. Weapon range, desired-use events, intervening nonhostile combatants, solids and extremity movement can reject firing. The selected magazine loader distinguishes loaded ammo from compatible inventory stock. The cold ability enters its command list only within range and with a usable enabled ability entry; ordinary positive cooldown or AI disable suppresses it. E04–E08, E10–E14, E19.

**F3, SHOWN control flow; INFERRED comparison: one ally changes the chosen action.** Condition on an outer order that tries abilities before missile, with the cold command sampled, and a valid equipped loaded firearm. With the first eligible burst area clear, the cold command pays 1000 energy, requests cooldown 50 and creates field objects. Adding a same-phase nonhostile combatant to that area makes the NPC burst selector return no region immediately, before those cast costs. A clear direct firing line can still allow the next firearm candidate. The selector does not search another safe region after that friendly veto. Its player visibility-picker argument is not an equivalent NPC visibility gate. [Full branch set](../private/repass-2026-10-14/decoded/BRANCH_SET.json), E06–E14, E18–E21.

The private fixture binds an authored actor's complete body/mutation/inventory declarations, item inheritance and projectile/field records. Current equipped/loaded state, the sampled order and successful unrelated handlers are explicit assumptions. It does not claim that this actor spawned or performed the comparison. Successful field end-turn code reaches damage and temperature consumers; actual damage, freezing and resistance results remain unexecuted.

**F4, SHOWN: failure has different return boundaries.** Failed sampled ability commands can continue to sampled alternatives and then another action kind. The command-list helper tries at most three random indices, can repeat draws and does not exhaust or priority-sort the list. However, the missile wrapper ignores its inner fire-event return and can return true after an ammo-loading rejection. Kill then ends selection even though no projectile was produced. An empty magazine with compatible reserve ammo illustrates this distinction: desire can pass, actual loading fails, and a reload flag can affect a later turn. A miss is also not proof of same-turn fallback. This narrows the prior dossier's broad failed-candidate wording. E09–E12, E21–E22.

**F5, SHOWN: exhausted candidates can change the goal rather than attack.** If every ranged kind returns false and fallback events allow it, a mobile actor can push a pathfinding Step. Step later rechecks mobility, destination and occupants before moving. Path failure can instead switch target, flee, flush navigation caches or wait; prolonged pursuit can stop. Pushing Step does not prove movement occurred. E04, E16–E17.
