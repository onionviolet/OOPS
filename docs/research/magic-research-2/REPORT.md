# Magic Research 2: public demo source audit

**Decision:** Use this as a bounded design reference for earned spell knowledge and sustained casting. Five connected traces were read from the public browser demo's source map. They describe that demo at hosting commit `05717a17798a2165780ac38465f1e0c2d8736796` (2024-07-08), not the later retail game, its DLC, or every recovered module. Evidence IDs below resolve to exact source-map indices, source-body hashes, and line spans in [FINDINGS.json](FINDINGS.json). The acquired code was inspected as text and never run.

F1. **Research unlocks knowledge, not power supply.** After the Essence Catalyst gate, Study becomes available [E01]. Assigned researchers add element experience each tick at a transformed per-researcher rate [E02]. Experience becomes an element level; spells become visible when all required elements are unlocked and high enough [E03]. The level-up consumer compares old and new visible spells and reports newly learned actions [E04]. Fireball is a concrete demo spell with Fire 6 as its knowledge requirement [E05]. A visible spell still passes separate cooldown, silence/stun, can-cast transformation, and affordability checks [E06, E07].

F2. **Casting spends actual fuel.** Fireball's nominal 380 mana, 6 second cooldown, and 20 autocast-point requirement are distinct numbers [E05]. Mana cost passes through transformations, including a 0.5 primary-element multiplier, so 380 is not a universal live price [E08]. The action affordability gate checks both current resource amount and its capacity, and paying a cost subtracts the transformed amount [E07]. Spell execution pays after the effect and grants experience from use only for an affordable cast [E09]. This makes a level-up a new option, while mana production and storage still determine when that option works.

F3. **Elemental equipment couples several systems.** The demo registers a Water wand transmutation [E10]. Its recipe requires Water 14, mana, Water Essence, and Water shards [E11]. The item supplies attack, mana regeneration, mana capacity, and a Water-tagged action-effect multiplier while equipped in the hand slot [E11]. Action effects read those tags through the common transformation consumer [E12]. Its visibility also requires Exploration unlock [E13]. The recipe, equipment slot, and spell effect are one connected progression path rather than three unrelated bonuses.

F4. **Automation has explicit waits and a sustained-cast hazard.** A progression event unlocks Wizards after Transmutation and 500 capped Coins [E14]. Ordinary rules gather points from assigned wizards each tick, then skip disabled, unassigned, undercharged, invisible, unaffordable/disabled, or condition-failing spells. A successful ordinary rule calls the spell action and spends points [E15]. A check-only rule can stop later rules in that tick [E15]. Permacast is different: it can deduct a per-tick mana cost while charging points before checking `isEnabled` and conditions, so the mana may be spent without an effect that tick [E16]. A second tick listener resumes mana-starved permacasts after income [E17]. Strategy load can auto-disable spells over mana cap or estimated wizard/mana income, but this is an estimate, not a guarantee against transient fuel shortages [E18].

F5. **Retirement makes a discovered event into a persistent benefit.** The demo loads the Posterity storyline [E19]. On a level-up after the primary element's maximum level for that run reaches 7, its event appears once; choosing Continue completes the storyline and activates its bonus [E20]. Storyline completion writes run and world flags, and the retirement gate reads the world completion flag [E21]. The retirement UI previews a hypothetical reset and requires a second click for the actual one [E22]. The reset records current primary/secondary maxima, increments retirement count, replaces run state, and runs post-retirement listeners [E23]. Those maxima feed starting experience and multipliers for later runs [E24]. This is a persistent knowledge/reward loop, not evidence that every run resource survives.

**Boundary:** The main map holds 584 source entries with content, including 423 `src/backend/` entries. The vendor chunk map holds 1,236 entries, 1,232 with content. The 24 evidence IDs cite 18 distinct source bodies from the main map; the private cache contains 91 extracted main-map entries, which is not a count of files fully read. We read the selected source paths supporting these traces, plus immediate call paths and demo registration. We did not audit all demo systems, reproduce gameplay in a browser, test save migration, or inspect retail binaries. The public map includes symbols and initial-state fields for wider game content; those alone do not establish reachable demo play. [COVERAGE.json](COVERAGE.json) records the measured subset and open edges. [VALIDATION.json](VALIDATION.json) records source-range, hash, and commit-parity checks. [IMPLEMENTATION_PACKETS.md](IMPLEMENTATION_PACKETS.md) contains original YAIR proposals only; none is accepted or implemented.
