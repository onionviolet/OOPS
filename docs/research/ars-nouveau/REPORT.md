# Ars Nouveau source pass, 2026-10-14

A learned glyph adds a reusable spell part. A form chooses how to reach the target, effects run in sequence, and augments modify the immediately preceding part. The same grammar supports crop work, movement and processing. Unattended work has two routes: a turret runs a stored composed spell using infrastructure energy, while creatures run specialized production and transport behaviors. Familiars mainly support their owner and are a separate system from placed workers.

For YAIR, the strongest connection is **learn a useful verb, apply it to the same known task, then queue a bounded application with real inputs and stop conditions**. This supports LP1 and composable-technique proposals without requiring a universal spell engine or a new world. This pass changes no gameplay or accepted design.

## Findings answering the named question

### F1: Glyph acquisition grants vocabulary, separate from book capacity

**SHOWN:** generated glyph recipes spend ingredients and XP points at the Scribe's Table. The player then uses the glyph item to add its ID to persistent player knowledge. Duplicate, starter and disabled cases have explicit handling. Authoring filters known/starter parts and checks book tier. Starter defaults provide Projectile, Touch, Self, Break and Harm. The book records a highest tier, and learning records a glyph-count bonus used by mana calculations. [Glyph](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/items/Glyph.java), [ScribesTile](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/block/tile/ScribesTile.java), [GuiSpellBook](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/client/gui/book/GuiSpellBook.java), [SpellBook](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/items/SpellBook.java)

Recipe generation assigns **27 / 55 / 160 XP points** to default tiers 1 / 2 / 3. These are acquisition costs, distinct from casting mana. A Harvest glyph's recipe consumes an earth essence and iron hoe. There is no school timetable or hypothesis experiment in this traced unlock route. **INFERRED:** YAIR can adapt the functional unlock while preserving its own willing-teacher, understanding, practice and provenance stages. [GlyphRecipeProvider](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/datagen/GlyphRecipeProvider.java)

### F2: Spell meaning comes from local modifiers and ordered mutations

**SHOWN:** the first part supplies the cast method. Each form/effect receives only its consecutive following augments. The resolver advances through effects in order; each gets new stats built from those augments, equipment modifiers and an event hook. Target capabilities can skip an effect or stop the remaining resolution. Context delay/cancellation can suspend the chain. [Spell](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/spell/Spell.java), [SpellResolver](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/spell/SpellResolver.java), [SpellStats](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/spell/SpellStats.java), [SpellContext](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/spell/SpellContext.java)

Crafting validation checks at most one form, compatible augments, action-specific caps, occurrence caps and invalid combinations. Casting requires a nonempty spell starting with a form and normally enforces configured caps, but deliberately omits some crafting checks for existing spells. Known-glyph/book-tier checks live in authoring, not the standard resolver validator. **INFERRED:** a YAIR compiler should distinguish composition errors, unavailable personal means and a presently invalid target. These are different failures. [StandardSpellValidator](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/spell/validation/StandardSpellValidator.java), [GuiSpellBook](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/client/gui/book/GuiSpellBook.java)

### F3: Mana supports a learned repertoire, with reservation tradeoffs

**SHOWN:** before attributes and events, configured contributions are maximum mana `100 + 15*g + 50*t` and regeneration `5 + 0.33*g + t`, for stored learned-glyph bonus `g` and highest recorded noncreative book tier `t`. Usable maximum applies the reservation fraction afterward. These are baseline contributions, not universal final totals. Worn items/tool discounts and separate pre-check/post-spend events modify spell cost; costs clamp at zero. [ManaUtil](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/util/ManaUtil.java), [SpellResolver](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/spell/SpellResolver.java), [ServerConfig](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/setup/config/ServerConfig.java)

Regeneration updates every five game ticks by default, scaled by sampled server TPS. Familiars normally reserve 15% of maximum each; the Whirlisprig familiar reduces costs of earth-school parts using its own per-part calculation. A successful cast method triggers personal mana expenditure, even if a later effect has no useful target. Projectile launch and effect success are distinct. **INFERRED:** capacity, throughput, reserved support and per-job expense should be separately legible in YAIR. [ManaCapEvents](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/event/ManaCapEvents.java), [FamiliarEntity](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/entity/familiar/FamiliarEntity.java), [FamiliarEvents](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/event/FamiliarEvents.java), [FamiliarWhirlisprig](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/entity/familiar/FamiliarWhirlisprig.java)

### F4: Utility effects preserve target and recipe rules

**SHOWN:** Harvest recognizes mature crop families, generates loot, accounts for a replant seed and resets crop age rather than treating every plant as a generic break. Grow delegates to bonemeal behavior. Break checks harvest level, blacklist and protection hooks. These choices make the same learned part useful in a concrete world context. [EffectHarvest](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/spell/effect/EffectHarvest.java), [EffectGrow](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/spell/effect/EffectGrow.java), [EffectBreak](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/spell/effect/EffectBreak.java)

Movement also follows delivery and target rules: Self makes Leap move the caster; Blink has validity/exclusion checks and a special tile-caster scroll route. ### F5: Turrets directly reuse a composed spell; helpers usually do not

**SHOWN:** configuring a spell turret stores the player's spell and UUID. Its supported form chooses projectile delivery or a front target. The tile consumes **Source**, infrastructure energy, before dispatch and uses a fake player for attribution. Its entity resolver bypasses personal mana sufficiency and the turret avoids a second personal mana debit. A timer supplies repeated triggers and retains off/lock/elapsed settings. [BasicSpellTurret](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/block/BasicSpellTurret.java), [BasicSpellTurretTile](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/block/tile/BasicSpellTurretTile.java), [EntitySpellResolver](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/spell/EntitySpellResolver.java), [TimerSpellTurretTile](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/block/tile/TimerSpellTurretTile.java)

Timer turrets discount selected delivery/control parts: default Touch plus Harvest is **10 Source** per timer shot, versus **15** on the basic turret. A nearby living entity can take priority over the front block in Touch delivery. Infrastructure payment therefore does not by itself prove useful crop output. Crop-growth sourcelinks receive growth events, but an energy-positive farm requires proving those event paths and net costs. [AgronomicSourcelinkTile](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/common/block/tile/AgronomicSourcelinkTile.java), [SourcelinkEventQueue](https://github.com/baileyholl/Ars-Nouveau/blob/fd8c9520722bb96a3e75febaf770d7078db5ac43/src/main/java/com/hollingsworth/arsnouveau/api/source/SourcelinkEventQueue.java)

**INFERRED:** reuse a learned operation through a device execution carrier, while making target selection, fuel payment and failed-work behavior explicit. This is a closer fit to a composed YAIR technique than treating every creature as an arbitrary spell interpreter.

### F7: Permissions and offline work need stronger distinctions than a helper label
