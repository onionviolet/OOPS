## Desktop host, background time and Steam

ER3-T12–T14 extend TS6. The palette's blanket “no storage quota, no tab throttling”
claim needs qualification. Native file APIs can bypass **browser-origin** quotas;
keeping saves in a wrapper's web storage does not. Neither a wrapper nor a worker
guarantees execution during OS sleep, app exit or process termination. Use the
offline audit's owner for elapsed reconciliation, caps and exactly-once settlement.
Disabling throttling alone does not supply those semantics.
