# M2: Xeus24 mod.js lines 4700-9400

Research only. Paraphrased from the unlicensed mod; no code copied. Labels: SHOWN = read in the cited lines, INFERRED = my reading, UNKNOWN = not in this range.

## Coverage

Read every line of mod.js 4700-9409 with the Read tool, in 400-line chunks. Outside the range I read only 4281-4345 (Renown definition) to make the titles section complete. YAIRPG was checked by grep of `src/` filenames and keywords only, so "none found" means none by keyword. Sections in range: 19 (tail), 20-34 of the mod's own numbering.

## Systems

### S1. Skill XP curve tail (4700-4754) - section 19 end
- SHOWN: `setXpCurve` takes `vanillaTo` (0-12, clamped) or `fixedRatio`; it re-solves a per-level ratio so level 110 stays the same total distance away (4705-4727). Below `vanillaTo` the author's cost formula is kept (4730).
- SHOWN: `modXpCurve()` prints a ladder table at levels 1-109 and per-cap totals at "2 xp/tick" (4729-4749).
- The curve is installed by `MOD_installXpCurve` (defined before 4700; UNKNOWN how it patches).
- Relevance: YAIRPG already has a geometric curve with cap, so ALREADY-HAVE.

### S2. Three save slots (4757-5087) - section 20
- Patch: wraps `save()` to mirror its returned blob into `p23_slot_N` plus a meta record (name, level, cap, timestamp, version) (4843-4855). The game's own key `v0.3` always holds the live slot (4763-4771).
- Boot only adopts: if the active slot has no mirror, the live save becomes that slot; it never overwrites `v0.3` (4857-4873).
- Switch/new/delete write `v0.3` then reload the page, because the game cannot unload a save (4886-4931). New and delete use `confirm()`; switching saves the current slot first and aborts if that fails (4877-4884).
- Rebinds the "delete save" button (original calls `localStorage.clear()`) to delete one slot only (5050-5059).
- Compat: new keys only; old save adopted as slot 1 (4863-4872). Slot count 3 (4793).
- Relevance: YAIRPG has an envelope, migrations and backups (per main audit section 6); multi-slot is UNKNOWN in src (grep found only unrelated hits). Class: ADAPT only if Weibao wants multiple characters. Low priority.

### S3. Unrestricted actions toggle (5090-5347) - section 21
- Lets several sustained actions run at once and start anywhere (ignores each action's `cond`). Off by default, persisted in `p23_mod_freeactions` (5137-5149).
- Patch: wraps each action's `cond/activate/deactivate/use`, swapping the shared `timers.actm` slot around the original call so no timer logic is duplicated (5153-5205). Wraps `giveAction`, `activateAct`, `deactivateAct`, `load` (stops all actions on load), `ontick` (checkbox sync) (5214-5344).
- A tick that throws 5 times is auto-stopped (5141, 5193-5204).
- Relevance: YAIRPG is a different action model. NOT-RELEVANT as code; the idea of a "comfort switch" for concurrency is a possible ADAPT but conflicts with "limits are deliberate" design. Low.

### S4. Perk ladder for every skill (5350-5551) - section 22
- Finding (5355-5361): of 94 skills, 25 had no milestones, 12 none past 10, 44 none past 50, 81 gave nothing at levels 51-110.
- Rule: every skill gets rungs at levels 10, 25, 50, 60, 75, 90, 110 appended above its current top milestone (5413, 5523-5535). Append-only and ascending because "granted" flags are saved by array index (5370-5376).
- Magnitudes per rung (5416-5422): flat 1,3,6,8,11,14,18; mult 4,6,8,10,12,15,20 percent; EXP gain 2,3,4,5,6,8,10 percent; resistance 2,3,4,5,6,7,9 percent; affinity 1,1,2,2,3,3,4.
- Perk content by skill type (5387-5397, 5443-5513): combat gives STR, STR mult (x1.25 of base mult) and crit damage (quarter mult, nerfed because it ran 1.2 to 13.0, 5451-5453); physical STR and HP (x20); agility AGL; mental INT and EXP gain; crafting INT and energy efficiency; resistance reduces its own damage type (floor 0.05) plus HP; absorption gives its element's defence plus INT; gathering STR/max energy/efficiency; upkeep INT/efficiency/EXP; social luck and EXP gain.
- Deliberately avoids writing skill XP multiplier `p` from milestones (restored after milestones on load, 5401-5405) and avoids `you.res` for absorption (5407-5410).
- Relevance: YAIRPG has smooth multiplicative skill bonuses, no milestone array. ADAPT idea: "uniform rung table by skill type" as a template for generated perks, but F1 says YAIRPG is data-driven so a table is natural. ALREADY-HAVE in spirit.

### S9. Dojo level advancement to 110 (6400-6692) - section 27
- Base dojo rewards stop at level 30 (rungs at 5..30: 25/100/200/300/350/400 coin, 6400-6412). Mod adds 16 rungs at levels 35-110 in steps of 5 (6543-6552), shown as a separate lobby entry that appears once base rung 6 is done (6650-6672). Wrapped: `chss.t3.sl` (6650).
- Reward formula (6531-6536): level 35-45 gives Superior Spirit Pill x2/x3 (x2 up to 40) and coin 400 + 20 per level over 30; 50-70 Refined x2/x3 (x2 up to 60), coin 700 + 30 per level over 45; 75-95 Sublime x2/x3, coin 1500 + 60 per level over 70; 100-110 Transcendent x2 (x3 at 110), coin 3000 + 100 per level over 95.
- Four new spirit pills: 100,000 / 600,000 / 3,500,000 / 20,000,000 character EXP (6453-6462). Reason: character EXP per level is `4*lvl^3 + lvl^2`, 5,336,100 at level 110, the best base pill is 15,000 (6420-6423).
- Six "Manuals" (third skillbook grade): +30 percent skill XP rate, plus 9000 skill XP on finish, 30 hours reading, offered as a choice at rungs 50/75/100 (6487-6495, 6511-6520, 6550). Base grades are +5 and +15 percent (6431-6434).
- Realm 6-10 breakthrough pills are handed out at rungs 45/60/75/90/105 (6541). A once-only "pill for the wall" can be requested when stuck at a bottleneck without the pill (6606-6623).
- Flags: `mod_djrw<level>`, `mod_djwall<n>` in `global.flags` (6547, 6619). Item ids 4220-4223, 9110-9115.
- Relevance: milestone reward ladder every N levels with sized currency. ADAPT idea (the sizing-against-curve logic). YAIRPG has no character level, so only the principle applies.

### S10. Cultivation realms (6695-7003) - section 28
- Ten realms above Mortal; thresholds are the title rank levels `[1,8,18,30,45,58,70,82,90,110]` of Qi Circulation (6711-6721, 6777).
- Stat multiplier / body (HP and max energy) multiplier per realm (6757-6768): 1.10/1.20, 1.30/1.50, 1.55/1.90, 1.85/2.40, 2.20/3.00, 2.65/3.80, 3.15/4.70, 3.80/5.80, 4.80/7.00, 6.00/8.50. They do not stack; the current realm applies (7667-7670).
- Reaching the level does not advance; you reach a bottleneck (6798-6800) and must consume a pill (6883-6923). Chance = min(0.55 + 0.05 per level over the threshold, 0.95), plus root and seclusion bonuses shown in the wiki (6904-6905, 6990-6991, 7715-7718). Fail: pill lost, HP set to 1, no death (6906-6911).
- Success sets `global.flags.mod_realm`, grants a realm title `mod_realm<n>` (ids 3901-3910, rank derived from level, 6928-6937) and updates Renown (6914-6921).
- Applied by wrapping `allbuff`: multiplies str/int/agl/spd on the rebuilt value, and sets a body factor through `MOD_BODY` because a direct HP write is undone by `stat_r` (332 to 39 measured, 6957-6972).
- Pill sources: realm 1 from the dojo (SHOWN 7694), realms 2-5 from the Herbalist `vendor.pha1` at prices 900/3200/11000/38000 and chances .55/.40/.25/.12 (6866-6871), realms 6-10 from dojo rungs and the Pill Tower (7694-7699). Pill value `150 * 2.6^realm` (6835). Not craftable on purpose (6803-6805).
- Extra systems visible only through wiki text (defined before 4700 or after 9400, so mechanics UNKNOWN here): spiritual root with grade, weight, XP multiplier and breakthrough odds (7812-7829); insight resource from meditating, near-loss kills, first area visits (7722-7745); nine layers per realm (7763-7776); Closed Door Training seclusion; Qi Deviation penalty (7789-7795); Heavenly Tribulation from a set realm, HP-fraction cost (7797-7809).
- Relevance: YAIRPG has `feature_expansion_book_cultivation.js` and pocket-realm files, but no realm/bottleneck/pill system was found by keyword (grep "breakthrough" returned no hit in that file). Class: ADAPT for a source-fit world that wants a cultivation ladder. Not core.

### S11. Elemental Mastery (7006-7200) - section 29
- Six skills (Fire, Water, Air, Earth, Light, Dark Mastery) each paired with the matching Absorption skill and one named technique (7042-7055). Ids 2016, 2011-2015 (fire was moved after a duplicate id with a parent skill caused a save doubling bug, 7069-7081).
- Combat is automatic, so a technique is a proc: wraps `you.battle_ai`. Chance = mastery level x 0.006 + realm x 0.012, cap 0.45 (7130-7142); zero while Mortal. When several qualify the highest chance wins (7145-7153).
- A technique is an `Ability` with `stt: 2` (INT branch) and an element, damage multiplier 1.15 (7092-7094, 7134). Each use gives 1.2 XP to the mastery, 0.3 to the paired absorption, 0.4 to Qi Circulation (7161-7163).
- Element index: 1 air, 2 earth, 3 fire, 4 water, 5 light, 6 dark (7040-7041).
- Relevance: YAIRPG has one physical damage number (main audit F4). O9 in the main audit covers elemental affinities. ADAPT: "proc a different damage type per swing" is a cheap bridge to elements. Not O1.

### S13. Generated wiki (7371-8610) - section 31
- Builds an HTML document string from live game data (skills, items, areas, titles, actions, dojo, realms, mechanics) and writes it to a new window; no fetches (7377-7384, 8549-8571). 11 pages (`start`, `progress`, `skills`, `cultivation`, `mastery`, `titles`, `areas`, `items`, `actions`, `dojo`, `mechanics`) with search, collapsible groups, "expand all" (7448-7478, 8454-8510).
- It also reads the save, so it works as a progress sheet (7385-7388). Marks unfinished and unreachable content (7919-7924, 8053-8084).
- Stated mechanics in text: hit damage = attacker STR minus defender STR plus weapon plus 1, before crits (8301-8304); late-game crits about a third rate, about 8x damage, roughly three quarters of damage (8319-8323); parents earn a feed share of children's XP and lagging children train up to 2x faster (7507-7512, 8330-8336).
- Enemy scaling (7105-7110): each spawn solved against player power so it takes `MOD_ENEMY.kill` swings and `MOD_ENEMY.die` to kill you (values defined elsewhere, UNKNOWN). Two modes, Original and Scaled (8097-8104).
- Relevance: YAIRPG has `display.js` and bestiary-like surfaces; a data-generated codex is ADOPT-IDEA if one does not exist. UNKNOWN whether one exists in src.

### S14. Marketplace access (8613-8849) - section 32
- Problem: the Pamphlet (read to open the marketplace) could be sold, locking out marketplace, Herbalist and cultivation (8618-8629).
- Fix A: key items cannot be sold; derived by scanning the game's own source for flags that are set true and never set false (8643-8714). Wraps `MOD_sellable` (8710).
- Fix B: the Paper Boy returns at 40 percent per visit if the player has no Pamphlet (8728-8729, 8796-8806). Fix C: Village Center and marketplace greyed lines say why the door is missing (8767-8783, 8809-8846).
- Relevance: "soft-lock guard, never allow selling a quest-flag item" is a good principle. YAIRPG quests: UNKNOWN. ADOPT-IDEA as a check (a test that no one-way flag item is sellable).

### S15. Duplicate repair (8852-8989) - section 33
- Base bug: loader matches skills by id with no break, so duplicate ids double the skill list each save (8855-8863). `giveTitle` pushes to both `global.titles` and `global.titlese`, and `load()` appends `titlese` again, so a character with 241 titles had 481 after a load (8876-8892).
- Repairs by identity: `MOD_dedupeSkills` and `MOD_dedupeTitles`, run after `load` (wrapped) and 3 s after boot (8906-8989).
- Relevance: a warning for O1. In YAIRPG `character.titles` is a keyed object (`main.js:4392`, `4782`), so duplicates cannot occur from array appends. ALREADY-HAVE.

### S16. Rank ladder (8992-9409) - section 34
- Base `you.rank()` is a derived Power rank, formula written in the comment (8998-9001), roughly S^-1.5. Measured: only taking every skill to 110 reaches rank 1 (9012-9029).
- Mod adds 10 named challengers, rank 10 to 1, in "The Hall of the First Gate", location id 979, past the Old Path (9093-9123, 9314, 9372-9387). Strictly ordered: rank N+1 must be taken first (9176-9180). Required character level `need` per rung 60 to 110 in steps of 5 (9094-9122); challenger level 62, 68, 74, 80, 86, 92, 98, 104, 110, 120.
- Held rank is a flag `mod_rank` (9167); `you.rank` is wrapped to return min of held and stat-derived rank, so it floors but never caps (9199-9206). The display turns gold when the held rank is the better one (9211-9221).
- Difficulty: each rung is a protected single-spawn area. Step multiplier = 1 + (10 - rank) x 0.07 (9084, 9230-9232); kill time x step, die time floored at kill time x 1.4 (MOD_RANK_MARGIN, 9091, 9243-9244). Creature fields: `hp_r = 400 + lvl*6`, `str_r = 20 + (10-rank)*3`, `agl_r = 40 + (10-rank)*4`, danger grades 11-14 chosen to avoid a 100x coin-drop exponent jump (9074-9082, 9136-9143).
- Reward: EXP = 15 percent of one character level at the rung's `need` level, coin = need x 400 (9277-9280). Losing costs only the walk (9297-9302).
- Relevance: a named ranking ladder of duelists is ADAPT (YAIRPG has guild rank content, UNKNOWN whether ranked duels exist; `native_battle_host.js` and `feature_expansion_book_roster.js` matched "duel/ladder"). The "rank as flag floor" patch trick is useful if we add ranks.

## TITLES for O1

All numbers below are from this range unless marked.

### Base game titles as the mod describes them (SHOWN)
- Before the mod: 120 titles across 93 skills, 73 from story events; only four titles carried a `talent`; picking a title only changes the name printed next to level (5646-5649). Rank `rar` was 0-5, assigned by feel (5639-5644). Base titles are unlocked by milestone closures calling `giveTitle` (5660-5662).

### Rank scale (5649-5713)
- Rank = highest threshold reached by the earning level: ranks 1-10 at levels 1, 8, 18, 30, 45, 58, 70, 82, 90, 110 (5706). Rank 10 means level 110 only (5658).
- For 47 milestone-granted base titles, the level is read by scanning the milestone function source text for a `giveTitle` call (5660-5662, 5716-5735). For the 73 story titles the author's 0-5 is mapped to 1, 2, 4, 5, 6, 8 (5753-5754).
- Marking field `_modRanked`, level field `_modAtLevel` (5743-5757).

### Generated skill titles (5666-5837)
- Five per skill, at skill levels 25, 50, 75, 90, 110, meaning ranks 3, 5, 7, 9, 10 (5668-5670, 5764). 465 titles. Ids start at 3000 (5787). Key shape: `mod_t_<skill>_<level>` (5813). Only skills with a milestone at that level get one (5802-5804).
- Name formula: rank word by skill type plus "of" plus skill name. Eleven type word lists of five nouns each (5769-5781). Example lists: combat Recruit, Veteran, Warmaster, Champion, Paragon; crafting Apprentice, Journeyman, Master, Artisan, Grandmaster; social Face, Notable, Luminary, Legend, Myth.
- Description auto text: "Earned by taking <skill> to level <n>"; talent text: skill exp +x percent (5809-5810).
- Grant: folded into the existing milestone at that level by wrapping its function, appending the title name to the perk text (5823-5827). No new milestone, to keep array-index save flags (5820-5822).

### Bonuses (5680-5693, 5784, 5849-5929)
- Each generated title gives its own skill exp rate: +5, +10, +15, +20, +30 percent for rungs 25, 50, 75, 90, 110 (5784). Stacking is additive per skill (5873).
- Applied by a tick reconciler, not at earn time: tracks the applied amount per skill in `global.flags.mod_ttlxp` and adds only the difference to `skl.<x>.p`, floor 0.05 (5862-5889). Reason: `p` is restored after milestones on load (5840-5845).
- A title bonus is active if held and either (a) it is the worn title (any rank) or (b) its rank is at or below the Renown level (5855-5860, 5693-5698). The wiki states this to the player (7875-7876).
- `giveTitle` is wrapped to recompute Renown and bonuses at once; the picker click re-runs it after 50 ms; selecting a title re-runs it (5914-5926, 6151).
- Reset helper `modResetTitleBonuses` (5893-5904).

### Renown (4281-4345, outside range; SHOWN in wiki 7895-7909)
- A skill `rnwn` (id 2100) counts titles held, not trained. Titles needed per level: 2, 12, 30, 60, 105, 160, 230, 320, 430, 550 (4281). Each level multiplies all stats by 1.05, compounding, max level 10, about x1.63 (4284-4289, 7897-7899). Recomputed every tick (4323-4335, 4343-4345). Ignores the story level cap (4309-4310). Renown level N makes titles of rank N or lower permanent (5693-5698).

### Realm titles (6928-6937)
- Ten titles `mod_realm1..10`, ids 3901-3910, named after the realm, rank derived from the Qi Circulation threshold level, granted on a successful breakthrough (6920, 6930-6935).

### Picker (5976-6305)
- Second click listener on the title button, runs after the game builds the list and rebuilds its body (5997-6002, 6173-6177, 6296-6302). Failure falls back to the game's list.
- Titles group under their skill with a caret; the best held (by rank then earn level) is shown with a count, others expand (6205-6208, 6212-6260). Worn title shown bold with a tint (6167, 6233). Groups sorted by skill name; unattributed families after; loose one-off titles last, sorted by rank (6263-6286). Expand state is session-only (`MOD_TTL_OPEN`, 6136).
- Attribution passes (6019-6081): generated titles know their skill; flagship titles via a pairing table; base titles by scanning milestone source; numbered keys like `tghs1/2/3` by stem if the stem is a skill key or a unique prefix of one. Families with no skill (6095-6107): realms "Cultivation", `kill` "Creatures killed" (five), `geti` "Items gathered" (four), `ttsttl` "Titles collected" (four), `hstr` "Punch power", `neet` "Time spent indoors", `sld` Shields, `jbs` Jobs done, `eat` Eating, `mone` Money, `shpt` Shopping. Family label falls back to the lowest-rank member's name (6120-6129). A family of one shows as a plain row (6201-6203).
- Titles with name "null" or empty are skipped in the picker (five author-left blanks: `ddcd`, `shpt2`, `shpt3`, `mone3`) (6184-6187); the wiki lists them tagged "unfinished" (7945-7948, 7919-7924).

### Colours and tooltip (6308-6397)
- Ten-rank palette: 1 grey-blue, 2 cyan, 3 lime, 4 yellow, 5 orange, 6 purple, 7 pink, 8 red, 9 gold, 10 white with glow (6341-6352). Base had colours for ranks 0, 2-6 only; rank 7 threw an error in the tooltip because it set the wrong element (6318-6323). Fix: wrap `dscr`, set rank to 1 during the original call, then paint the label (6371-6392). Tooltip adds "Rank N" and "earned at level L" (6387-6391).

### Save (INFERRED from comments)
- Mod adds `global.flags.mod_ttlxp` (5866), reuses saved title list (`global.titles`), saved Renown skill. Title definitions are code-side (new ids 3000+, 3901-3910); a missing id on old saves simply has no entry (INFERRED, mechanism not shown in range). Base game title list is an array with an extra `titlese` array, with the double-append bug repaired by identity dedupe (8876-8892, 8932-8954).

### Counts (SHOWN)
- 585 titles after the mod (120 base + 465 generated; 5979), 241 held in one measured character (8890). The wiki prints "held of total" (7870, 7878).

### What O1 can take
1. Rank-from-requirement (ranks 1-10 at a level/threshold table) as a derived property rather than a hand-set number.
2. Five tiers per counter or skill with formula names ("<rank word> of <thing>"), but beware: the mod's own text calls 372 generated names "legible, consistent, hard to tell apart" (5677-5679). For YAIRPG lifetime counters (cat pats, years at home) hand-written names are better.
3. Two-state bonus rule: only the worn title applies, until a meta-stat (Renown) makes lower ranks permanent (5688-5698). This gives the picker a purpose.
4. Reconcile applied bonuses against a stored delta each tick so reloads cannot compound them (5840-5889). In YAIRPG, derive the bonus from `character.titles` on read instead of storing a delta.
5. Collapse titles by family in the picker and show best held, with a count (6212-6260).
6. Titles never block anything (no gating); all are flavour or small bonus.
- Not to copy: the stretch table for story titles, the 10-rank cap tied to level 110 (YAIRPG has no character level), and the source-text scan for `giveTitle` (5725, 6043), which only exists because Proto23 titles are code closures.
