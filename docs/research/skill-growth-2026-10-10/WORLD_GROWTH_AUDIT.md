# C3 world growth audit

Date: 2026-10-10. Status: complete, research only. All profiles and code mappings are proposals, not accepted specifications or gameplay claims.

## Method and scope

READ means this run read the named local text. It certifies that document's content, not its underlying franchise. STATED means a synopsis, wiki, or earlier reader dossier reports the source rule; this run has not checked its primary passage. MEMORY means unverified recall. Proposal means this run's suggested interpretation, not an additional evidence label. Every profile row states its evidence basis. Population curves without a census are proposed shapes, never measured distributions.

Use the merged G1–G40 and L1–L23 definitions in [Skills and talents](../../SKILLS_AND_TALENTS.md), not the older colliding numbers in the two precursor audits. Use S1–S14 from its level-scales section. A level, a technique stage, an institution rank and an equipment grade need not describe the same thing. No universal conversion rate is selected.

Inventory: nine [world cards](../../WORLD_CARDS.md) plus fourteen world folders. Frontier/original-frontier and Paradise/paradise-hub are overlapping owners, so there are 21 main sections. The novel-worlds folder also names four additional candidate worlds beyond Mother of Learning; each will have its own subprofile. Conceptual is a reference/engine area, not an established destination.

No Royal Road requests or harvest access, source download, user-save access, build, code edit, commit or other output-path edit is authorized. Public source mechanics can be discussed; divergent or randomized secrets remain sealed. Sealed truths will not be used to justify public growth profiles.
