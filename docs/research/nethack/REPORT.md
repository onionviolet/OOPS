# NetHack source patterns for original YAIRPG systems

Research-only audit for the authorized YAIRPG implementation. NetHack source was available directly, so no decompilation was needed. This report describes mechanics patterns, not a request to copy code, names, text, or setting. Implement any selected ideas as original YAIRPG content.

## Source and scope

Reviewed the official [NetHack repository](https://github.com/NetHack/NetHack) at branch `NetHack-5.0`, commit [`8898570da710513f38d81ed973f834863b795217`](https://github.com/NetHack/NetHack/tree/8898570da710513f38d81ed973f834863b795217). The source checkout is `/tmp/yairpg-nethack-source`, clean at inspection. The repository README directs readers to `dat/license`; that file identifies itself as the NetHack General Public License and sets out redistribution/source, notice, and derivative-work terms. YAIRPG's `PROJECT.md` separately says to keep its MIT license and upstream attribution. This is a source/license fact record, not legal advice. Do not treat the different license labels as interchangeable; this audit copies no source.

This is a representative source audit, not whole-game coverage. Inspected item dispatch and use (`apply.c`, `potion.c`, `o_init.c`), pet suitability/taming/feeding (`dog.c`, `dogmove.c`), food and effects (`eat.c`, `zap.c`, `spell.c`), and conduct recording/encoding (`topten.c`). Hashes and reviewed files are in [SOURCE.json](SOURCE.json). Function names below link to the exact reviewed revision and path; line anchors are useful orientation but GitHub may move line rendering.

## Transferable patterns

1. **One object can invite multiple contextual decisions.** `doapply()` dispatches by object type and context; it supports multiple kinds of useful tool interaction, while oil is both a light fuel/apply-case and a drinkable potion with a distinct `peffect_oil` effect. See [`doapply`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/apply.c#L4215), [oil apply branches](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/apply.c#L1506), [`peffects`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/potion.c#L1333), and [`peffect_oil`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/potion.c#L1260). YAIRPG opportunity: make an item have a few legible, materially different verbs based on target/situation, with costs and results surfaced before commitment. Surprise comes from a familiar consumable behaving as a practical tool too, not merely from adding a stronger rarity tier.

2. **Character knowledge is separate from item truth and item state.** `discover_object()` separately marks an object type known and encountered, and the discovery list maintains its own ordering. This supports a progression where the world has fixed underlying facts, the item has its current condition/charges/ownership, and the character records what they have identified. See [`discover_object`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/o_init.c#L454). For YAIRPG, use explicit observation receipts to reveal a function or provenance without changing condition, and let testing one instance inform (or fail to inform) the character about related items by authored rules.

3. **A companion is an actor with preferences, needs, and service behavior, not a passive bonus.** `dogfood()` evaluates safety and suitability with creature-specific dietary, poison, age, and condition cases. `dog_eat()` changes the pet's hunger deadline, tameness, recovery state, and carried-object behavior; taming also modifies peacefulness/fear and a pet conduct counter. See [`dogfood`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/dog.c#L999), [`tamedog`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/dog.c#L1147), and [`dog_eat`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/dogmove.c#L218). Transferable idea: a companion has preferences/needs and can provide a distinct service or assistance; care is funded with actual resources and time. For YAIRPG, avoid turning ongoing care into a punitive hidden timer: disclose upkeep and allow a calm return/hand-off path.

4. **Voluntary conduct works when tracked at the causal action and judged later.** NetHack increments counters where relevant actions happen (for example, food, weapon use, pet acquisition), then `encodeconduct()` evaluates a bundle of no-violation conditions. Its Sokoban note explicitly avoids claiming success without participation, and uses another achievement bit to disambiguate whether the challenge was entered. See [`encodeconduct`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/topten.c#L411) and the pet counter in [`initedog`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/dog.c#L79). YAIRPG can use causal receipts such as “did not consume a field ration during this expedition,” then adjudicate only when the expedition actually closes; distinguish not attempted, still active, met, and broken.

5. **Effects can propagate through actors and the environment, creating lessons beyond raw damage.** `potionhit()` routes a thrown potion through collision and target-specific effects; `dobuzz()` resolves a ray through its path and calls actor/environment interactions (fire/cold defenses and object effects appear in this subsystem). Spell effects also share handlers with item effects for several effect families. See [`potionhit`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/potion.c#L1625), [`dobuzz`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/zap.c#L4789), and [`spelleffects`](https://github.com/NetHack/NetHack/blob/8898570da710513f38d81ed973f834863b795217/src/spell.c#L1385). The YAIRPG lesson is to let materials, weather, equipment, allies, and targets participate in a shared interaction rule, so preparation changes what an action can do.

6. **Progression teaches through useful early actions that retain later relevance.** The inspected code repeatedly connects ordinary verbs (eat, apply, throw, identify, cast) to several owners: resources, status, information, conduct, and NPC response. This supports PROJECT.md's existing direction to let ordinary skills/resources open later uses, such as cooking for preparation or environmental skills for routes. A small early action can remain valuable through new contexts and mastery instead of being replaced by a numerically larger version.

## Limits

This review did not inspect every item, spell, food, monster, level, save path, or complete conduct lifecycle. It makes no claim about balance, player experience, or which mechanics should be adopted. Any YAIRPG design remains an original implementation choice and must be integrated by its current runtime owner; no code or source text was transferred.
