## Evidence and inventory boundary

**F1. Evidence labels.** VERIFIED means the linked public metadata or synopsis page (or a search result summarizing it) was inspected on 2026-10-14. The premise is **STATED by that page**, not SHOWN by reading the work. Some VERIFIED links are summary sites or fan wikis because no publisher or Wikipedia page surfaced; treat those as weaker. MEMORY means recalled and unchecked. Native spellings marked MEMORY are unverified even when the English premise is VERIFIED. UNKNOWN means not established. Every fit judgment, hook-grammar reading, tone label and priority is **INFERRED**.

**F2. Holdings, SHOWN by local inventory.** Same route as the Start as X catalog's F2/F3: title checks in `docs/research/novels/LOCAL_LIBRARY.md` and `.json`, directory names under `docs/research/novels/` and `full-book/`, `docs/BOOKSHELF_INSPIRATION.md`, `docs/RESEARCH_GENRE_TROPES.md`, `docs/RESEARCH_GENRE_SWEEP.md`, and `/Users/weiwei/Downloads` filenames only. The named Calibre database is empty per that catalog's F2, so a Downloads file counts as DOWNLOADED-NOT-IMPORTED. NOT LOCAL means no title match in those places, not proof of absence.

**F3. Hook grammar.** H1 origin, H2 displacement, H3 mismatched caretaker or host, H4 belief gap, H5 hidden nature surfacing, H6 payoff. Pattern codes (PC, PS, PY, PV, PK, PD) are defined in the [audit](PREMISE_HOOK_AUDIT_2026-10-14.md#pattern-catalog).

**F4. Short-form premises.** The 167 short-form premises (SF001 to SF167: r/WritingPrompts titles, AniList synopses, a YouTube Shorts pass) and their H1-H6 breakdowns live in gitignored `premise-hooks/private/SHORTFORM_PREMISES.md`, with raw captions and failed routes in `SHORTFORM_RAW.md`. The audit summarizes them. The dragon egg premise Weibao described is **UNKNOWN**: no source page found (see the audit, F2).

**F5. Dedupe.** Works already in the Start as X catalog appear as cross-reference lines, not rows. A work fitting two PH sections has one full row and a cross-reference line in the other.
