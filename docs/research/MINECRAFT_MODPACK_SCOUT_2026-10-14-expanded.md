## How to read the catalog

The evidence column separates author-described mechanics from unverified receiving ideas. **Page** means an official author/project page was opened; **repo** means a public repository was opened; **tree** means a pinned file inventory was additionally inspected. None means installed, played, fully read, licensed for arbitrary reuse or ready to implement. The research questions and YAIRPG translations are proposals. "Niche" is an exploratory design lens, not a measured popularity ranking.

## Recovered ChatGPT response: what changes

**F6: SevTech becomes an explicit discovery comparison.** Its author README supports progressive visibility. The practical proposal is to compare visibility, interpretation, eligibility and rights separately, not hide all unknown content indiscriminately.

That supports the response's design distinction, but strings do not prove every runtime edge. See [pinned language evidence](MINECRAFT_MODPACK_SCOUT_2026-10-14-quest-guidance-evidence.json). An original YAIRPG adaptation could recognize legitimate prior practice without requiring tutorial-order obedience or replaying an already paid reward.

**F8: preserve different kinds of proof.** A delivered object, a crafted object and a successfully used object can satisfy different requests. The response's exact GTNH `ignoreNBT` example and standalone questbook release claim were not independently reproduced in this turn; retain them as targeted source questions. Existing Nomifactory sample retrieval/consumption fields remain evidence about that specific donor edition, not GTNH parity.

The paste includes blank entity labels and citation widgets without URLs. Those gaps are preserved in the recovered file. No missing label has been silently treated as a verified source. Its old advice that a full scripting language is "premature" is a proposal, not a user scope prohibition. Richer scripting remains a reachable later option when a selected world and useful consumer justify it.
