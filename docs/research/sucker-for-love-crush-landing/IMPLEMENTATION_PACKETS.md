Proposed first packet: P1 only. Reuse a native recipe and one new optional
conversation; record a stable cause ID, a compact preparation category and one
relationship memory. Later dialogue reads this cause. Existing saves default
to no episode, reward or relationship. Reserve a migration if state shape
changes. Repeated clicks must not duplicate consumption, reward or memory.

Preparation is not a price-to-affection formula. Original YAIR romance must
represent another person's willingness separately from material gifts. This
is an adaptation choice, not a claim that the reference code implements it.

Before calling a future slice gameplay complete, rebuild and exercise the

persistence changes. Content tone, natural progression and balance remain
