# Sucker for Love: Crush Landing, source audit, 2026-10-09

The useful lesson for YAIR is that a relationship can remember **how** a
milestone happened. The installed code stores three typed hearts from earlier
preparation choices, then consults those types at a final scene. It also keeps
completed endings through current-run object recreation. This suggests one
optional native conversation with a prepared gift, a remembered cause and a
later callback as the smallest original adaptation.

This replaces the acquisition-only report. Build `25151407` was inspected
read-only, without launching it or accessing saves. Private `data.win` matches
the installed file by SHA-256. A source-qualified Python parser recovered
27,609 strings, 6,108 code entries, 14,853 variables, 2,916 functions, 792
objects and 75 rooms. All unique bytecode streams decoded with zero parse
errors or unresolved variable/function references. That is instruction
recovery, not a full high-level decompilation or runtime acceptance.

F1/F2: **Preparation leaves a history.** The heart handler counts six feeding
flags with value 2 and classifies the result: at least three gives type 2,
none gives type 1, otherwise type 0. It records the type in successive heart
slots. The final event tests whether any stored slot is type 2 and selects a
bad or good scene branch. A later gain does not erase the earlier stored type.
Anchors: private `derived/disassembly.json`, CODE #4327 at byte offsets
4520620–4521260 and #4421 at 4703020–4703232.

F3: **Conduct changes recollection.** Argument-driven helpers increment good,
sleaze and wicked counters. Finale event branches test sleaze >3 and good >5.
These are distinct story counters, not evidence of a general autonomous dating
model. One later read spells `point_wicked` singular while the increment
helper uses `points_wicked`; that unresolved discrepancy stays explicit.
Anchors: CODE #1870/#1872/#1874 and #4421 at 4701572–4701632,
4702308–4702408 and 4702676–4702792.

F4/F5/F6/F7: **Preparation and aftermath have concrete state.** A gift action checks
place and possession with specific localized errors; clock advancement changes
waiting preparation states. Ending-room entry marks an outcome, saves it, and
tracker recreation restores the fifteen completed-ending flags. A menu has
fifteen configured slots and shows five at a time. Neither slot counts nor
room names prove all endings are reachable. Anchors: CODE #1721, #1647,
#5119, #1820, #1834, #1774 and #3881; exact instruction ranges are in
[FINDINGS.json](FINDINGS.json).

The strongest proposed adaptations, ranked, are in
[IMPLEMENTATION_PACKETS.md](IMPLEMENTATION_PACKETS.md): a prepared gift,
typed relationship memories, a closing recollection, clock-based household
preparation, an episode ending, separately retained accomplishments, care for
bystanders and precise blocked-action feedback. All eight are proposals.
Twenty-four small original touches are mapped to native owners in
[FINDINGS.json](FINDINGS.json).

YAIR already has native jobs/crafting, relationship axes/ties and bounded
memories, a compact biography and counted routines. Extend those owners and
the center menu. A biography is a lossy record, not reward authority; a
completed outcome should have an authoritative optional content flag. This
audit does not accept romance, true death, prestige retention or a new world.
