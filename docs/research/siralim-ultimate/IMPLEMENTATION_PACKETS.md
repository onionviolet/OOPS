## SU-P01: a place changes an ordinary decision

- **Scope:** one existing destination has one original local encounter object offering two useful actions or refusal, with different actual support/cost/outcome. K2/K5/K10/K13; synthesis P14. Source: `codex.csv:143-148`, local machine/clock/music examples in REALMS_AND_CARRY.
- **Reuse:** `previewSimulationCommand` and typed effects; `worldInstanceFacts` for the actual instance, not a global biome flag. No second travel or event engine.
- **Compatibility:** stable object/instance/occurrence IDs; absent data inert for old saves. State whether a renewable excursion is a new visit while the lived destination persists.
- **Failure/proof:** wrong place, unavailable fuel, refusal and repeated interaction cannot pay twice. Complete a useful local action, leave and return with the causal result retained. A color change or descriptive line alone does not pass.

## SU-P02: source-aware build inspection

- **Scope:** one current carried method/item gets a read-only source/lifetime/usability view, and one valid comparison. K3/K9/K11/K14/K30; P04/P11. Source: `ui.csv:35-85,422-423`, `codex.csv:186,189`.
- **Reuse:** current ability/item owners and `projectKnownActionRequirements`/`projectActionLegibility`; no copied foreign trait registry or hidden prerequisite leakage.
- **Compatibility:** projection only by default. If a selected sort/filter becomes saved, add an explicit old-save default. Editing a view must never grant or refresh an effect.
- **Failure/proof:** owned but suppressed, known but unowned, expired temporary effect, unloaded source, and undisclosed cause stay distinct. At 1366x768 keep actor summary, selected detail and relevant native action readable together. Rebuild and exercise keyboard entry/exit and native action outcome.

## SU-P03: travel retains the actual carriers

- **Scope:** preview/commit for one existing edge classifies body, learned method, source/fuel, physical stock, permissions, local benefits and visit effects. K15/K18/K25; P05/P12. Source: `codex.csv:148,151-154,168-171`, NATIVE_TRACE save boundary.
- **Reuse:** `planWorldDeparture`, `createWorldVisit`, `planWorldInstanceUpdate` and the existing durable publisher. A visit constructor explicitly grants no passage.
- **Compatibility:** retain existing native instance, visit, custody and pending-job records. Define suppression versus deletion. Add versioned local fields or recoverable rejection if meaning changes; never normalize a foreign source into free global XP.
- **Failure/proof:** cancel travel, insufficient support, stale quote, double departure and return/revisit. Show a useful carried function still works where lawful, a local bonus stays local, and the same unique stock is neither cloned nor lost. Exact persistence roundtrip required.

## SU-P04: finite causal combat chains

- **Scope:** NEW bounded extension to P14/P16. Select one actual native encounter with repeated effects; declare event source/target, ordering, re-entry and stop/defer policy. K3/K10/K18/K34. Source: `codex.csv:190-193`, named `bc_Event*`/`bc_On*` families; exact foreign queue implementation remains unproved.
- **Reuse:** existing native combat path and preview/commit legality. First identify two actual callers before proposing a shared primitive. Siralim thresholds are evidence of one solution, not YAIRPG balance constants.
- **Compatibility:** old encounters keep prior behavior unless a migration/compatibility decision selects otherwise. No universal once limits, no silent event dropping and no new scheduler merely to mirror Siralim.
- **Failure/proof:** self-trigger, two-effect cycle, same-tick independent event, stale/dead target and persistence at an allowed boundary. Demonstrate termination and one useful ordinary chain, with source-attributed history and no duplicated spending. Presentation speed may change without changing results.

## SU-P05: standing buys access, currency pays the price

- **Scope:** one existing local institution offers a useful service unlocked by standing and paid from owned stock. K7/K8/K21/K29; P07/P18. Source: `codex.csv:151-154`, `overworld.csv:122-158`.
- **Reuse:** institution/permission/custody owners and staged complete-basket costs. A new rank label must have a real downstream service reader.
- **Compatibility:** preserve issuer IDs and existing permissions. Possessing a token does not create standing, ownership or jurisdiction in another place.
- **Failure/proof:** enough money but no access; access but missing money; refusal; changed quote; local blessing outside its scope. One actual service changes later ordinary play and survives the relevant persistence roundtrip.

## SU-P06: expeditions pay for useful home services

- **Scope:** one home project consumes a real trip-earned material and unlocks one useful refit/training/repair function. K8/K9/K13/K25; P02/P06/P12. Source: `codex.csv:168-171`, `projects.csv` stable project tags.
- **Reuse:** existing production/work/stock and hub service owners. Keep custom visual decorations distinct from a service's consent, access, means and active availability.
- **Compatibility:** one persistent project/paid receipt; missing new data grants no free completion. No reset of other projects or home layout.
- **Failure/proof:** partial material basket, interrupted work, reused receipt, trip departure and return. The finished service must consume or modify something useful in ordinary play, not only unlock a menu label.

## SU-P07: reachable acquired role swaps

- **Scope:** one acquired role/loadout switch quotes body/source/equipment dependencies and keeps earned learning under declared rules. K3/K4/K15/K33; P03/P16. Source: `codex.csv:195,235`, `ui.csv:827-841`.
- **Reuse:** actual power/ability/role owners; the start adapter does not overwrite a continuing actor or rewrite biography to simulate mastery.
- **Compatibility:** preserve origin, learned methods, custody and obligations. Save selected active role separately from acquired options with an explicit default/version.
- **Failure/proof:** unsupported body, absent source, incompatible equipment, insufficient swap cost and cancel. Demonstrate useful legal expression after a swap and return, with no duplicated perk points, fuel or items. No new permanent exclusion is imposed.
