2026-10-11. Source audit only. Proposed adapters and acceptance cases are not implemented gameplay or accepted fictional rules. No original sealed truth appears here. JoJo source semantics must come from the source ledger, separately from these original engineering proposals.

It does not yet establish general conceptual combat, arbitrary restoration, or JoJo time semantics. Several bounded object, body, observation and temporal implementations already exist. ## D1 First original slice: minimum reusable work

Proposal: one small authored encounter with a real everyday object consequence, a discoverable effect, two distinct supported responses, withdrawal and a direct-force route when the authored rule permits it. This does not select a JoJo campaign or accept the old Borrowed Fastening fixture.

Build only the adapters that this chosen fixture proves necessary:

1. **A1 Target and activation contract:** stable scene/object/actor reference plus revision, actual supported contact/cover/body channel, source/cost/recovery gate shared by command and response. Revalidate declared sustained invariants; retain interruption cost policy.
2. **A2 Knowledge projection:** private truth separate from each actor's observed evidence; observer-safe preview/rejection and NPC policy inputs. Reuse knowledge and observation receipts. Paid identification supplies information, not execution means.
3. **A3 Object consequence and settlement:** modify the same authored object/function or native identity with custody/history. Reuse acquisition/native durability/publication where their actual semantics fit; settle the unique aftermath exactly once.
4. **A4 Save and integration contract:** validate cause/source/target links and ongoing effects in the existing envelope; additive absent-domain defaults, declared revision compatibility, no live publication on failed writes. One integrator owns all shared seams.

These four items are a proposed minimum, not a callable API or runtime assignment. Numbers, target classes, counter routes, source visibility and lethal policy remain fixture choices. No universal weakness requirement, body convention, damage-sharing rule or one-power limit is introduced.

## D2 Later systems kept separate

Time-domain scheduling needs explicit affected actors/objects, native timers, internal-step budgets, exceptional movement, impact order and one release/catch-up receipt. Skipped time, acceleration, rewinds and forecasts need distinct contracts; retain existing bell-yard/offline semantics as bounded implementations.

Topology changes need real segment/object identity, adjacency/occupancy/navigation consequences and removal history. General repair needs original-form/fragment rules rather than a generic HP refill. Memory writing needs qualified private history plus constrained action enforcement. Exact source theft/copying needs instance/body/fuel fidelity. Each should earn its own playable slice when an actual selected power requires it, rather than precede the first encounter as speculative infrastructure.
