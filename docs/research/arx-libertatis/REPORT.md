# Arx Libertatis source pass, 2026-10-14

A learned rune changes which authored methods the player can use. Those methods can light or extinguish eligible fixtures, extend the reach of ordinary interactions, support levitation, create barriers and remove particular existing effects. Drawing recognition ends at rune IDs and a spell ID. Target rules, mana spending and world changes execute afterward in separate code. This is a useful model for YAIR's LP1 lesson-to-verb chain and for validated technique recipes. It does not establish arbitrary generative magic or a universal door-unlock spell.

The source pass is complete at its static boundary. The commercial scripts, level assets and localization are missing, so particular acquisition scenes, door puzzles and native play remain unverified. Steam and GOG were checked read-only. No local Arx installation or matching Steam library record was found; both browser account routes were signed out, so current account entitlement remains **unverified**. Nothing was purchased, installed, built or launched, and no user save was accessed.

One source-derived before/after example makes the distinction concrete: **INFERRED**, if a player owns the creation rune but lacks the fire rune, drawing their ignition recipe can select the spell but fails the ownership check. Learning the missing rune changes that check and can reveal the recipe. A subsequent cast still needs mana and eligible fixtures. This was not executed in a game.

Magic sight is a separate sustained perception/rendering effect. It does not ignite physical lights or prove discovery of every concealed object. Counter/removal spells act on declared live effects and their limits. A broad “reveal” name is likewise not proof of a universal environmental reveal.

## Definitions, mana and retained depth

The full private tables preserve 21 rune definitions, including 20 ordinary script-learnable runes, and all 50 spell records. Each spell joins its current enum value, script/event name, recognition sequence, book sequence, localization IDs, page tier, visibility/duration/audio flags, upfront cost expression, effect class and runtime method locators. The internal hidden entry whose book recipe differs from its recognition registration is retained explicitly. Table completeness does not imply every combat spell was semantically audited.

All 50 upfront mana cases are retained exactly. Sustained costs come from effect Launch methods, separately from book duration icons. Ignition and dousing are paid world changes; telekinesis, levitation and magic sight also drain mana over time. Natural recovery is stat-dependent and capped. [Private C4 notes](private/CALL_NOTES.md#c4-authorization-target-cost-and-effects) preserve formulas, units, branches and the order of spending/refusal instead of inventing a generic cost formula.

Prepared casts store spell metadata before paying mana. Release checks current affordability but final dispatch can use a stored caster level. They are not idle jobs. NPC/item script casting can skip drawing and reach the same effect implementation. This is especially useful evidence that a gesture interface need not own effect rules.

Rune flags and prepared-cast metadata have source save/load edges. No save behavior was executed and active-effect persistence was not comprehensively audited. The missing commercial localization is represented by 100 UI key references with null text and explicit display conditions. Full commercial dialogue cannot be honestly recovered from this repository.
