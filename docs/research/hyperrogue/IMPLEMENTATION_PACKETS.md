**Observable acceptance:** Preview both places, execute the useful tool action in one, then show its different lawful outcome in the other. A failed or queued attempt uses the same admission and spends nothing on rejection.

**Compatibility:** Additive inert defaults for older worlds; any changed save meaning needs an explicit compatibility decision.

**Bound:** Park an original two-place slice inside the selected canon-first world. Do not add two new worlds just to prove this pattern.
