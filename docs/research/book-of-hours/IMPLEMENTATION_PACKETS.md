# Selected original Book of Hours-inspired packets

Five unaccepted original proposals selected from 17 source paths and 38 findings. They are research outputs, not a runtime dispatch. [PACKETS.json](PACKETS.json) owns requirements, existing owners, concrete new gaps, compatibility and later acceptance. The larger lessons remain in [REPORT.md](REPORT.md) and [FINDINGS.json](FINDINGS.json).

| Packet | Observable original play | Existing foundation and bounded extension |
| --- | --- | --- |

The source numbers, nine Wisdoms, soul cards, Hush House, visitor cast and Lighthouse Institute are not adopted. Source invitation routing does not establish willingness, so the original hosting packet explicitly needs independent actor acceptance and availability. Current paid instruction, care and physical work remain implemented-unverified in their existing owners; this dossier grants none of them new verification.

Every packet uses the current common clock, durable command path and existing stock/body/knowledge owners. Old saves remain inert until an optional activity is deliberately accepted. A compatible item is an actual owned object; a learned source is not a copied rank; an account is known only to its real recipients. Stable content versions, exact cancellation/refund policy and migration belong to the implementation owner if a packet is selected.

Later proof is an observable full chain: choice and actual means, commitment, work, failure or completion, real output/retained cause, later consumer and changed return. Fresh-origin gameplay, save/reload and failure verification stay on the later backlog. No current test or implementation gate is claimed passed.
