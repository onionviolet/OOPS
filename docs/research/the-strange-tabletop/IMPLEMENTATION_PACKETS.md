# Bounded implementation proposals

PROPOSALS only. No runtime source inspection or patching was needed for this tabletop pass. Owner seams below are document routing, not claims that named APIs already implement these contracts. Canonical existing synthesis scopes remain in `../cross-game-synthesis-2026-10-14/PACKETS.md`.

All future UI claims require a fresh rebuilt browser origin at 1366x768 desktop, useful visible outcome, save/reload and literal-file import where persistence changes. Mobile, full-world rollout, career overhaul, generic offline catch-up and new profile switching are deferred. No runtime implementation is authorized by recording these packets.

## MWTS-P01: Crossing mode and per-carrier preview

Synthesis: P05/P04/P14. Kit: K2/K4/K9/K15/K18. Owners: RULES_FROM_SCRATCH; nested-world owner; start/branch integration map. Evidence: F02/F05/F07/F08 in FINDINGS.json.

**Scope:** One original route with translation-like adaptation and one distinct physical passage fixture. Reuse existing travel preview/commit and actor owners; no universal travel engine.

**Proposed contract:** Declare source/destination instance IDs, route mode, actual actor, body, current resources, knowledge policy, custody and destination support. Preview uses only known facts. Commit one validated state change with travel receipt.

**Observable acceptance:** Arrive, use a supported local action, leave and revisit changed destination. Refuse stale quotes without spending. Check foreign gear that arrives but lacks support; no copied stock.

**Compatibility and failure:** Version any new edge/receipt state; old routes retain behavior. Failed persistence leaves departure intact. Save/reload and literal-file import at both endpoints; no user saves.
