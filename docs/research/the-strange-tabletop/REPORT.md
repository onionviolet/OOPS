# The Strange: one traveler, local forms and local laws

The Strange makes destinations differ through operating laws, local forms and abilities, and distinct social context. Translation adapts the traveler; an inapposite gate carries the existing traveler through. Ordinary gear waits for a return, while cyphers cross. The useful lesson for YAIRPG is an explicit travel contract, not a universal rule that removes imported powers.
