**F6/F7 (shown):** Communitree is organized by five creator modules: jac, aar, aca, tfu and des. File sizes are 1,453 / 1,032 / 3,166 / 882 / 6,102 lines respectively. Creator names group styles; mod metadata names ducdat0507. No inspected contributor contract assigns one writer per module. Shallow history cannot settle how contributions were managed. **F16 (shown):** Profectus makes a lazy layer factory with stable ID, event emitter and public return object. Persistent refs must occur somewhere in that object; the persistence registrar emits a console error with creation trace when one is missing. The template recommends returning all useful features, while requiring state and externally accessed features. Return-object coverage is a durability concern, not just UI style. Dynamic layers must be reconstructed by getInitialLayers from saved player data. Accessing a disabled layer remains possible, so disabling tick dispatch is not deleting state. [profectus/src/game/layers.tsx:218–240](https://github.com/profectus-engine/Profectus/blob/d69197d5c7225a0bb58b5a4d5f8e19c1c04a61ea/src/game/layers.tsx#L218-L240); [profectus/src/game/persistence.ts:362–372](https://github.com/profectus-engine/Profectus/blob/d69197d5c7225a0bb58b5a4d5f8e19c1c04a61ea/src/game/persistence.ts#L362-L372); [profectus/src/data/projEntry.tsx:105–114](https://github.com/profectus-engine/Profectus/blob/d69197d5c7225a0bb58b5a4d5f8e19c1c04a61ea/src/data/projEntry.tsx#L105-L114)

**F16/F18 (shown):** global dispatch completes all preUpdate listeners, then all update listeners, then all postUpdate listeners. The docs suggest generation, automation and state checks. That phase separation does not establish independence of listeners within each phase. The phase comments describe milliseconds while the caller sends seconds. Pin actual units in author contracts. [profectus/src/game/layers.tsx:391–401](https://github.com/profectus-engine/Profectus/blob/d69197d5c7225a0bb58b5a4d5f8e19c1c04a61ea/src/game/layers.tsx#L391-L401); [profectus/src/game/gameLoop.ts:15–17](https://github.com/profectus-engine/Profectus/blob/d69197d5c7225a0bb58b5a4d5f8e19c1c04a61ea/src/game/gameLoop.ts#L15-L17)
