# The Modding Tree family research extension

The Tree family separates progression rules, stored state and derived presentation. Profectus adds persistent layout positions, transient drag previews and explicit save registration, with static offline-accounting concerns left for runtime verification.

The useful new evidence is conversation admission, retained versus derived state, and explicit action/UI boundaries. TMT 2.7, Prestige Tree Rewritten, Communitree and Profectus pinned source snapshots. Source inspection only. These are incremental frameworks/games, not general text-world engines. Source-derived UI structure is not desktop usability proof.

All recommendations are PROPOSALS. No runtime implementation or accepted decision. No game was launched, downloaded code run, personal save opened, account used, install changed, git staged, committed or pushed. Only assigned aspect folders and asp-text scratch were written.
