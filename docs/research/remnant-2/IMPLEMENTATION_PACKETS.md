# Implementation proposals

All packets are PROPOSALS. No runtime writer assigned, no new acceptance gate imposed on current work. Extend existing consumers. Before execution, an owner must read current source and reserve its files. No source symbol in this research is an assertion of today's YAIRPG implementation.

UI target for any selected packet: 1366×768 desktop, a known consequence or useful changed action in its existing surface home. Link `docs/UI_RULES.md`; keep the log intact, use shared controller/back/Esc where needed. Mobile optimization is deferred. A data inspector alone is not playable delivery.
