## What the deeper sweep changes

**F1, SHOWN:** daily life is built from different state machines. Crops store care and maturity; magic plants collect five element totals; hives retain a history of surrounding plant power; workshops separate work completion from collection; specialists retain a selected future reward. Treating all of them as one recipe timer would lose the useful behavior.

**F2, SHOWN:** knowledge, permission, tools and custody are separate. A recipe exchange can execute an unlock command, a building can exist without all recipes, and finished goods can remain uncollected. Existing source calls also expose incomplete transaction boundaries: fixed ShopController.Buy is only an item/event mutation, and workshop cancel is separate from resource return. These are caller-read questions, not verified player exploits.

**F3, SHOWN/INFERRED:** the census now routes all **296 TextAssets and 203 inventoried services**, across 22 source families, to candidate YAIRPG owners. Fifteen deep accounts link native/data evidence to kit K codes, synthesis packets and topic palettes. A generic owner route is not an implemented reader or accepted product decision. [FAMILY_MAP.json](FAMILY_MAP.json) retains each old documentation state and current partial status.
