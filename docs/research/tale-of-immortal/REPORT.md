# Tale of Immortal source audit, 2026-10-08

The extraction and bounded audit are complete. The strongest lesson for YAIR is that a life becomes interesting when preparation, remembered conduct and institutional obligations change later choices. Another realm ladder alone would miss that.

The install stayed read-only and remains installed. No launch, user-save access, YAIR source edit, build or commit occurred. This is source research, not playable acceptance.

## What was recovered

**F1: Actual data, with a current-build check.** Build21758240 uses Unity2020.3.9f1c1 and Windows IL2CPP. A734MB selective snapshot contains2034 SHA256-matched inputs. Official modding workbooks yielded1613 readable sheets from914 files, including realm, aptitude, technique, NPC, sect, event, item, monster and localized text tables. These counts describe extraction, not every row reviewed.

**F2: Fresh signatures and targeted bodies.** Existing MelonLoader stubs have address/field drift. A fresh Il2CppDumper map supersedes them. Sixteen selected methods were disassembled; useful paths were reviewed for memory retention, history, event probability, material-rate aggregation and save compression. Partial compiled realm defaults matched all440 recovered scalar/string fields across11 identifiable workbook rows. The binary also supplied missing NPC-memory defaults:14 records, each with count parameter10 and retention100years. Mod overrides were not inspected.

**F3: Connected systems.** Breakthrough quality depends on preparation, and failure can leave a12-month recovery condition. Sects connect rank and duties to wages, loyalty, reserves and war aftermath. Events separate eligibility from chance, share cooldowns and can create a successor when they expire. Sealed souls have an authored release/reseal branch; inheritance can inspect earlier actions. These table chains are distinguished from executable transactions not yet traced.

**F4: History has different lifetimes.** Current native code stamps NPC memories with target/month, passes a configured count to a limiter and prunes by configured age. Ordinary logs have a five-calendar-year cutoff; that method leaves vital logs untouched. Save writing supports optional GZip compression followed by optional encryption. This does not establish a bound on the whole save, active flag settings or crash safety.
