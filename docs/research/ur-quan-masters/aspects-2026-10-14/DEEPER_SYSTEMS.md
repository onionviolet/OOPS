# Three deeper systems by payoff

PROPOSALS ONLY. These extend the inventory's highest-payoff partially documented joins. [Source locators](../SOURCES.md) pin every source. Complete foreign systems and native behavior remain out of scope.

## D1: Conversation is an economic and evidence transaction

**SHOWN:** `DoResponsePhrase` stores an ID and callback; `SelectResponse` invokes it; `melnorm.c:DoBuy` deducts costs and sets capabilities/knowledge. `AlienRaces` has two selected knowledge-grant cases. `syreenc.c:NormalSyreen` reads knowledge and independently checks carried evidence. `starbas.c:CheckBulletins` distinguishes replay from first-delivery escort grants. These are three different uses of dialogue over the same dispatch mechanism.

**Implementation chain:** selected response -> predicate reads -> spend or refusal -> retained flags/stock -> next options -> later encounter reader. The full phrase text, 27 tables and 4,790 call-site records are retained privately. Those records are lexical source context, not an automatically solved dialogue graph. Session suppression edits loaded text; it is not a durable quest fact.

**Inference for YAIRPG:** strengthen P19/P11/P20 through one scoped native host and a second useful consumer. Preserve current staged publisher and coherent cursor/receipt save. Avoid UQM's direct-global mutation as a model for paid writes. Acceptance is both alternative/refusal branches, a stale offer, failed write, changed revisit and exact pending/paid save roundtrip. K6/K11/K18/K20/K23/K31.

## D2: Exploration needs a baseline plus mutable aftermath

**SHOWN:** default analysis/scan seeds generate nodes; per-node retrieval masks mark changes; planet info persists; special system hooks override named local behavior. Cargo limits, hazard tables, landing gravity and fleet contact affect whether the same place is worth visiting now. `genspa.c` chooses different contact and discovery text based on retained world state.

**Implementation chain:** stable system/world descriptor -> seeded default or special hook -> scan node -> capacity/risk/collection -> changed mask and real cargo -> saved campaign -> changed revisit. Initial generation, depletion and traveler inventory are separate. The default mineral path can accept only free hold space yet mark the full node retrieved; no remainder quantity is retained in this inspected path. Stable retrieval is not itself material conservation.

**Inference for YAIRPG:** P15/P12 should connect one generated fact to an actual harvesting consumer and saved stock/custody. UQM-N1 is a future fitting choice only with real capacity consumers. A source seed cannot stand in for native mutable owners. Test separate instances and repeated visits under explicit generation revision compatibility. K5/K9/K15/K18/K28/K29/K33.

## D3: A date queue supports political aftermath without a generic society engine

**SHOWN:** `AddEvent` validates relative/absolute dates, immediately dispatches relative zero delay, and otherwise inserts by date. `processClockDayEvents` consumes due events. `MoveGameClockDays` advances day by day and processes due events, rather than merely adding a number to a calendar. `gameev.c` has 18 named selectors: periodic portal access, daily encounters/growth, multi-step fleet missions and delayed consequences. Selected local events postpone if the player is present at the affected system.

**Implementation chain:** authored trigger/date -> queued selector -> bespoke C conditions -> actual fleet/world changes -> subsequent contact/report. A menu render does not drive the political clock. This source is evidence for scheduled authored politics, not universal background lives or general eligibility/priority/cooldown/closure machinery.

**Inference for YAIRPG:** extend P10/P13 and return-news P20 using the joined scheduler proposed by the start integration map. Persist due-event cursor and actual consequences together. Specify ordering versus paid actions and supported clock jumps; keep unsupported absence frozen. Do not import UQM's global crisis deadline into existing saves. K7/K12/K23/K29/K32.
