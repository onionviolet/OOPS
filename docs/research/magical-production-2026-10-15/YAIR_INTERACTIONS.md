# Production mechanics across YAIR systems, worlds and cheats

2026-10-15. Requested follow-up to [downloaded-game mechanics research](REPORT.md). This is a bounded current-source and design-owner audit, followed by original interaction proposals. It does not select a new world, revise accepted laws, resume a paused assignment or authorize implementation.

## Outcome and authority

**F6:** YAIR already has useful narrow consumers for much of this design space. The largest new value is connecting their real outputs, ownership and stopping conditions, rather than building a separate factory engine.

**F7:** Production should be a process that different means can perform or bypass. Ordinary craft, a skilled helper, an engineered device, body production and a creation cheat need not follow the same recipe. A cheat that actually creates matter is an exception to ordinary material conservation, not a reason to invent compensating costs.

**F8:** Cross-world value has several forms: a useful object, learned method, tested specification, accessible specialist, operating source, compatible carrier or institutional right. Carrying one does not imply carrying the others.

**F9:** Existing source already goes beyond the earlier five application examples, including a named stock reserve, leased assistance, preservation, represented modeling, independent NPC work and original artifice. General production networks, arbitrary conditional automation, editable assemblies and universal cheat execution remain distinct gaps.

**F10:** Time and identity are consequential boundaries. A preserved object, an accelerating workshop, an inactive world and a rewound world have different behavior. The current narrow continuation implementation cannot certify a multiversal factory.

## Interaction atlas beyond P6–P10

All MP rows are original proposals. **ACCOUNT** means retain a constraint when relevant work is selected; **LATER** means useful optional content or behavior, not new required work. Existing source behavior is identified through SC references rather than assumed from a feature name.

| Code | Interaction and actual player consequence | Fit / disposition |
|---|---|---|
| MP01 | **Personal equipment competes with orders.** Reserve sound metal for a shield while selling lower-grade fittings; a rush order can consume the stock needed for an expedition. Show actual free versus held stock. | SC01/06/18; ACCOUNT. Shared priority across consumers is not yet a general policy. |
| MP02 | **Input preparation can replace brute scale.** Dry, grade, grind, refine or align a material before using a scarce catalyst. A capable spell may supply the relevant process condition instead. Compare total cost, not just machine output. | SC01/08/09; LATER content using real consumers. No invented universal processing tax. |
| MP03 | **Reusable apparatus is different from fuel.** A lens, clamp or ritual focus occupies a job and returns; a charge is spent; an installed component stays fitted. Higher throughput may need a second tool rather than more material. | SC07/08 and assembly owner; ACCOUNT exact reservation/return versus consumption. |
| MP04 | **Byproducts can become another career's input.** Tailings, spent carriers or recovered fittings can support an actual repair, crop treatment or service. Give unwanted outputs a disclosed hold/sell/recycle/dispose policy. | Factory backpressure + SC01/18; LATER. No compulsory all-output clogging where the process does not require it. |
| MP05 | **Financing can be the bottleneck.** A guild has materials but no money for wages; the player funds a finite order, takes goods or waits for actual demand. Physical coins matter only in worlds that give denomination a function. | SC09/13/18; ACCOUNT. Production does not replenish a buyer's purse automatically. |
| MP06 | **Site capacity competes with social commitments.** Calibration and teaching both need the same artisan, while construction needs the same bench. More player speed need not increase another person's availability. | SC07/13; ACCOUNT actual participant/site reservations. |
| MP07 | **Repair can retain identity.** Improve the real apparatus or replace a worn module; keep the existing bond, history and ownership where supported. Salvaging a unique item is a different action from making a fresh copy. | SC01/07/09 and assembly owner; ACCOUNT. Editable universal assemblies remain planned. |
| MP08 | **Quality must feed a real use.** Precision can improve a guard, measurement or known fit; purity can change a supported reaction; condition can limit operation. Avoid a quality number that buffs every output. | SC01/09; LATER one selected input→consumer join. |
| MP09 | **Research is broader than new recipes.** Test lower consumption, different substrates, reliability, portability, easier control, recovery or a new consumer. Retain baseline and changed conditions as method revisions. | SC02/03/09/12; ACCOUNT evidence; generalized invention remains planned. |
| MP10 | **Assays and production have different outputs.** Inspection may reveal a defect; an experiment produces observations and actual samples; production repeats a qualified method. Do not award discovery merely for queueing it. | SC02/09/12; ACCOUNT. Existing oral-only mixture learning is a narrow consumer, not a universal requirement to ingest unknown products. |
| MP11 | **Teaching changes who can execute.** A recipe notebook can be sold or taught; the apprentice's own skill/source and stock decide the result. Player teaching recognition and artisan production mastery need separate causes. | SC13/14; LATER using the existing independent-worker specimen. |
| MP12 | **Secrecy changes production organization.** A closed workshop may hide a process but still reveal purchases, noise, deliveries or witnesses where authored. A paid report remains a dated account. | SC13 and ability/knowledge owners; LATER. No universal detection or inevitable punishment. |
| MP13 | **A batch can be safe to repeat but unsafe to substitute.** An ingredient shortage pauses the current method; a supported substitute is a different revision with its own known or unknown properties. | SC02/03; ACCOUNT. Never silently change committed inputs. |
| MP14 | **A method revision may rebalance the entire line.** Reducing feedstock can also reduce a co-product needed elsewhere. Keep an older useful method when its real rules permit, rather than automatically treating every new revision as globally superior. | Factory recipe change + SC03; LATER revision choice, not silent mutation of saved outputs. |
| MP15 | **Portable workshops have several requirements.** Carrying an apparatus requires cargo access; operating it requires space, control, power, support and the right target medium. Moving it need not destroy its inventory. | SC08/11/15; ACCOUNT. Storage alone does not create a habitable, powered production realm. |
| MP16 | **Stasis changes the best shipping route.** Preservation can make distant samples viable; it can also pause a fermentation/growth stage that needs time. A machine outside stasis may still be unable to reach an input inside. | SC10/11; ACCOUNT. Current code proves only named exposure policies, not arbitrary biology. |
| MP17 | **Time acceleration can move rather than remove a bottleneck.** Faster processing can exhaust stock, fill storage or wait for an outside delivery. State which clocks cover workers, fuel, growth, decay, deadline and boundary transport. | SC04/08/15 plus accepted time direction; ACCOUNT, no new dilation implementation claimed. |
| MP18 | **Banked time is not extra yield.** A high-yield recipe changes output per input; a speedup changes elapsed simulation per real second; efficient bank use changes time credit. Keep them separate in quotes and receipts. | Accepted time-bank owner + Alterhistorian comparison; ACCOUNT. |
| MP19 | **Travel interrupts by means, not by UI presence alone.** An autonomous local plant may run without the player if actual local support/time permits; an inactive frozen world still pauses unless selected means change that law. | SC04/07/15; ACCOUNT. Remote commands and remote observation are separate permissions. |
| MP20 | **Rewinds split knowledge from stock.** A remembered design can shorten a supported investigation while a consumed part returns or remains consumed according to the actual boundary. External goods, loans and payments must not be settled twice. | SC16/17 and CA5/CA6; ACCOUNT for a selected extension, not current foreign-world support. |
| MP21 | **Clones can divide labor without cloning infrastructure.** Separate bodies can operate separate stages when their actual agency/source allows; one borrowed tool, bench or shared energy reserve remains one resource. | SC07/08/13/14; LATER clone adapter, not generic current concurrency. |
| MP22 | **Body production is a legitimate supply route.** A source-qualified organism or constructed body can make a real batch or grow a structure. Internal stock is one owner; harvesting, detaching and continuing growth can differ. | Nonhuman making G1–G5; LATER. No generic living-being-to-resource conversion or fixed biological drawback. |
| MP23 | **A nonhuman maker changes interfaces.** Breath may supply heat; roots may grow a brace; tentacles may hold parts; an intermediary may work beyond reach. Each supplies the function it actually has. | Nonhuman making MK1–MK15; ACCOUNT. Current humanoid container access is not evidence for these bodies. |
| MP24 | **Enchanting and assembly cross material and authority boundaries.** Fabricate a carrier, learn a pattern, establish a bond, charge it and activate a function. Some powers skip several steps; some personal powers cannot be manufactured as parts. | SC08/14 + assembly/ability owners; LATER. No universal slot or energy conversion system. |
| MP25 | **Territory can supply a process condition.** A suitable room, vein, field or local law can enable a reaction. It is a real site property, not an inventory token for an entire place. | SC07/15 + nonhuman G4; LATER. A larger factory is not automatically territorial rule authority. |
| MP26 | **Combat changes production and production changes combat.** Prepare a known consumable, maintain gear, fortify a route or disrupt an enemy's actual supply. Keep source contact and tactical eligibility distinct from possession. | SC01/07/08/14; LATER local authored chain. No mandatory combat career or level-scaled opposition. |
| MP27 | **A created mind is not an ordinary component.** A sentient construct can become a worker, resident or kin with the actual authored agency model. Maker, owner of materials, animator and person need not coincide. | Nonhuman making/kin owners + SC13; ACCOUNT. Factory's Sentient Meat labels do not establish YAIR personhood or ownership laws. |
| MP28 | **Titles and system objectives need causal credit.** Distinguish personally made, supervised, commissioned, gifted and duplicated goods. A reward can intentionally accept any of these, but a player craft counter should not rise just because an NPC made stock. | SC09/13/17/18; ACCOUNT. Craft title bonuses do not imply arbitrary achievement powers. |
| MP29 | **Duplicates affect exchange, evidence and uniqueness differently.** A copied reagent may replace feedstock if its source permits; copying a certificate does not automatically create issuer authority. A copied object gets its actual identity/lineage terms. | SC14/15/18 + cheat/assembly owners; ACCOUNT. Never add a scarcity cap merely to cancel an authorized duplication power. |
| MP30 | **Infrastructure changes local stories.** A reliable clinic, crossing, workshop or water service can change actual access, demand, relationships and later opportunities. A completed order need not count as completing the world's campaign. | SC07/09/13/18 + Frontier/Paradise owners; LATER content, no universal prosperity score. |
