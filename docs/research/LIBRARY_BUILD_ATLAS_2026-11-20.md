## Planning from this map

Accepted build order is the procedural foundations and named lead work in [PROJECT](../../PROJECT.md#current-focus). The following are proposed research moves within that order.

1. **A1. Map checked cases to the next consumer.** As a build question comes up, use a compact entry with the question, two source cases, an unknown, an existing OOPS owner and a testable result. For example, give the ferry one specified ally-assisted outcome and one exposed concealment outcome. This reuses the bank and the design owner.
2. **A2. Extract by question.** When the recipe, job, injury, or settlement interaction lacks evidence, inspect the smallest useful span first. Start with existing outputs and held sources. Use a contrasting or held-out case to test the generalization.
3. **A3. Track edition and access gaps when they affect the next build.** Reconcile missing locations, incomplete compilations, PDF layout and manga chapter/edition questions under the relevant holdings record. Give acquisition quota to a specific unresolved gap.

## Scope and counts

Live inspection queried the Source Library asset and location tables read-only, checked at least one registered path per hash for file presence, and joined PDF hashes to the central screening ledger. It found **4,487 assets with a present file** of 4,579 registrations. Present files break down to **2,144 CBZ, 1,286 EPUB and 1,057 PDF**. The other 92 registrations had no present registered path in this check. These units count assets by hash. Volumes, compilations, translations, formats, and duplicate editions can represent the same work.

Calibre separately records **232 books with at least one registered format**. This is a metadata count. The stores overlap, so a combined unique work count needs edition matching. [Calibre catalogue](CALIBRE_CATALOGUE.md).

The current mapping uses the library index, registered text outputs, PDF screening ledger, project and world owners, and bounded research reports. It covers each main shelf at its available evidence level. Private unregistered captures and external collections sit outside the numerical census. Game dossiers are included as references without a fresh ownership or installation count. This pass does not establish the semantic completeness of individual extractions, source coverage of every volume, or new runtime proof.
