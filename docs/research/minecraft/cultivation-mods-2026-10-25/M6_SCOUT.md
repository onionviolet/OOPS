**Date:** 2026-10-25
**Scope:** platform discovery and public-page listing only. No jars were run, installed, opened, or decompiled. This report does not score A/P/M/U or make absorption claims.

## Findings

The author quote does not identify a username or link, so I cannot attach it to one creator with certainty. The search does find independently verifiable mods for all three named properties:

- **Reverend Insanity:** [Gu Craft](https://www.curseforge.com/minecraft/mc-mods/gu-craft), by **poggerpengy**, explicitly describes itself as based on *Gu Zhen Ren*. Separately, the larger Chinese [[gu] 蛊真人](https://www.mcmod.cn/class/19099.html) lists **奈落就是我** and **The小灰** as owners, with MCreator credited for programming. These are distinct projects.
- **Lord of Mysteries:** two plausible projects surfaced. [Project Mystery](https://github.com/Herdeny/Lord-of-Mysteries) is authored under the GitHub account **Herdeny**; its README says Minecraft 1.20.1, Forge, and last updated 2026-08-14. [诡秘之主同人模组](https://www.mcmod.cn/class/30167.html) is a separate NeoForge 1.21.1 project whose MC百科 page names **晚间星光** as owner. No evidence ties either creator to the quote itself.
- **Shadow Slave:** [Dawn of the Spell](https://www.curseforge.com/minecraft/mc-mods/dawn-of-the-spell) by **LostFromSleep**, with **K4z0w** listed as contributor, already has a publicly downloadable **0.2.1-alpha** for Forge 1.20.1. The page calls it hard alpha. So “released soon” may refer to a fuller release or another project; an alpha is already public. [Aspects of Cataclysm](https://github.com/L0stFromSleep/Aspects-of-Cataclysm) is a related source repository/add-on, not the main mod.

The best fit is not limited to adaptations: a few standalone projects model systems that map unusually well to OOPS's existing progression, crafting, world-state and item owners. I ranked by distinct mechanics and likely system fit, then source quality; download counts are context, not the ranking formula.

### Older Chinese cultivation trail

The MC百科 1.12.2 Chinese Forge filter surfaced **原初修真**, **雷鸣修仙录**, **凡人修仙人界篇**, and the **[Hd]混沌天道** expansion. [雷鸣修仙录](https://www.mcmod.cn/class/14649.html) describes traditional cultivation and lists body refinement/soul as unfinished. [混沌天道](https://www.mcmod.cn/class/26553.html) is a high-difficulty expansion with a new dimension, bosses, higher realms and three techniques. These are useful legacy sources; the pages expose external cloud/video distribution links but I did not establish a clean public direct-j ar route or source license for them. MCXZ is an older GitHub project about Chinese myths/cultivators, but its repository is marked early-development and [has no GitHub release assets](https://github.com/mcxz/mcxz/releases).
