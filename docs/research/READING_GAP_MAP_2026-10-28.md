Weibao: "Glean what gaps and stuff and more of our local game we can hope to learn from and address based on the readings." Research and proposals only. No runtime change, no spend, nothing here is accepted by Weibao. Every row is a palette entry (AGENTS.md: idea docs are palettes), written as default, dial and reason, and ordering is his call.

This is a crosswalk, not a competing register. Each row names the existing owner it extends (PRF5): the [book-world feature gaps](worlds/BOOK_WORLD_FEATURE_GAPS_2026-10-15.md) (BF71-BF84), the [master plan](MASTER_PLAYABILITY_PLAN_2026-10-25.md) round 6 (BC, SC, HR), the [world completion standard](WORLD_COMPLETION_STANDARD.md) (S01-S14) and the [world core kit cards](worlds/world-core-kit-2026-10-14/cards/). Evidence classes are the feature-gap doc's: N module lacks the binding, C content needed, H handler unestablished, S source qualification open, P proof missing. "Not re-checked" means the claim comes from the cited doc and I did not re-read the code. Sealed slots appear by ID only (none are needed here).

Reading the rows: a rules row carries `conditions`, `steps`, `inputs`, `products`, `costs`, `results`, `limits`, `consequences`, `who`, each with an S/T/I label and a locator (example: `mol.rite.angel-summoning`, locator `en b1 c20 p62`). A people row carries `routine` slots (`days`, `place`, `what`), `relations` (kind, attitude, basis), `knows` (fact, since). A texture row has four fields only: `what`, `about`, `label`, `locator`, with no kind, amount, unit or hours. Only LOTM volume 1 has been merged (`lord-of-mysteries/private/lead-run-2026-10-27/merged`); Mother of Learning, Harry Potter and Shadow Slave rows are unmerged, so step 0 for any of them is `node scripts/lead_run/merge_shards.mjs <privateDir> --out <dir>` (free).

Most of this is unspent. Shadow Slave has about 5,000 people rows against a 127-line life pack (`src/world_packs/book_shadow_slave_life.js`); Harry Potter has about 3,800 against roughly 340 lines across `book_hp_pack.js`, `book_hp_life_data.js` and `book_hp_school_extension.js`. Mother of Learning's pack is the exception (13,149 lines), so its rows serve depth, not breadth.

### How an implementer cites paragraphs

```
node scripts/lead_run/merge_shards.mjs docs/research/novels/<book>/private/<lead-run> --out <dir>   # once per book
node scripts/lead_run/cite_paragraphs.mjs docs/research/novels/<book>/private/<lead-run> --id <id> --context 2
node scripts/lead_run/cite_paragraphs.mjs <privateDir> --topic '<regex>' --merged <dir> --max 20
```

Output is source text: read locally, never commit or paste it (workflow round 8). Row labels S/T are reader claims; the implementer confirms each against the printed paragraph before building.
