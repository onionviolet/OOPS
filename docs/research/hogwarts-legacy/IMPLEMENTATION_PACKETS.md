# Bounded implementation proposals

2026-10-14. **PROPOSALS only.** No owner accepted these and no implementation is authorized by this report. Extend the earlier [P1–P5 packets](../hogwarts-games/IMPLEMENTATION_PACKETS.md), [HP brief](../../worlds/harry-potter/WORLD_BRIEF.md) and [source ledger](../../worlds/harry-potter/SOURCE_LEDGER.md), rather than creating new competing owners. Legacy is adaptation evidence, not the novel baseline.

Shared proposed UI target: 1440 × 900 desktop; later 1366 × 768 fit. Visible lesson, useful task and actual resources use distinct panels. Mobile optimization, full class-year simulation, copied action combat, full franchise reproduction and new worlds/prestige layers are deferred. Numbers and time policies must be authored per world; Legacy values are references, not engine defaults.
