# Blueprint evidence

2026-10-14, Steam build 20773316. SHOWN below means decoded code in the installed assets, not a played route. All paths in this table are relative to `extract/blueprints/Phoenix/Content/` under the private workspace. CUE4Parse parsed 20 packages into JSON with script reading enabled. kismet-analyzer produced readable text and DOT flow for the ten selected assets below, with zero command failures. The Lumos and talent-screen exports warn when a local function call does not use a single constant integer argument. The generator cannot add its special inter-function graph edge for those calls; the call text is still present. Selected call and branch claims were checked against the original CUE4Parse bytecode JSON. No browser or game was opened.

| ID | Asset path | Shown flow and limit |
|---|---|---|
| B1 | `Gameplay/Blueprints/Classroom/Blueprints/BP_Class_SpellMiniGame.uasset` | StartSpellMiniGame enters graph offset 175 and calls AsyncCreateSpellMiniGame with its Spell field. OnMiniGameLoaded binds SpellComplete. SpellComplete enters offset 67 and calls MissionBPLibrary.CompleteMissionTask with Mission ID and Step Name. This is the bridge from a lesson UI result to a mission task. It does not itself decide the task's spell reward. |

Simplified JSON in `notes/flows/` is only a reading aid; original parser output remains the authority.

Additional parsed assets include spell tools for Accio, Levioso and Incendio; the creature nurture actor; Lumos/brazier managers; talent button/tree and loom trait-cost UI. Their defaults and function inventory were checked. These are not full semantic audits of every method. The nurture actor itself has no script functions; that does not prove its native components have no behavior.

No mappings were supplied for this successful sample. CUE4Parse's Hogwarts-specific UE4.27 mode parsed named properties and Kismet. The dispatch's blanket description of the game as requiring unversioned mappings was too strong for these assets. This sample does not establish that every package can be parsed without mappings.
