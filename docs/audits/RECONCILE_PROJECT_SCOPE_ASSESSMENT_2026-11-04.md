## Proposed way to cover the whole collection

1. **Inventory:** compare candidate documents against the existing writeup register and idea/domain indexes. Include untracked documents and appended sections. Record the searched roots, exclusions and an inventory identity; list unclassified residue. File discovery is not substantive review.
2. **Route:** assign each item to an existing owner, supersession group and topic. Distinguish proposals, accepted direction, source evidence, dependency maps, execution plans and historical receipts. Preserve useful alternatives and unresolved values.
3. **Reconcile:** work through bounded topic groups with the current skill. Retain original IDs; trace selected claims to authority and, for implementation claims, the producer, state owner and consumer. Record missing suppliers and checks without inventing a universal gate.
4. **Close coverage:** record which inventory items and section ranges were reviewed, where their dispositions live, and what remains unmapped. Refresh changed blocks and affected dependencies. Keep later additions visible as later intake.

The completion criterion is accounted-for material with honest dispositions, not all ideas implemented or all documents merged. The practical skill addition would be a short project-wide intake/coverage branch; its existing bounded reconciliation method can remain intact.
