Start from **Progress > Vision coverage** or select **Vision themes** in Find. The page draws its theme labels from the standing sections of [USER_VISION](../USER_VISION.md). The dated request log is the history behind those sections. The new [mapping](../../prototypes/world-atlas/vision-coverage.mjs) names an example and a remaining gap for each theme.

## Status used in the view

**Playable** links an exercised native example, such as Fang's first night or Alden's bedside choice. **Partial** records an implementation or verification gap alongside available evidence. **Reading-only** marks archive or development records. The label describes the example, and the text below it names what remains open for that theme.

First playable gaps to track on the existing routes are local and inherited starts, cross-life continuity, longer idle returns and the consequences of returning to repeat work. Prepared text and a readable Atlas record can inform those slices. Their gameplay receipts must name the actual life, action and build.

The normal Atlas server loaded the adopted archive. At 1366×768 and 1920×1080, Progress showed all six sections and 13 themes. Find returned **Time and progression** for `idle play`. Its direct address opened the theme and its link reached Fang's native evidence record. The replay had zero page errors and zero horizontal overflow.
