# world-legibility: Implementing entire worlds end to end (everything between a source book and a playable, finished world) / what the player can see, inspect, trust or be confused by on screen

1. Visual consistency of UI elements
The player may see mismatched button styles or font sizes that break immersion. A builder should test the interface on multiple screen resolutions to ensure uniformity. Effort M

2. Loading screen clarity
Users might not know if the game is stuck or actively generating world data. A builder can add a progress bar with estimated time remaining to reduce anxiety. Effort S

3. Text readability in low light
Small or light text on dark backgrounds can cause eye strain during long sessions. A builder should verify contrast ratios meet accessibility standards across all menus. Effort S

4. Inventory icon legibility
Items may look similar at small sizes, leading to accidental selection. A builder can zoom in on icons to check for distinct shapes and colors. Effort M

5. Dialogue pacing control
Rapid text appearance can overwhelm players who prefer slower reading speeds. A builder should test the skip function and speed adjustment sliders. Effort S

6. Map label overlap
Too many labels in dense areas can create visual clutter and confusion. A builder can toggle labels to see if they obscure important landmarks. Effort M

7. Character portrait coherence
Portraits might not match the described traits or mood of the scene. A builder should compare portraits against the source material descriptions for accuracy. Effort L

8. Tooltip information density
Overloading tooltips with too much lore can confuse the player. A builder can limit tooltip length and use expandable sections for details. Effort M

9. Feedback for invalid actions
Clicking on uninteractable objects may give no response, causing frustration. A builder should add subtle visual cues or sound effects for invalid inputs. Effort S

10. World transition smoothness
Abrupt cuts between areas can disorient the player regarding location and time. A builder can review transition animations to ensure they convey movement logically. Effort M

11. Language localization gaps
Untranslated text snippets can appear as raw codes or missing strings. A builder should scan all user-facing text for placeholder values. Effort M

12. Accessibility color coding
Important status effects might rely solely on color, which is unclear for colorblind users. A builder should add icons or patterns to distinguish status types. Effort M
