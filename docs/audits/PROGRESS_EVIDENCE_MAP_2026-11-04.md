### P1. Three layers, extended through existing owners

The foundation is a set of reusable mechanisms whose outcomes change play. A book-world implementation provides local laws and content; the UI explains the player's actual situation. The programme advances through connected slices that exercise all three.

| Layer | Responsibility | Boundary |
|---|---|---|
| Shared mechanisms | Identity, custody, commands, costs, jobs, clocks, knowledge, effects, persistence; additional mechanisms where worlds reasonably share semantics | Existing owners remain authoritative. New generalization earns its place through a real need and a different consumer (AR11/AD51). |
