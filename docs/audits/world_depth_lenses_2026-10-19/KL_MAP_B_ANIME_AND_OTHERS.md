- **Institution-vs-strength split** appears in four of six worlds (JJK, Bleach, Naruto, FMA) with the same wording in their ledgers. One "institutional rank" law family, with a dial for how far it lags reality, would serve all four. Default: rank is an access and duty label; dial: lag; reason: each ledger says rank is not a combat tier.
- **Staged process** (Naruto, FMA, Bleach, JJK) maps to the IX-A strata approach: one fraction axis per stage, ordinary reaction rows, no engine edit (IX-A verdict). This fits only worlds whose ledgers state ordered stages, so it excludes Fate and HxH.
