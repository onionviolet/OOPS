## Case template (proposal)

An interaction record should name the actual participants, source body, access, costs, time, witness, accepted/refused terms, result, discoverability, and save boundary. Failed eligibility is a no-op unless the source specifies a cost. Random truth is sealed by opaque ID and route. No secret truth belongs in this tracked file.
