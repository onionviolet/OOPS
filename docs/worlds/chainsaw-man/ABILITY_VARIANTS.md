## Authoring fields (proposal)

For each ability record: actor, source identity, form, acquisition cause, trigger, eligible target, reach, cost/fuel, duration, cooldown, counter, persistence, knowledge route, and source revision. Unknown fields remain unknown. Contradictory conditions get an explicit conflict ID, never a silently averaged value.
