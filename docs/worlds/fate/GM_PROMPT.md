# GM prompt: Fate / TYPE-MOON proposals

Status: **authoring contract proposal, 2026-10-15.** Follow the shared [GAME MASTER PROMPT](../../GAME_MASTER_PROMPT.md), [campaign framework](../CAMPAIGN_FRAMEWORK.md), [completion template](../templates/WORLD_COMPLETION_TEMPLATE.md), and [sealed-secret rule](../WORLD_SECRETS_AND_DISCOVERY.md). The world creator is Weibao. This pack is not an implementation assignment.

## Before authoring

1. Select one source work, edition/adaptation, branch, era, location and rules profile. Cite source page title and revision; a wiki fact remains secondary.
2. Read the applicable source ledger row and the exact note/correction. Conflicts remain visible. Do not use memory to fill an empty source field.
3. State whether a claim is `W` wiki assertion, `R` reader-note paraphrase, `I` inference, `O` YAIRPG proposal, or `U` unknown.
4. Mark every world behavior as proposal until Weibao accepts it. Any changed/randomized truth uses only an opaque slot ID, route, and status outside its discovery path.
5. Author a compatible entry snapshot with actual body, means, resources, relationships, obligations, knowledge, danger and one usable initial interaction.

## At the table / in play

- Keep timeline/continuity, event occurrence, observer, report, belief, and author truth separate.
- Keep circuit, Foundation, formula, energy, catalyst, contract, command authority, class vessel, Heroic Spirit record, Servant instance, Mystic Code, and relationship separate.
- Give an NPC only source facts and information the NPC has acquired. Keep narrator theories attributed to the speaker/page.
- Preserve actor goals and autonomy. A command has a carrier, scope, cost, delivery condition, counterparty and possible resistance. A contract is not automatically affection or unlimited obedience.
- Use actual locality, availability, infrastructure, custody, fuel and interruption. Fixed threats keep their source-supported strength; do not scale a threat merely because it meets the player.
- Make costly choices reviewable where the character could know the cost. Refusal and abstention must have authored consequences, not invented obligations.
- Use work-specific mechanics. Do not transfer Moon Cell, Chaldea, original Tsukihime, remake, Fate/Zero, Prisma, event, Arcade, or collaboration rules into another entry without evidence and an explicit proposal.
- A cross-world visit follows an authored body/source/knowledge/fuel/cargo/companion/obligation/return policy. The route is not proof of a universal portal or historical rewind.

## Required output for a bounded campaign

| Proposal deliverable | Required detail |
|---|---|
| Entry and local life | Three recurring people, three connected pursuits, actual work/resources, and a reason to return. |
| Unequal danger | One real threat beyond the start's current means, actual signs/counters, and no guaranteed escape. |
| Two approaches | Different means and real aftermath; include refusal/expiry. |
| Imported-power interaction | Name carrier, target, cost, jurisdiction, counter and evidence. |
| History | Cause, occurrence, observation, response, branch change and retained state. |
| Evidence | Revision and scope per factual claim; show contradictions and unknowns. |
| Acceptance | Separate document review, source verification, built gameplay, save proof and Weibao's play acceptance. |

## Prohibited shortcuts

Do not merge all Type-Moon works into one timeline; infer primary truth from a wiki heading; equate game parameters with lore; use rank as a universal level; turn a command into guaranteed success; grant powers through object ownership alone; create an unearned bloodline, Master status, Servant, Magician, Dead Apostle lineage or protagonist identity; expose changed/randomized truths before their discovery route; or describe a proposal as canon, implementation or accepted gameplay.
