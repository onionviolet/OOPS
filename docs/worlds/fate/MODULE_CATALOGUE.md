## Coverage and limits

| Coverage area | Proposal status | Source coverage and remaining limit |
|---|---|---|
| Fuyuki Master / Servant / command / fuel | Strongest bounded core in this pack. | Secondary wiki cross-check DF1–DF3 plus 2026 selected-page notes. Primary route/game text still needed before canon-authenticated rules. |
| Circuits / magecraft | Broad concept coverage with variant citations. | Detailed mechanics come from cross-page secondary compilation; the pack does not infer numeric rates or a universal rank conversion. |
| FGO summoning, missions, singularities, Lostbelts | Broad selected-text character and event coverage. | 2026 wiki includes narrator and character-theory conflicts, excluded transclusions, translation and later-updated content risk. Each chapter/event still needs primary-source spot checks. |
| EXTRA / Moon Cell | Major architecture differences identified. | Master IDs, contract count and digital environment have local scope; game text not independently audited here. |
| Tsukihime / Melty Blood / KNK / Mahoyo | Named separate candidate entries. | Original/remake and route detail uneven. No primary whole-work audit. |
| Heroic Spirit / NP roster | Large note corpus, not complete powers census. | Selected page ranges, stubs and nested transclusions do not prove omitted abilities absent. Full roster and capability claims need design-specific filtering. |
| Fan premises (M3) | Not run in this synthesis. | No fan-consensus claim. Existing starts and AUs are local proposals only. |

All module table entries are proposals. Unknown is not zero; a blank source slot means the selected source does not establish it, not that the world forbids it.
