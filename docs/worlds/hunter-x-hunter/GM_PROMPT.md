# Hunter × Hunter world GM prompt

Status: proposed authoring contract r1, 2026-10-14. Inherit repository `AGENTS.md`, [campaign framework](../CAMPAIGN_FRAMEWORK.md), [ability authoring](../ABILITY_AUTHORING.md), [world completion standard](../../WORLD_COMPLETION_STANDARD.md) and [secrets rule](../WORLD_SECRETS_AND_DISCOVERY.md). This file proposes how a future GM should extend this pack; it is not user-approved runtime authority.

## P1. Role

Author a playable, causally coherent Hunter × Hunter fan-world proposal within the user's canon-first priority. The manga is the authority for manga continuity. Research sources currently available are dated secondary wiki notes. Say `WIKI`, `INFERRED`, `P`, or `OPEN` at the point of use. Never turn a wiki summary into a primary-source claim.

## P2. Required working rules

1. Read the current live owners and confirm the requested file reservation before editing. Preserve dirty state; do not edit other worlds, runtime files or global priority owners without explicit scope.
2. Every new ability, institution rule, story detail, NPC, price and outcome is `P` until sourced or accepted. Source facts cite exact page title and revision id.
3. Preserve source disagreements. If a page conflicts with its own categories, another page, manga/anime continuity or a supplied note, record both claims and keep the mechanic open.
4. Define capability by actual method, source, target, trigger, cost, duration, range, counter, knowledge and ownership. Do not use one universal combat level or force every clever combination to fail.
5. Separate public exam, license, Hunter standing, Nen instruction, ability creation and personal combat strength. None implies all the others.
6. Keep all character knowledge local to actual witnesses and communication. The player knows what their selected actor learned, not every wiki fact.
7. Public franchise twists may be discussed. Changed/randomized franchise truths are sealed and must be referred to only by opaque ID, route and status in public outputs.
8. Use one world/continuity owner and one writer per file area. Add content only within the assigned revision; do not expand to a second playable slice before the first has a real checkpoint.
9. Label unknowns. Do not invent manga chapter locators, source quotes, exact cost formulas or gameplay evidence.
10. A design pack is not implementation. A future gameplay completion claim requires the project rebuild and fresh-origin browser exercise. Persistence changes also require save, reload and import evidence. Leave unsupported native gates open.

## P3. Output contract for new details

For each detail include stable ID, source/user provenance, owner, actual means and cost, trigger and expiry, positive case, alternative, failure/counter, lasting aftermath, observer knowledge, persistence decision, and named remaining gate. Cross-world imports need actual interface and compatible source, not label matching.

## P4. Current handoff state

This r1 pack is a proposal authored in a new folder. No runtime or global owner was changed. Source completeness, manga verification, detailed AU selection, secrecy payload, exact ability catalog and all implementation gates remain open. Future authors should reconcile current state before resuming.
