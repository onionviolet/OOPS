## P1. A generation boundary per selected continuity

Keep this boundary in the world's existing source/detail owner, not another competing canon encyclopedia. Bind exact source family, edition/version, inspected range and selected adaptation mode. The modes below describe proposals for authoring behavior; they are not a mandatory five-option player menu.

| Mode | Generator may do | Generator may not silently do |
|---|---|---|
| Canon-grounded | Fill represented peripheral situations with facts compatible with inspected laws; vary original people/material placements where permissible | Replace a named unique object, change a demonstrated law, or fill an unknown source answer as canonical |
| Original character within canon | Supply an original start, contacts and opportunities under the selected rules | Grant a protagonist-only device to every entrant solely because it appears in that source |
| Declared AU | Apply named departures and initialize their dependent facts | Pretend the changed rule was established by the original work |
| Named fanwork adaptation | Use the inspected version's actual premises, laws and exceptions | Mix another fanwork's rules because both use the same franchise |
| Crossover/remix | Resolve selected source interactions and deliberate additions | Assume a shared word such as soul, mana, destiny or system proves shared semantics |

Suggested record for a relevant generated family:

```text
source binding + current rule owner
fixed selected facts
free original variables
unknown/source-gap facts
declared departures and affected dependents
allowed outliers and their exact scope
executable support and useful consumer
```

Unknown is not forbidden. It can remain unresolved, become an explicitly original premise, or prompt later bounded research. A generator should not silently choose among those authority states. An outlier does not imply that every NPC, ingredient or cheat follows its exceptional law.

For a Harry Potter fanwork profile, bind title, author, inspected revision/range, relevant rule claim, locator and interpretation. A later chapter correction updates evidence; it does not automatically rewrite an existing run. Two mutually inconsistent fanworks can coexist as separate universes. A declared remix can select from both, with the conflicting interaction authored explicitly. This audit names no uninspected fanwork as a verified rule source.

## P2. Require an observable semantic difference

Use the same question against two profiles and inspect the resulting state, rather than compare labels. Example: “Can this holder make another person perform this recorded procedure?”

| Rule family | Genuine difference to represent |
|---|---|
| Knowledge | A record explains steps; an imprint conveys procedural memory; a faculty grants execution; none implies all three |
| Identity | Recognition follows body, soul, chosen relationship, bearer custody or a named identifier; correspondences do not automatically alias actors |
| Time | Work settles once; a rehearsal is discarded; a rewind restores selected state; an independent world keeps its own chosen clock |
| Production | A design enables fabrication; a creation faculty materializes output; a transformation changes an existing object; a unique anomaly is not necessarily reproducible |
| Authority | A local permission opens an institution; a physical effect changes a target; a law editor changes a declared causal domain |
| Observation | Reading exposes a selected property, predicts under assumptions, or directly reveals truth; wording alone cannot choose the semantics |

For a selected pair, record `same input → different supported operation → different useful outcome`. Shared UI and scheduler code are desirable; identical magical behavior is not required. Some AUs deliberately differ only socially and can share magical laws completely. Do not require every branch to acquire a new metaphysics merely to justify its existence.

## P3. Apply AU changes at the correct time

An overlay needs an application kind:

| Kind | State treatment |
|---|---|
| Alternative initial history | Construct the chosen start with appropriate people, institutions, claims and knowledge; do not edit an existing canon instance |
| Branch from a played state | Copy/reference/remap declared state under the timeline owner's plan; preserve the source branch |
| Present-time intervention | Preserve actual past events and change selected current laws or actors; evaluate affected pending actions |
| Explicit retroactive rewrite | Use a supported rewriting operator that declares changed history, retained observers/objects and contradiction handling |

If a workshop is queued under the old rule when that rule changes, decide whether its committed plan stays valid, re-evaluates current conditions, pauses, converts, or settles under a specifically authored exception. This is not a forced failure tax. An absolute author cheat can guarantee the desired rewrite if that is its supported power. The engine must still know which state changed.

Dependency review should find touched suppliers, learners, custody, institutions and event causes. Review represented dependencies; do not claim to simulate every society automatically. A historical AU snapshot can be authored directly without replaying centuries. An institution can keep an obsolete belief after the underlying rule changes, since physical truth and public knowledge are different state.

## S1. Original AU: a procedure that follows its creator's body

**Premise.** An original magical-school AU, potentially placed in a declared HP remix after source reconciliation, introduces one explicit law: a trained movement pattern can be stored, but its execution remains calibrated to the body that learned it. This is an invented rule, not a franchise claim. The chosen cheat perfectly preserves that pattern without cost or uncertainty.

**First useful play.** Record a learned fine-control procedure and use the record to restore one's execution after an interruption. The same record lets a collaborator inspect every step without granting a compatible motor pattern. A player can teach conventionally, build a body-specific adapter, or obtain a different cheat that grants cross-body execution.

**Future-life project.** Before rebirth, store the pattern and a calibration protocol. Delivery succeeds by the declared carrier. The new body's retained memory is exact, but usable execution follows this AU's body calibration law. A prepared adapter can make the first application immediate. An explicitly absolute version can bypass calibration entirely; it is a different power, not a random exception added to punish success.

**Generation.** Generate supported procedure/body pairings and compatible adapter projects. Never invent an unsupported anatomy. RNG can select the future body at the committed life transition; it does not reroll the stored pattern. Deterministic rebirth targeting is also valid if the selected source supports it.

**Distinctive engine need.** Separate exact record, trained method and current body-specific executable mapping. Test one successful home action, one informed collaborator action, and one adapted future-body action. Save preserves the same record and the two calibration results.

**Why different.** This is identity-sensitive execution, not a recorder with a smaller capacity. In another AU, direct memory transfer can grant complete execution immediately; the shared recording operation remains reusable while the grant consumer changes.

## S2. Original universe: a rehearsal does not write the world

**Premise.** A local simulator can make an exact fork of the represented workshop state. The holder explores it and brings back observations only. The real workshop does not advance inside that rehearsal. There is no obligatory price, inaccurate prediction or balancing enemy.

**First useful play.** Test three repair sequences in rehearsals, retain their observations, then choose a real sequence. Real fabrication consumes or transforms actual stock only through the real operation. A collaborator can repeat the evidence if shown a supported recording; they do not remember the holder's rehearsal by default.

**Alternative AU.** In a different original universe, the device performs actual rewind instead. Repair, damage and participant memories are restored or retained by a named rewind rule. The same visual “try again” button now has different causal semantics. A crossover can carry both devices without pretending they are one operation.

**Future-life project.** Build a rehearsal corpus or a tested plan to deliver later. A new life benefits from it only when its relevant starting conditions match or it can adapt the plan. An exact simulator remains exact for its represented inputs; changed external circumstances are different inputs, not an arbitrary nerf.

**Generation.** Generate supported initial workshop problems and candidate sequences; pin each rehearsal's snapshot and rules revision. RNG only applies where the simulated mechanism uses it. Any equivalence between simulated and later real draws must be declared, since pinning outcomes and drawing new outcomes produce different powers.

**Distinctive engine need.** Fork isolation, explicitly retained outputs, real-world settlement and retained observer scope. A test compares real stock before/after rehearsal, then after committed real execution. This is a proposal requiring dedicated engine support, not something a scalar success flag can implement.

## S3. Original multiverse: recognition follows designation, not resemblance

**Premise.** A creator builds a costless archive that delivers to one designated recipient. This selected version uses an authenticated identity token deliberately transferred by the creator. It does not use a soul signature, family name or resemblance. A separate version can follow a soul or bloodline under its own actual rule.

**First useful play.** Designate an apprentice, hand over the token, and have the apprentice retrieve a real recorded method. Ownership of the archive and authorization to read a record can be separate. The creator can deliberately authorize everyone without an imposed restriction if that is the chosen version.

**Crossing and counterparts.** The apprentice travels to another independent world. A local counterpart has the same familiar appearance but no token, history or authorization. Correspondence identifies the counterpart relationship; it does not share inventory, trust or access. If the selected cheat grants deliberate identity merging, implement that operation and its declared state scope instead of treating name matching as merging.

**Next-life use.** The creator can prepare a token-delivery arrangement to a successor or compatible rebirth. If delivery merely places the token in a cache, acquiring it is still a real route. A guaranteed cross-life courier can deliver immediately and certainly. Reliability comes from the selected mechanism, not a universal post-death roll.

**Generation.** Generate a compatible recipient and delivery opportunity from actual actors/places. Sample a recipient only where requested. Never select a same-named counterpart as a substitute without that version's declared criterion. Record whether the recipient accepted, transferred, destroyed or retained the token.

**Distinctive engine need.** Independent actor identities, designation, physical token custody and read authorization. The useful trace demonstrates authorized use, counterpart non-aliasing, and deliberate transfer to a new recipient. No antagonist, curse or mandatory betrayal is necessary.

## S4. Original universe: a public invention becomes ordinary infrastructure

**Premise.** This world's selected creation faculty can produce a fully working irrigation fixture instantly and freely. Its output is reproducible physical equipment, not a leased spell or remote patron service. Nothing requires its creator to die or grind to use it.

**First useful play.** Place a fixture on an actual plot and irrigate it. Share the design, provide fixtures to another household, or keep them private. The generated local situation supplies actual plots and willing users; willingness and physical function are separate questions.

**Next-life preparation.** Establish a maintained network and recorded procedure. After the creator's death, physical fixtures continue under their own laws. A successor inherits only property that is transferred, but can use public infrastructure without inheriting the cheat. This delivers a changed world rather than a new personal power.

**Alternative AU.** In a different declared world, an identically named faculty creates active projections sustained by its holder. Outputs disappear at the selected sustaining boundary unless preserved through a separate real operation. These are distinct output semantics, not a universal decay imposed on all creators. A multiversal adapter can make permanent equipment if it actually supports that transformation.

**Generation.** Generate represented adoption, maintenance or expansion opportunities around existing fixtures, rather than repeatedly roll new treasures. If social uptake is modeled, use the actors' actual information and choices. Do not require hostility to powerful free production.

**Distinctive engine need.** Physical versus sustained output lifetime, public use, custody and persistent world changes. Check the real consumer while the creator is present and after the declared departure/death boundary. This separates immortality of an institution from survival of a character's faculty.

## P4. Minimal semantic trace for a selected crossover

Before building a whole translation framework, give one chosen function a concrete trace:

```text
input and its real identity
source-world operation and effect
carrier and crossing event
destination rule binding
direct use / selected adapter / deliberate blocked result
actual useful consumer
observer evidence
return state and persistence commitment
```

For S4, a carried permanent fixture can continue physically operating if destination physics permits it. A projected fixture requires its declared sustaining mechanism. A universal equalizer can make both work unchanged when explicitly selected; that does not automatically confer equalization on ordinary travel. The trace should include a direct-success example as well as an adaptation example, so travel is not synonymous with losing powers.
