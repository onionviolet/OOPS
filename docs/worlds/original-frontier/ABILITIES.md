## Preserve working distinctions

General competence uses native skills/XP. Rat-step retains its dedicated observed/understood/owned/proficiency record. Load-bearing Step retains the existing simulation practice power; focus/drive retain actual reserve/output/control/strain. Conditioned grip is trained body development, Natural balance an inherited aptitude, and a learned procedure is knowledge. A career/feat/title is recognition or a supported unlock, not a replacement XP owner. Existing local source acquisition and copying rules keep provenance and do not remove the instructor's method.

## Existing functional chains to reuse

Rat-step already has slow and active learning routes, internalization at 2, execution at 6 plus Agility 8 and a route-specific guaranteed outcome at 12 ([source](../../../src/technique_content.js)). Its mastery case demonstrates that simple movement becomes useful and reliable without gaining a rare source. No new native combat feint/evade effect is claimed.

Load-bearing Step already distinguishes ordinary teaching from an earned imprint, mastery from ownership and measured focus from breath drive. Mastery 2 opens its declared forceful application; the Shack workshop uses actual logs, coins and energy ([source](../../../src/field_workshop.js)). A new route/control case can reuse the existing declared output/control limits; it cannot call mastery a license to hold arbitrary cargo or copy unknown methods.

Conditioned grip already requires two completed drills and recovered hands, gives actual carry/hand-control capability and changes existing packing/timber durations ([source](../../../src/body_progression.js), [town consumer](../../../src/town_content.js)). Soreness/recovery and permanent trained change remain separate. The quiet ordinary route is a valid alternative to exceptional focus/drive where the new case declares it.

Native stances, weapons, Shield blocking/Evasion and higher-level training continue to affect their existing native actions. The inherited grain-cart choices already demonstrate strength/handling alternatives. Use them as existing useful breadth, not a new completion reward, shortcut or a second copy of that quest. Strong actual output is preserved; author a specific target/contact/fuel/counter rather than universally suppressing it.

## Acquisition-to-use and discovery fields

For each selected returned function, Engine and the local author bind: runtime ID/revision, actual learning source, discovery basis/actor/time, teaching/tool/body/source/target requirements, native XP or existing method owner, legal practice, milestone receipt, paid execution, effect/output/duration, counter/interruption, local compatibility, known block reasons, action destination and aftermath. These are required authoring fields, not a request for another generic ability interpreter.

Player UI stages: undiscovered hides names/panels/counts/search/tooltips; source-grounded hint reveals only that hint; discovered unavailable exposes known terms/reasons; learned exposes legal controls; temporary tool/fuel/contact loss retains the known method and recovery route. Do not use low native XP visibility as proof that a learned method is unknown. Rendering cannot teach, activate, roll or reward. Current work/recovery/cancel navigation remains reachable.

Actions go to native location menus or Notebook Here; practice to Practice; discovered people/reports to People; accepted agreements to native Quests; actually known developments to Events. One binding routes button, event link, active-work attention and return recap. No duplicated UI button can settle the same claim again. Shared discovery APIs and final native callers remain Engine-owned and are not assumed from this proposal.
