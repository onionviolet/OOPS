## What needs deciding in the reviewed local implementation plan

Freeze the new post-acceptance native encounter receipt, exact stock/lot-result policy, actual four-order demand funding, narrow ordinary successor teaching and truthful current-work/ending UI bindings. These E02–E08 outputs are prerequisites to a full local campaign. Freeze each new lesson/application/feat against the actual Ability S2 roster rather than old suggested skill labels. A required stronger function must change an actual compatible result; a missing adapter is not lore uncertainty.

The next broader expansion can add a full mill/farm/mountain/river arc, an original research/invention lineage or a more advanced craft assembly with its own required outcomes. Those remain visible desires, but none is selected by quietly opening every region or importing every book system into Frontier. The current finite campaign should be complete within its chosen footprint before adding another required roster. That sequencing does not impose a permanent one-event or low-skill ceiling.
