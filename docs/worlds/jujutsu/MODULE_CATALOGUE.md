# Jujutsu Kaisen module catalogue: source, procedure and consequence

**Status: all module behaviors below are `P` proposals.** `W` marks secondary wiki claims; source title and revision are linked in [SOURCE_LEDGER.md](SOURCE_LEDGER.md). This catalogue is not a runtime registry. It follows the composition and actor-specific knowledge boundaries in [CAMPAIGN_FRAMEWORK.md](../CAMPAIGN_FRAMEWORK.md).

## Independent dimensions and compatibility

`P` Resolve each capability through a tuple: bearer/body; source; learned method; target; trigger; required fuel/material; scope; output/control; known counter; cost; interruption; provenance; knowledge. A grade, title, item or technique name is not an executable method by itself. Unknown values remain unknown until the selected source and continuity supply them.

## Central operating records

`P` Actor/body record tracks body-bound method, imposed restrictions, condition and injury. Soul/memory record tracks what the selected continuity actually says persists. Knowledge record stores observer, source, confidence, timestamp and whether it is inference or testimony. Capability record owns trigger, range, target, setup, resource and failure. A barrier/domain record owns geometry, admitted subjects, effects and aftermath. An obligation record owns signatories, consent, action window, evidence and adjudication state. An item record owns specimen, custody, owner, compatibility and condition.

## Failure, counters and salvage

`P` Validate preconditions before spending; once a genuine action begins, consume only declared resources. Unsupported target, incompatible body, absent tool, interrupted setup and expired window have distinct results. Counterplay must attack the real mechanism: disrupt source, leave scope, use an eligible counter, provide conflicting domain pressure, break boundary from a supported side, or exploit stated information. Never invent immunity to preserve a planned encounter.

`P` Salvage preserves genuine materials, evidence, training and local trust. It does not manufacture an innate source, undo a mutual bargain, resurrect a person, recreate a destroyed summon or promote an heir. Exceptional source-qualified restoration remains possible if the selected case states its conditions.

## Assemblies and worked loadouts

`P` **Evidence-and-curtain team:** window report + witness statement + barrier specialist + one student capability + actual exit route. The team can verify a curse report without guaranteeing combat success.

`P` **Tool-recovery bench:** custodian + inspection record + compatible repair material + qualified worker + durable custody receipt. The bench restores the same specimen only.

`P` **Rule-domain hearing:** caster procedure + named participants + evidence set + judge knowledge boundary + sanction route + post-domain aftermath. This cannot be replaced with a generic courtroom UI or free omniscient verdict.

## Exact runtime gaps

The catalogue establishes no current engine API. Before implementation inspect authoritative owners for condition/reward commits, skills/jobs, effect ordering, body/source compatibility, knowledge, world identity, save migration, item custody and imports. Domain, vow, curse ecology, AU binding and source selection need precise ownership contracts. This is a research proposal only.
