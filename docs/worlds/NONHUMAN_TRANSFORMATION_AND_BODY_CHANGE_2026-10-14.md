## 3. Control and consent

Default: a transformation preview names known body effects, carry terms,
duration/trigger, current control, return route and loss terms. The player selects
the premise that permits involuntary change or forced action. A warning can state
known risk while leaving sealed cause/truth hidden. Dial: voluntary shifting,
involuntary anatomy with retained choice, negotiated shared control, triggered
takeover or full compulsion. Reasonably: safe preparation, mitigation, resistance,
help, refusal and alternate bodies are available where the world supplies means;
no universal guarantee that every source crisis is curable.

| Control case | Proposed contract |
| --- | --- |
| Voluntary | Preview then commit at validated boundary; a trusted routine may repeat only the selected known change within its budget |
| Involuntary | Premise records whether only anatomy changes or executive control also changes. Do not secretly convert wolf instincts into attacks |
| Timed | Known expiry and return/stabilization rule. Renew only from real doses/fuel; never silently spend a new dose or extend control permission |
| Triggered | Pin trigger, calendar/location/support and allowed result when enrolled. Unknown triggers can remain hidden but their risk mode is selected |
| Instinct pull | Default suggestions/bonuses for hunt, hoard, migrate or dormancy; player can decline. Compulsory action is a separate premise policy, not a high instinct value's surprise reward |
| Another person's body | Consent specifies channels, duration, permitted jobs, reserve use, revocation and exit. Expired consent blocks new work; a selected hostile mode records contest rather than pretending agreement |
| Body swap | Two occupants and both destinations, including each displaced body's control and goods. Consent for one transfer is not consent for every later return/swap |
| Familiar/golem link | Advice, sensation, commands and direct control are separate grants. An independent familiar can disagree; title over an object does not prove control over its mind |

Control of one body does not imply another body's knowledge. A clone can be a new
person; a puppet can be one controller's remote executor; a golem can have either
agency model. Record it before granting output/XP. Consent revocation or connection
loss uses an authored safe handback/hold policy. It need not teleport the guest,
refund work already done or erase damage.

Default transaction: pure preview, revalidate sequence/body/control/source/stock,
stage costs and carriers, validate combined native/simulation envelope, durably
save, then publish. This is proposed safety, not proof of the current transition
service's storage atomicity. A failed publication/save leaves the last committed
state authoritative and grants no partial item, source or control transfer.
Before commit, abort discards the staged change. After commit, rollback means a
new supported restoration/compensation transition; it does not erase witnesses,
rewards, consumed goods or intervening injuries. Paid preparation remains paid
unless its refund rule permits otherwise.

Default migration retains old human, reedling, Tern offered/active/returned and
partially trained records without granting bodies or enrolling new services.
Unknown template/revision/dangling return target preserves the original save and
blocks unsafe play; it does not fabricate a human body. Dial: an explicit content
conversion can repair compatibility with a receipt. Reasonably: export and a

validator changes; existing scalar body effects are not a shortcut.

export and literal-file import at pending/active/returned states. Later selected
UI proof target:1366×768 desktop/laptop, visible current form, return terms,
changed action eligibility and gear disposition. Mobile optimization deferred.

## 5. Idle-game fit

Default: idle means funded queued work or a sustained supported condition on the
existing clock. [Origins](ORIGINS_AND_WORLD_TIMELINES.md#infant-and-child-play-without-long-forced-waits)
retains no browser-closed advancement by default. Dial: separately selected capped
offline settlement of already authorized routines. Reasonably: transformation
preparation and recovery offer useful work without compulsory babysitting.

| Loop | Useful idle work and intervention boundary |
| --- | --- |
| Timed forms | Queue a known short routine with its required form and expiry. At expiry stop/replan incompatible work before spending another input. A permitted safe return occurs under agreed terms, rather than waiting forever for a manual click |
| Molting | Reserve shelter/materials, grow the selected structure, keep a supported signal/analysis routine while immobile, then settle shed-part custody. No automatic world-long helplessness or overnight lethal exposure |
| Evolution milestones | Preparation/practice can accrue; preview known branch gains, costs and carrier terms before commitment. Trusted selected evolution may auto-complete, while unselected species branches pause for choice |
| Partial/full-form practice | Rehearse a known limb or form's coordination with real means. Retained theory can speed work if the rule supports it; a form label itself grants no practiced mastery |
| Possession and second bodies | Run only leased jobs within actual channel reach, time and reserves. Partner autonomy can continue an agreed job after disconnection if competent; no extra full-rate XP for every avatar's identical copied knowledge |
| Repair and part fabrication | Craft one replacement, fit it, rehabilitate its control and restore a useful function. Detached parts remain real stock; old part plus installed new part cannot become two copies of the same object |
| Ghost and return preparation | Practice a known signal, maintain an anchor or coordinate a helper's repair job. Return waits for real access/body availability; a ghost is not reduced to an idle resurrection countdown |

A form's timer should create planning, not dominate every minute. Default known
cycle UI shows a due boundary and viable tasks. Dial: seasons, long incubation,
instant changes, no duration or a source-specific crisis. Causal stopping rules
matter more than an arbitrary universal timer. Hunger-free ordinary play applies
to every form even where the source examples have harsher feeding pressure.

1. **S1:** After the engine foundation, prove one reversible two-form change with one useful action in each form, one incompatible gear item and a witnessed return. This is a candidate, not a replacement for the owner's first-start recommendation.

4. **S4:** Add second bodies only after focus switching cannot duplicate stock, fuel, XP or knowledge. Prove one puppet or one independent familiar before broad multi-body scheduling.
5. **S5:** Resolve direct-adaptation questions when their route is selected: hollowfication control/return, JJK entity/brain/body carriers, fiend brain-memory wording, and chimera identity/reversal.
