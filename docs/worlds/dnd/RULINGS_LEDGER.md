# D&D first rulings ledger

2026-10-14. `dnd.first-slice.rulings@1`. All 28 records below are **proposed**, revision **1**. This is a frozen proposal set for [ST2](SRD521_START.md) and PS01–PS06 in [FIRST_SLICE](FIRST_SLICE.md), not a global D&D house-rule book. Root trace: RB12, L1, A3-acc, GM1–GM7.

## Record contract

`id`, `question`, `proposedRuling`, `sourceLocator`, `revision`, `status` are mandatory. Each row is one record. `D` marks an explicit SRD delegation to the GM; `A` an application of a rule to this authored situation; `Y` a YAIR/authored policy beyond the SRD. A source locator identifies the underlying rule, not a claim that the book supplies the authored wage, delay or consequence. Application and policy records prevent the same silent drift as explicit DM calls.

Source key `Lxx` resolves to the hash-pinned [private registry](../../gm/dispatch/rulebook-engine-2026-10-14/r5/private/LOCATORS.json) and [exact selected-page text](../../gm/dispatch/rulebook-engine-2026-10-14/r5/private/SOURCE_EXCERPTS.md); both use SRD 5.2.1 only. All times and numbers not in the cited rule are proposals. No sealed files were opened or secret truth defined.

At instantiation, pin each effective `id@revision`, the ruling-set revision and source hash. Store its question and answer with the action/check/job receipt. A change appends a revision and a reason; never edit a revealed receipt or reinterpret an existing agreement. Until root/Weibao review, no record has `accepted` or `implemented` status. Uncovered material discretion pauses the affected action for a new record rather than letting an agent choose silently.

## Coverage boundary and future acceptance

This is the complete first decision inventory for the **authored ST2, noncombat PS01–PS06 fixture described here**, not an exhaustive index of every GM decision in the SRD. It includes the alternative mundane/replacement/negotiation paths the fixture exposes. Other class starts, novel spells, surprise, combat, wounds, resurrection, item identification/attunement, teaching progression and canonical event scheduling stay out of this fixture; before such an action is enabled, inspect its passage and append the decisions it needs.
