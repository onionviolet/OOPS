# Completion contract template

Use with [the completion standard](../../WORLD_COMPLETION_STANDARD.md). Reuse a
scope's existing completion owner instead of adding a competing one. Fill only
the relevant detail owners, but review every section for applicability. This is
an authoring contract, not a runtime definition or a promise of a completed world.
