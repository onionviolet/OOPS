## Catalogue completeness note

The wiki dump contains hundreds of character, location, history, item and adaptation pages. This table is a systems index, not an exhaustive roster. The notes should be searched for a specific character or item before extending a module. Continuity fields are mandatory, including for shared-looking names. Additional ability families should be added only with an exact source revision and continuity assignment.
