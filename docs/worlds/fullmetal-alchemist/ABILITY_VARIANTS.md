## Authoring rule

A variant record should separate `sourceContinuity`, `learnedMethod`, `knowledgeConfidence`, `carrier`, `materials`, `trigger`, `range`, `duration`, `costPayer`, `bodySupport`, `counterEvidence`, and `transferPolicy`. Unknown fields remain unknown. A label such as “flame alchemy” does not fill missing values automatically.
