### What was not read

No manga volumes, Brotherhood episodes, 2003 episodes, sequel film, novels or games were read in full during this synthesis. Private wiki payload spot-checks were performed for Alchemy r78024 (Overview, Equivalent Exchange, Rebound, Transmutation Circle) and Philosopher's Stone r78123 (Composition and History). Claims here remain traced to dated secondary wiki revisions, not primary manga/anime scenes. The review summary calls out procedural deviation from strict ascending input order/checkpoint cadence, but reports no hash/range mismatch. The `source-deep-dive` skill was requested, but no such skill was available in the loaded catalog or local skill search; the repository's M5 playbook and checklist were used.

## 2. Rules an engine has to model

## 8. First playable slice proposal

| Status | Field | Proposal |
|---|---|---|
| Proposal | Slice | A supervised materials-bench operation in one selected manga/Brotherhood snapshot. The player inspects one sample, reviews a taught method, and chooses to execute, request help or stop. |
| Proposal | Screen | Desktop/laptop first: persistent sample/tool/method panel, action/result panel and readable cost receipt. Mobile optimization deferred. |
| Proposal | Outcome | One simple source-verified transformation with declared matter inputs and one useful output. A missing input and uncertain composition have truthful blocked paths. |
| Proposal | Play loop | Gather sample -> study composition -> prepare array -> commit operation -> inspect result and remaining stock -> return to mentor or shop. |
| Proposal | Exclusions | No Philosopher's Stone, human transmutation, soul binding, canon protagonist control, randomized truth, cross-world power, new prestige or full campaign. |
| Proposal | Completion gate | Primary source checked; existing state owners mapped; new authoring reviewed; one writer transferred; rebuilt bytes exercised from a fresh browser origin; save/reload/import if persistence changes. Human acceptance remains separate. |

- Tracked/private boundary: no raw prose included; source summaries are paraphrased, and this pack is suitable for tracked docs.

This synthesis searched the notes and digest, then directly spot-checked selected sections of two private revision payloads. It did not read primary installments.
