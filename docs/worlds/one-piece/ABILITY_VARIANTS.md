# One Piece ability variants (proposal)

Status: Develop/Research proposal. The source pages describe individual effects and counterexamples; this file maps those to authoring tests, not new canon facts. Every variant below is an O proposal; evidence keys are in [SOURCE_LEDGER](SOURCE_LEDGER.md). Shared contract: [ABILITY_AUTHORING](../ABILITY_AUTHORING.md).

## Variant axes

| Axis | Authoring question | Proposal rule |
|---|---|---|
| Actor/source | Who has this gift or learned method? | Bind it to actual bearer/source; no transfer by visual imitation |
| Trigger | What exact act starts it? | Include intent, contact, target selection, spoken procedure or passive condition only where sourced |
| Target and scope | Person, body, object, terrain, zone, or environment? | Name range, boundary, line/path and eligibility separately |
| Resource | What effort or finite reserve is spent? | Separate stamina, Haki reserve, medicine, tool fuel, time and lifespan |
| Counter | What can interrupt, resist, expose or redirect it? | Use actual material/ability-specific interactions; no global anti-power toggle |
| Persistence | What remains after the user stops, leaves or is defeated? | Record effect state, custody and cause of reversal independently |
| Evidence | Who knows the rule and why? | Separate observed result, report, interpretation, wiki assertion and proposal |

## Cross-world interaction policy (proposal)

A genuinely compatible imported ability acts at its full supported strength. The adjudicator first checks actual target, mechanism, medium, body, range and timing. If all match, the effect works even if it trivializes a weaker obstacle. If one is unknown, preserve uncertainty or ask for a supported test; never add a compensating immunity because the result is strong. World-specific authority such as a crew order does not automatically travel as combat power. Fruit sea weakness applies to its bearer under its own rule, not to unrelated imported abilities.

## Source version labels

Do not combine anime aura depiction, movie-only fruits, game stats, attraction rules or guidebook dimensions with manga mechanics. A candidate variant may use those sources only after a separate continuity is selected and its label remains at row level. Snapshot assertions after the latest dump page date are U until verified; no memory-based update is allowed.
