## W15.D: proposed landing and one schema (INFERRED)

**W15.D1 Default:** extend the existing capability read boundary, with executable power records as the canonical power-ownership/mastery writer. A world core is an author-side composite card compiled into existing sources, powers, advancements, energies and commands. It is not a seventh saved `powerCores` store. The public read shape includes named views of the existing owners; it does not pretend `queryCapabilities` already exposes them. A1's final read API can host this shape.

**W15.D1 Dial:** leave legacy technique proficiency or skill XP authoritative when an existing ability actually uses them; declare that binding explicitly. New world techniques default to power IDs plus knowledge-route evidence, avoiding another copy of owned/mastery on `actors.techniques`. A later techniques-to-powers migration is optional and bounded. In-world reason: owning a gift, knowing how to use it and improving a craft are separate facts.

**W15.D2 Stated merge:** capabilities and power models are a single *read/authoring interface*, not a blind physical-store merge. Sources/faculties supply access; powers supply execution/ownership; resources supply means; advancement supplies growth. No two authoritative meters for the same mastery. A derived capability contribution may refer to that meter, but does not copy it. Institutional rank lives with standing/claims/titles, not in the power core.

Views name authority IDs and current revision. Self-view and observer-view differ. Quotes are not executable commitments: commit rechecks sequence, presence, custody, funding and current suppression. Never expose secret truth or private rank through unavailable reasons.

**W15.S14 Personal generation:** choose compatible authored candidates or bounded effect functions after actual acquisition eligibility; source-world profile and body capacity gate first. Use a future adopted seeded stream for a committed draw, freeze choices/parameters/revision/cause, validate effects, then grant. Invalid candidates produce a visible refusal with no charge or reroll. Do not assume an immutable generator root exists today. Names, visual signatures and rumours use separate presentation randomness; names grant no effect.

**W15.S15 Idle rule:** credit only a supported committed interval or maintained condition. Recovery is not mastery; mastery is not rank recognition. Split at local clock, resource exhaustion, participant departure and condition changes. Integer quanta with explicit remainder; deduplicate cause/interval receipts. Default closed-browser absence freezes as current world owners require. Dial later supported catch-up and safe stop policy through the offline lane. No automatic digestion, lethal hazard or rare breakthrough from UI repaint or elapsed wall-clock alone.
