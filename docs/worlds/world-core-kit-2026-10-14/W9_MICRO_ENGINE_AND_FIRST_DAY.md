**ME12 Default:** one versioned `microRows` collection under a world's existing
content-pack definition, not a second world registry. Direct source names and
sourced text follow the existing private-pack boundary. Public mechanisms and
original fill can remain generic. W7 owns source-qualified rows; W8 owns K19-K24;

**ME13 Generation:** resolve instance ID, stable micro seed, pinned content revision,
local day/phase, district, channel and sensory/knowledge context. Filter eligibility
first. Order authored rows before original generated fill for the same family and
scope; priority never bypasses a gate. Hash a separate `micro` namespace into a
stable candidate order. Fill composes small checked slots, such as known shop type,
current rain and time phase. It cannot invent a name, price, death, NPC presence,
quest, hidden truth or item ownership. Unknown slots fall back to plain sensation
or silence. Missing private pack produces a declared unavailable channel, not an
alternate canon world. Rendering never consumes combat, story or reward draws.

**ME14 KM-c default:** one chosen line per eligible observation slot, with deterministic
cyclic order across clock slots. Same slot and eligibility snapshot return the same
line on all redraws. A bounded session cache tracks actually displayed row/family
IDs and ephemeral seen counts across look/log/NPC channels, skipping recent rows
when alternatives exist. Fewer eligible rows than the guard window means silence
or a longer interval, not forced repetition or gate bypass. Hash ordering plus
cyclic indexing needs to use the same eligible deck for a slot; eligibility changes
can otherwise repeat a row, which the cache guards during the session.

**ME14 Dial:** session variety is save-free but does not promise exact cross-reload
seen counts. Strict cross-reload variety needs a bounded saved ring of recent IDs,
last observation slot and counts for that ring, pruned by window; it is a real
KM-h exception. Default reload returns the current derived line and earns nothing.
Content updates retain the pinned revision or migrate IDs explicitly. Do not derive
micro from mutable expansion RNG. Creating a stable root for an old save needs
one durable initialization transaction, never a new root on each load.

**ME15 KM-d default:** newcomer notices public sound/smell and plain signs. Familiar
notices distinctions backed by actual repeated exposure or instruction. Regular
recognizes a learned tell only where that fact is understood and the actor can
sense it. Prefer specific knowledge keys over a universal XP meter. One meaningful
observation quantum or queued practice receipt may advance familiarity; UI renders,
refresh loops and repeated clicks in the same quantum do not. Instruction can be
an accessible alternative to hearing/seeing a cue. A rumour remains attributed and
uncertain; understanding wording does not certify its truth. Knowledge gates operate
before spoiler/secret-safe text projection, with route eligibility still required.

**ME15 Dial:** familiarity pace, useful instruction and sensory channels vary by
world/district/body. If exposure counts are not already owned, add one bounded
place/family counter with a schema decision; do not claim counts are save-free.
Repetition alone never learns a forbidden name, private motive or sealed answer.
