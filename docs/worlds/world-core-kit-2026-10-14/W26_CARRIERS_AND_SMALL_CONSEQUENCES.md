Filenames and lines are repository-relative unless a URL is given.

**W26.F1:** the shared gap is accountable delivery, not an absence of consequences. Keep this chain visible in design: committed act → eligible observation/record → account sent by a carrier → actual receipt → holder-specific belief → authorized response. A rumour can change belief without proving guilt. A debt can exist between parties before any third party hears it. An apology can close a specific grievance without erasing the act.

Standing direction remains canon-first, one realm/one prestige for the first milestone, Soldier runtime paused. No new lane or implementation wave is authorized here. A later cause/receipt view should target 1366×768 and wider desktop/laptop space, beside routine actions; mobile optimization remains deferred. This document makes no UI claim.
