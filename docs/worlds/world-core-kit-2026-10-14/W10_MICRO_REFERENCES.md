## Evidence and choice key

**STATED** identifies a checked official page, wiki or developer source, linked
in each row. **STATED(index)** means the web search index supplied the bounded
claim; direct access was unavailable or unnecessary. It is weaker than reading
the full page, and is explicitly marked. **SHOWN(doc)** means inspected local
documentation, not gameplay. **INFERRED** covers every adoption choice, transfer,
dial and proposed guard. No unchecked MEMORY claim supplies a mechanism.

Each mechanism records **T** trigger, **V** visible result and **P** persistence.
P describes source-game or source-story continuity, not a tested save format.
No reference game was played in this pass. For a book, a recurring practice or
kept object counts as continuity; it is not evidence of an engine counter.
Where persistence is not established, the row says so.

**Adopt** means the mechanism's shape fits; **adapt** means change its timing,
cost, scope or presentation; **skip** means skip the named source behavior for
the modest default, with a world-specific dial still possible. These are taste
judgments, not new absolute rules. Maps use the root's existing codes, not new
parallel feature families. KG codes in a transfer column are proposed guards,
not a claim that the source game implements that guard.
