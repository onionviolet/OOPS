# Local artifacts and maintained studies

The four-group integration retains useful work as source, dated evidence or a named local archive. A Git ignore entry describes storage/publication policy, not permission to discard a file or evidence that a study works.

| Home | Role and maintenance |
|---|---|
| `prototypes/workbench/studies/` | Maintained comparison sources, build/probe scripts and dated study evidence; see the [study index](../../prototypes/workbench/studies/README.md). Sketches and native prototypes retain distinct labels. |
| `prototypes/progress-atlas/` | Promoted historical atlas sources, preview, data, manifests and checks. [Commands and freshness limits](../../prototypes/progress-atlas/README.md). Draft generation does not overwrite the reviewed report. |
| `.lane-builds/` and `prototypes/workbench/built/` | Reproducible local bundles/assets. Preserve referenced proof builds until their receipts are retired; regenerate for new behavior claims. Public build sources remain versioned. |
| `private/` | Retained test logs, generated-origin saves, images and recovery archives. `private/artifact-catalogue/retained-artifacts-2026-11-04.json` records original paths, byte sizes, hashes and local dispositions. The root-promotion manifest records all six relocated strays. |
| `docs/research/recovered-artifacts/private/2026-11-04/` | Recovered source-shaped JSON with unestablished provenance, separated from qualified holdings. [Recovery owner](../research/recovered-artifacts/README.md). |
| Existing dated dispatch evidence directories | Historical screenshots, generated saves, profiles and raw diagnostic captures stay at their existing locators, catalogued locally and explicitly excluded from publication.
