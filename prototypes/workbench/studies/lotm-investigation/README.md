# LOTM investigation and confrontation comparison

**Sketch. Original LOTM-inspired case, not a canon scene or native engine integration.**
All evidence, costs, outcomes, figures and map geometry are authored comparison fixtures.
No personal save access or purchases. Same commands/state across all three styles.

```sh
node prototypes/workbench/studies/lotm-investigation/build.mjs
node prototypes/workbench/serve.mjs
```

Open the printed URL with `?study=lotm-investigation`. Layout switching preserves
state; Compare mirrors resulting snapshots rather than replaying commands.

Investigation: inspect latch, question porter, compare sources in notebook,
establish focus with the field kit, then choose an appropriate response. Spirit
Vision is another evidence source with a resource/time cost. Committed actions
advance the disturbance; inspection/notebook reading do not. Prepared confrontation
starts near the choice; Low spirituality exposes refusal and withdrawal alternatives.
Walking uses arrows/WASD, E, on-screen controls or click-to-route. It changes
position but does not spend a turn, matching the prior comparison's fairness policy.
A central crate footprint blocks routes; this is not a full physics/visibility model.

```sh
node prototypes/workbench/studies/lotm-investigation/check.cjs http://127.0.0.1:PORT/
```

Evidence: checks.json and 1920px combat captures under evidence/. INPUTS.json
records frozen source/output hashes; the workbench reports drift. The inline
fragment is generated from the same source, not a second model.
