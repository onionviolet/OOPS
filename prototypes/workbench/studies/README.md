These sources have been promoted from uncommitted experiments into the existing workbench. They retain their original proposal and evidence scope; none changes the production UI by being kept.

| Study | Source and route |
|---|---|
| Functional home | [README](functional-home/README.md): native Cottage-owner comparison, furnishing/replacement and rest/repair controls. |
| Equipment comparison | [README](equipment-comparison/README.md): native prepared-fixture repair and component swap comparison. |
| Native home | [README](native-home/README.md): earlier native home presentation experiment, retained as an alternative. |

| LOTM investigation | [README](lotm-investigation/README.md): original synthetic case with shared state/commands across presentation variants. |

Run a study's build command from the repository root, then `node prototypes/workbench/serve.mjs`. Generated bundles live under ignored `prototypes/workbench/built/`. The main [workbench README](../README.md) and [mockup owner](../../../docs/MOCKUP_SYSTEM.md) govern freshness and proof boundaries. Dated capture galleries are historical evidence, not current-source verification. The named native-character fresh-base fixture is retained as the existing study's generated QA input, not a player save.
